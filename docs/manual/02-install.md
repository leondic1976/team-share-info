# 설치와 시작

## 1. 설치

1. 설치 파일 `TeamHub-Setup-버전.exe`를 실행합니다. 관리자 권한은 필요 없습니다.
2. **"Windows의 PC 보호"** 창이 뜨면 **추가 정보** → **실행**을 누릅니다. (사내용 프로그램이라 코드 서명이 없어 표시됩니다.)
3. 설치가 끝나면 TeamHub가 실행되고 바탕화면에 바로가기가 생깁니다.

팀원은 서버 PC 설정이 끝난 뒤 브라우저에서 `http://서버IP:47800/download` 를 열어 설치 파일을 받을 수 있습니다.

> 보안 프로그램이 설치나 실행을 막으면 관리자에게 예외 등록을 요청하세요. 필요한 정보: 프로그램 이름 TeamHub, 사용 포트 TCP 47800(변경 가능), UDP 47801.

## 2. 처음 실행 — 사용 방식 선택

| 선택 | 대상 |
|---|---|
| **서버에 접속** | 대부분의 팀원 |
| **이 PC를 서버로 사용** | 팀에서 한 대만. 자료와 일정이 이 PC에 저장됩니다. |

## 3. 서버 PC 설정 (관리자, 1회)

**이 PC를 서버로 사용**을 누르면 8단계 설정 화면이 나옵니다. 모든 값은 나중에 **관리 → 조직·운영 설정**에서 바꿀 수 있습니다.

| 단계 | 입력 | 설명 |
|---|---|---|
| 1. 조직 정보 | 기관/회사명, 소속 팀명 | 하단 표시줄에 표시됩니다. |
| 2. 관리자 | 이름, 부서, 직위, 내선번호, 관리 PIN(선택) | PIN(숫자 4~8자리)을 정하면 관리 메뉴를 열 때마다 입력합니다. |
| 3. 네트워크 | 사용할 네트워크(IP), 포트, 허용 IP 대역, 승인 방식 | 팀원이 접속할 주소를 고릅니다. 가상/VPN 표시가 있는 항목은 피하세요. 허용 IP 대역을 비우면 제한이 없습니다. |
| 4. 저장 위치 | 데이터 폴더, 전체 용량 한도, 파일당 최대 크기 | 여유 공간이 충분한 드라이브를 고릅니다. |
| 5. 백업 | 백업 위치, 매일 백업 시각, 보관 개수 | 다른 드라이브나 NAS를 권장합니다. |
| 6. 안내문 | 하단 안내문 | 모든 팀원 화면 맨 아래에 표시됩니다. |
| 7. 운영 | Windows 시작 시 자동 실행, 절전 방지, 방화벽 규칙 자동 등록 | 방화벽 등록 시 관리자 권한 확인 창이 한 번 뜹니다. **예**를 누르세요. |
| 8. 완료 | 입력 내용 확인 → **설정 완료** | |

설정이 끝나면 **접속 주소**(예: `192.168.10.5:47800`)와 **설치 안내 주소**가 표시됩니다. 복사 버튼으로 복사해 팀원에게 알려 주고 **시작하기**를 누릅니다.

**서버 PC 운영 시 지킬 것**
- 서버 PC는 팀원이 사용하는 동안 켜 두어야 합니다. 꺼져 있으면 팀원은 저장된 화면만 볼 수 있습니다.
- 서버 PC의 IP가 바뀌지 않도록 고정 IP(또는 공유기의 DHCP 예약)를 쓰세요.

## 4. 팀원 접속과 사용 신청

1. **서버에 접속**을 누릅니다.
2. **자동으로 찾은 서버** 목록에 팀 서버가 보이면 클릭합니다. 없으면 **서버 주소**에 관리자에게 받은 주소를 입력하고 **연결 확인**을 누릅니다.
   - 포트가 기본값(47800)과 다르면 `192.168.10.5:5000`처럼 입력합니다.
3. 이름·부서·직위·내선번호를 입력합니다.
4. 안내 사항을 확인하고 체크한 뒤 **사용 신청**을 누릅니다.
5. **승인 대기 중** 화면이 나옵니다. 관리자가 승인하면 자동으로 메인 화면이 열립니다.

- 로그인과 비밀번호는 없습니다. 승인된 PC와 Windows 계정으로 본인을 확인합니다.
- 다른 PC나 다른 Windows 계정에서 쓰려면 그 PC(계정)에서 다시 사용 신청을 합니다.
- PC 앞을 비울 때는 Windows 잠금(`Windows 키 + L`)을 하세요. 로그인이 없으므로 PC를 쓰는 사람이 곧 그 팀원으로 처리됩니다.

## 5. 업데이트

- 관리자가 서버에 새 버전을 등록하면 접속 중인 PC가 자동으로 내려받습니다.
- 다 받으면 하단 표시줄에 **v버전 설치(다시 시작)** 버튼이 나옵니다. 누르면 설치 후 다시 실행됩니다. 누르지 않으면 다음에 프로그램을 끌 때 설치됩니다.
- **업데이트가 필요합니다** 화면이 나오면 새 버전을 받는 중이니 기다렸다가 **지금 설치하고 다시 시작**을 누릅니다.

## 6. 제거

Windows **설정 → 앱 → 설치된 앱**에서 TeamHub를 제거합니다. 개인 데이터는 지워지지 않고 `%APPDATA%\TeamHub` 폴더에 남습니다. 다시 설치하면 그대로 이어서 쓸 수 있습니다.
