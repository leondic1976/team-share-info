# 자료실

팀 파일을 서버 PC에 모아 두고 함께 쓰는 곳입니다.

## 폴더 구조와 공개 범위
- 자료실 첫 화면에는 **최상위 폴더**가 보입니다. 최상위 폴더마다 **공개 범위**(팀 전체·그룹·지정한 사람)와 **올리기 권한**이 있고, 안의 하위 폴더·파일은 모두 이 설정을 따릅니다.
- 공개 범위 밖의 사람에게는 폴더가 보이지 않습니다.
- 왼쪽 위 공간 전환에서 그룹을 고르면 그 그룹의 최상위 폴더만 보입니다.
- 위쪽 경로(**자료실 > 폴더 > …**)를 눌러 상위 폴더로 이동합니다.

## 폴더 만들기
1. **새 폴더**를 누릅니다.
2. 최상위 폴더라면 공개 범위와 올리기 권한을 고릅니다.
   - **볼 수 있는 사람 모두**: 볼 수 있는 사람은 누구나 파일을 올릴 수 있습니다.
   - **만든 사람·관리자만 (읽기 전용 폴더)**: 양식·규정처럼 정해진 사람만 올리는 폴더입니다.
3. **저장**을 누릅니다.
- 폴더 줄 오른쪽 **⋯ → 설정**에서 이름·공개 범위·권한을 바꾸고, **⋯ → 삭제**로 휴지통에 보냅니다.

## 올리기
- 폴더를 연 뒤 **파일 올리기** 또는 **폴더 올리기**를 누르거나, 탐색기에서 파일·폴더를 **창에 끌어다 놓습니다**.
- 폴더를 올리면 안의 하위 폴더 구조가 그대로 만들어집니다.
- 오른쪽 아래 **전송** 창에 진행률이 표시됩니다. ✕로 취소합니다.
- 큰 파일은 8MB씩 나누어 보냅니다. 도중에 네트워크가 끊기거나 서버 PC가 꺼지거나 프로그램이 꺼져도, 다시 연결되면 **멈춘 곳부터 이어서** 올립니다. 기다리는 동안 전송 창에 "연결되면 이어서 올립니다"라고 표시되고, 최대 1분 간격으로 스스로 다시 시도합니다.
- 멈췄거나 실패한 항목은 전송 창의 **↻ (다시 시도)** 로 바로 이어서 보낼 수 있습니다.
- **같은 이름**의 파일을 같은 폴더에 올리면 기존 파일의 **새 버전**으로 쌓입니다.
- 파일 하나의 크기 한도는 기본 **5GB**, 서버 전체 한도는 기본 **200GB**입니다. 한도와 올릴 수 없는 확장자(실행 파일 등)는 관리자가 정합니다(관리 → 설정 → 저장 공간).

## 파일 열기와 수정
- 파일을 **더블클릭**하거나 **⋯ → 바로 열기**를 누르면 연결된 프로그램(한글·엑셀 등)으로 열립니다.
- 그 프로그램에서 저장하면 TeamHub가 **"새 버전으로 올릴까요?"** 를 묻습니다. **새 버전으로 올리기**를 누르면 자료실에 반영됩니다.
- **⋯ → 내려받기**: 원하는 위치에 저장합니다. 받는 도중 네트워크가 끊기면 전송 창에 "연결되면 이어서 받습니다"라고 표시되고, 다시 연결되면 **받은 곳부터 이어서** 받습니다. 프로그램을 껐다 켜도 이어집니다. 그 사이 파일이 새 버전으로 바뀌었으면 처음부터 새 버전을 받습니다.
- 받는 중인 파일은 저장 위치에 `파일이름.teamhub-part`로 있다가, 다 받으면 원래 이름으로 바뀝니다. ✕로 취소하면 지워집니다.

## 파일 정보 (파일을 한 번 클릭)
- **미리보기**: 그림, PDF, 텍스트 파일은 바로 보입니다.
- **버전**: 버전별 시각·올린 사람·크기·메모. 각 버전을 내려받거나 **이 버전으로 복원**할 수 있습니다(복원하면 새 버전으로 등록됨).
- **편집 잠금**: 내가 고치는 동안 다른 사람이 새 버전을 올리지 못하게 합니다. 목록에 🔒 이름이 표시됩니다. 다 고친 뒤 **편집 잠금 풀기**를 누르세요. 폴더 관리자와 관리자는 **잠금 강제 해제**를 할 수 있습니다.
- **내려받기 기록**: 올린 사람과 폴더 관리자에게 누가 언제 받았는지 보입니다.
- **⋯ → 이름 바꾸기 / 삭제**

## 검색·최근 파일
- 위쪽 **파일 이름 검색**에 입력하면 볼 수 있는 모든 폴더에서 찾습니다(위치 함께 표시).
- **최근**: 최근에 올라오거나 바뀐 파일 30개.

## 휴지통
- 지운 파일·폴더는 **30일** 동안 휴지통에 남았다가 자동으로 완전히 지워집니다.
- **휴지통**을 누르면 내가 올렸거나 지운 항목이 보입니다(관리자는 전체).
- **복원**으로 원래 자리에 되돌리고, **영구 삭제**로 바로 지웁니다.
