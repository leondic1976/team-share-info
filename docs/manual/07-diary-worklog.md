# 다이어리 · 업무일지

왼쪽 메뉴 **다이어리**를 누르고, 오른쪽 위 **다이어리 / 업무일지** 버튼으로 바꿉니다.

## 다이어리 (개인용, 내 PC에만 저장)
- 하루에 한 장씩 씁니다. 왼쪽 달력에서 날짜를 고르면 그날 다이어리가 열립니다. 점이 찍힌 날은 쓴 내용이 있는 날입니다.
- 입력하면 **자동으로 저장**됩니다(오른쪽 위에 "저장됨" 시각 표시).
- 서식 도구(굵게, 목록, 체크리스트, 표 등)를 쓸 수 있고 이미지를 붙여넣을 수 있습니다.
- **태그**: 쉼표로 구분해 입력하면 검색에 쓰입니다.
- **내용·태그 검색**: 왼쪽 검색창에 입력하면 해당 날짜 목록이 나옵니다.
- **지우기**: 그날 다이어리를 지웁니다.
- 다이어리는 서버로 보내지 않으며 관리자도 볼 수 없습니다. 서버에 연결되지 않아도 쓸 수 있습니다.
- PC를 바꿀 때는 **설정 → 개인 데이터 → 내보내기/가져오기**로 옮깁니다.

## 업무일지 (공유)

### 쓰기
1. **내 업무일지 쓰기**를 누릅니다.
2. 날짜를 고릅니다(양쪽 화살표 단추로 하루씩 이동).
3. **오늘 한 일 / 내일 할 일 / 특이사항**을 씁니다.
4. **공개 범위**를 정합니다(팀 전체 · 그룹 · 지정한 사람, 예: 팀장만).
5. **업무일지 저장**을 누릅니다. 같은 날짜에 다시 저장하면 덮어씁니다.

### 보기와 주간·월간 취합
1. **팀 업무일지 보기·취합**을 누릅니다.
2. 기간을 정합니다(**이번 주 / 이번 달** 버튼 또는 날짜 직접 입력). 작성자를 고를 수 있습니다.
3. 공개 범위에 해당하는 일지만 보입니다.
4. **문서로 내보내기(.doc)** 를 누르면 기간 내 일지가 날짜·작성자 순으로 묶인 문서가 저장됩니다. 한글·워드에서 열어 주간·월간 업무보고로 고쳐 씁니다.

## 주간 돌아보기
**다이어리 → 주간 돌아보기**. 한 주의 업무를 모아 주간 보고 초안을 만듭니다.
1. 양쪽 화살표 단추로 주를 고릅니다(월요일 시작).
2. 위 숫자 칸에 그 주의 **일정·회의**와 **업무일지** 개수가 나옵니다.
3. **보고 초안 만들기**를 누르면 초안이 편집기에 채워집니다. **이번 주 한 일**에는 업무일지의 "오늘 한 일"이, **참석한 일정·회의**에는 그 주의 일정이 들어가고, **다음 주 계획**과 **특이 사항**은 직접 씁니다. 자유롭게 고칩니다.
4. **글자만 복사**로 한글·메일에 붙여넣거나, **메모로 저장**(태그 "주간보고")합니다.
- 초안은 저장하기 전까지 아무 곳에도 보내지 않습니다. 서버에 연결되지 않으면 이 PC의 개인 일정만 모읍니다. 다이어리 내용은 넣지 않습니다.
