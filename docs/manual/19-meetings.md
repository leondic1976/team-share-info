# 회의 (화상회의 · 화면 공유)

사내망 안에서 PC끼리 직접 연결해 영상·음성·화면을 주고받습니다. 별도 회의 서버나 인터넷이 필요 없습니다. **영상·음성·화면·회의 대화는 어디에도 저장되지 않습니다.** 서버에는 회의 제목·시각·참가자만 남습니다.

## 회의 시작
| 어디서 | 방법 | 참가 대상 |
|---|---|---|
| 회의 메뉴 | **회의 시작** → 제목, 방식(영상 회의 / 화면만 공유), 참가할 사람 → **시작** | 고른 사람·그룹 |
| 메신저 대화방 | 대화방 위쪽 **이 대화방에서 회의 시작**(카메라 모양 단추) | 대화방 구성원(그룹 대화방은 그룹) |
| 그룹 | 그룹 정보에서 **그룹 회의 시작** | 그룹 구성원 |
| 일정 | 공유 일정을 열고 **화상 회의** | 참석자. 이미 열린 회의가 있으면 그 회의로 들어감 |

- 지정한 사람·그룹에게는 화면 오른쪽 아래에 **초대 창**이 뜨고 소리가 납니다. **참가** 또는 **거절**을 누릅니다. 거절하면 회의를 연 사람에게 알려집니다.
- 팀 전체로 연 회의는 초대 창 없이 **회의** 메뉴와 홈의 **진행 중인 회의**에 보입니다. 누구나 **참가**할 수 있습니다.
- 공개 범위 밖의 사람에게는 회의가 보이지 않습니다.

## 참가 전 확인
회의 창이 열리면 먼저 내 화면이 미리 보입니다.
- 마이크·카메라를 켜거나 끄고 들어갈 수 있습니다. 장치가 여러 개면 목록에서 고릅니다.
- 카메라나 마이크가 없어도 참가할 수 있습니다(음성만, 또는 보기만).
- **참가**를 누르면 회의에 들어갑니다.

## 회의 중
| 버튼 | 기능 |
|---|---|
| **마이크 켜기 / 끄기** | 마이크 켜기·끄기. 꺼진 사람은 이름 옆에 빨간 표시 |
| **카메라 켜기 / 끄기** | 카메라 켜기·끄기 |
| 화면 공유 | 공유할 **화면** 또는 **창**을 고름. "컴퓨터 소리도 함께 공유"를 체크하면 소리도 보냄(전체 화면일 때) |
| **손들기** | 손을 들어 말하고 싶다고 알림 |
| **회의 대화** | 회의 대화(회의가 끝나면 사라짐) |
| **참가자** | 참가자 목록 |
| 나가기 | 나만 나감. 마지막 사람이 나가면 회의가 끝남 |
| 회의 끝내기 | 회의를 연 사람·관리자만. 모두의 회의를 끝냄 |

- 말하는 사람의 화면 둘레가 초록색으로 빛납니다.
- 누군가 화면을 공유하면 공유 화면이 크게, 참가자 영상은 오른쪽에 작게 보입니다. 공유 화면을 누르면 그 위치에 빨간 표시가 모두에게 보입니다(설명할 때 가리키기).
- 전체 화면을 공유하는 동안 내 화면 가장자리에 빨간 테두리와 "화면 공유 중"이 표시됩니다(상대에게는 보이지 않음).
- 연결이 끊기면 자동으로 다시 연결합니다.

## 인원 기준
- 영상 회의: **6명까지 권장**, 최대 8명. 6명을 넘으면 새로 들어오는 사람은 카메라가 꺼진 채로 들어갑니다(필요하면 켬).
- 화면만 공유: 보는 사람 15명까지 권장.
- 인원이 많을수록 각 PC의 CPU·네트워크 사용량이 늘어납니다.

## 회의가 끝난 뒤
- 회의 창에 **회의록 작성**이 나옵니다. 누르면 회의 제목·일시·참석자가 채워진 회의록 쓰기 화면이 열립니다(일정에 걸린 회의는 그 일정과 연결).
- **회의 → 지난 회의**에서 지난 회의의 제목·시각·참가자를 봅니다.

## 연결이 안 될 때
- 서로 다른 PC끼리 연결되지 않으면 Windows 방화벽이 TeamHub를 막고 있을 수 있습니다. **설정 → 서버 연결 → 방화벽**에서 **방화벽 규칙 등록**을 누르거나(관리자 권한 필요), 처음 회의할 때 Windows가 묻는 창에서 **허용**을 누르거나, 전산 담당자에게 TeamHub 허용을 요청하세요.
- 서로 다른 네트워크(예: 업무망과 인터넷망)에 있는 PC끼리는 연결되지 않습니다.
- 카메라·마이크가 다른 프로그램(다른 화상회의 프로그램)에서 쓰이고 있으면 켜지지 않습니다. 그 프로그램을 닫고 다시 참가하세요.
