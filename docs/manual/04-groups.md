# 그룹

팀 안에서 **일부 구성원끼리만** 정보를 나누는 공간입니다. (예: TF, 담당 업무 모임, 행사 준비반)

## 공간 전환

왼쪽 메뉴 맨 위의 **팀 전체 ▾** 를 누르면 내가 속한 그룹 목록이 나옵니다.

- 그룹을 고르면 공지·일정·자료실 등 각 메뉴가 **그 그룹의 내용만** 보여 줍니다.
- 그룹을 고른 상태에서 새 글을 쓰면 공개 범위가 **그 그룹**으로 미리 정해집니다.
- 다시 **팀 전체**를 고르면 팀 전체 내용과 내 그룹 내용을 모두 봅니다.
- 프로그램 맨 위 표시줄에 **기관 · 팀명 › 지금 보고 있는 그룹명**이 표시됩니다(팀 전체일 때는 팀명만). 그룹명을 누르면 그룹 화면이 열립니다.
- 그룹 내용에는 그룹 색깔의 이름표가 붙습니다.

## 그룹 만들기

1. **팀 전체 ▾** → **그룹 관리…** (또는 그룹 화면)으로 갑니다.
2. **새 그룹**을 누릅니다.
3. 그룹 이름, 설명, 색상, 종류, 초대할 사람을 정하고 **만들기**를 누릅니다.

| 종류 | 설명 |
|---|---|
| 비공개 | 그룹 목록에 보이지 않습니다. 초대받은 사람만 가입합니다. |
| 공개 | 모든 팀원의 그룹 목록에 보이고 누구나 **가입 신청**을 할 수 있습니다. |

만든 사람이 **그룹장**(왕관 표시)이 됩니다. 관리자가 "그룹 만들기 권한"을 최종관리자·서무만으로 정했으면 일반 팀원은 만들 수 없습니다.

## 초대와 가입
- **초대받은 사람**: 그룹 화면 위쪽 **받은 초대·가입 신청**에서 **수락** 또는 **거절**을 누릅니다. 홈의 **그룹 초대** 위젯에도 표시됩니다.
- **공개 그룹 가입**: 그룹 화면 아래 **공개 그룹·초대받은 그룹**에서 **가입 신청**을 누릅니다. 그룹장이 **승인**하면 가입됩니다.

## 그룹 관리 (그룹 카드를 누르면 열림)

| 기능 | 누가 | 설명 |
|---|---|---|
| 이 그룹 알림 끄기/켜기 | 구성원 | 이 그룹의 일반 알림을 받지 않습니다. |
| 그룹 회의 시작 | 구성원 | 그룹 구성원과 화상 회의를 엽니다(회의 장). |
| 그룹 나가기 | 구성원 | 나가면 그룹 자료를 더 이상 볼 수 없습니다. |
| 초대 보내기 | 그룹장 | 구성원을 골라 초대합니다. |
| 그룹장 넘기기 | 그룹장 | 다른 구성원을 그룹장으로 정합니다. 그룹장은 넘긴 뒤에 나갈 수 있습니다. |
| 내보내기 | 그룹장 | 구성원을 그룹에서 뺍니다. 즉시 그룹 자료를 볼 수 없게 됩니다. |
| 보관 | 그룹장 | 그룹을 읽기 전용으로 남깁니다. 새 글을 올릴 수 없습니다. **보관 해제**로 되돌립니다. |
| 그룹 해체 | 그룹장 | 구성원이 모두 빠지고 그룹 자료는 작성자 본인만 볼 수 있게 됩니다. |

## 알아둘 점
- 그룹 내용은 그룹 구성원에게만 전달됩니다. 구성원이 아니면 목록·검색·알림 어디에도 나타나지 않습니다.
- 관리자는 그룹의 이름·그룹장·인원만 볼 수 있고, 구성원이 아니면 내용은 볼 수 없습니다.
- 그룹 자료도 서버 PC에 저장됩니다. 그룹 안에서도 중요 보안 내용, 개인정보, 비공개 정보는 공유할 수 없습니다.
