# 메신저 · 쪽지 · 공유 메모 · 팀원 알람

왼쪽 메뉴 **메신저**를 누릅니다. 팀원에게 무언가를 보내는 기능은 모두 여기에 있습니다. 메뉴 옆 빨간 숫자는 안 읽은 메시지와 쪽지 수입니다.

| 탭 | 언제 쓰나 |
|---|---|
| **대화** | 실시간으로 주고받는 1:1 대화와 대화방 |
| **쪽지** | 한 사람씩 받는 전달 글. 누가 읽었는지 보입니다 |
| **공유 메모** | 팀·그룹·지정한 사람이 함께 보는 전달 메모판(전화 메모 등) |
| **팀원 알람** | 정한 시각에 팀원 PC에서 울리는 알람 |

화면 오른쪽 위에 **새 대화**와 **쪽지 쓰기** 단추가 항상 있습니다. 어느 탭에 있든 누르면 받는 사람을 고르는 창이 열립니다.

## 대화

### 대화 시작
1. 화면 오른쪽 위의 **새 대화**를 누릅니다.
2. 사람을 고릅니다. 한 명이면 **1:1 대화**, 여러 명이면 **대화방**이 됩니다(대화방 이름은 선택).
3. **대화 시작**을 누릅니다. 같은 사람과의 1:1 대화는 항상 같은 대화방으로 이어집니다.
- **그룹 대화방**은 그룹마다 자동으로 있습니다. 그룹 구성원이 바뀌면 대화방 구성원도 따라 바뀝니다.

### 메시지 보내기
- 아래 입력칸에 쓰고 **Enter**로 보냅니다. **Shift+Enter**는 줄바꿈입니다.
- **📎(파일 보내기)** 를 누르거나 파일을 대화 창에 끌어다 놓으면 파일을 보냅니다. 사진은 대화에 바로 보이고 누르면 크게 봅니다.
- 화면 캡처(예: `Windows 키 + Shift + S`) 후 입력칸에 **붙여넣기(Ctrl+V)** 하면 캡처 이미지가 바로 전송됩니다.
- 내가 보낸 메시지에 마우스를 올리면 나오는 휴지통으로 메시지를 지울 수 있습니다.

### 읽음 표시
메시지 옆의 **주황색 숫자**는 아직 읽지 않은 사람 수입니다. 모두 읽으면 숫자가 사라집니다.

### 대화방 관리 (오른쪽 위 버튼)
| 버튼 | 기능 |
|---|---|
| 🔔 / 🔕 | 이 대화방의 알림 켜기·끄기. 끄면 Windows 알림과 안 읽은 숫자 합계에서 빠집니다. |
| ✏ | 대화방 이름 바꾸기 (여러 명 대화방) |
| 👥 **참가자** | 참가자 목록을 보고 사람을 추가하거나 내보냅니다(아래 "참가자 추가·내보내기"). 대화방 이름 옆의 **○명**을 눌러도 열립니다. |
| 대화방 나가기 | 대화방에서 나갑니다. 1:1 대화는 상대가 다시 메시지를 보내면 다시 나타납니다. 그룹 대화방은 그룹에서 나가야 빠집니다. |

### 참가자 추가·내보내기
대화 도중 언제든 **참가자** 창에서 사람을 넣고 뺄 수 있습니다.

- **추가**: "추가할 사람"에서 사람을 체크하고 **추가**를 누릅니다. 대화방에 "○○님이 △△님을 초대했습니다"가 표시됩니다.
- **1:1 대화에 추가**: 1:1 대화는 두 사람만의 대화로 남습니다. 사람을 추가하면 두 사람과 추가한 사람이 들어간 **새 대화방**이 만들어지고 화면이 그 대화방으로 바뀝니다. 이전 1:1 대화 내용은 새 대화방으로 옮겨지지 않습니다.
- **내보내기**: 참가자 이름 옆의 **내보내기**를 누릅니다. 대화방을 만든 사람과 관리자(최종관리자·서무)만 할 수 있습니다. 내보낸 사람의 목록에서 대화방이 바로 사라지고, 그 사람은 이 대화방의 이전 대화도 볼 수 없습니다. 다시 추가하면 다시 볼 수 있습니다.
- **나가기**: 내가 대화방에서 나갑니다.
- **그룹 대화방**은 그룹 구성원을 그대로 따르므로 여기서 바꿀 수 없습니다. 그룹 메뉴에서 그룹 구성원을 바꾸세요.
- 참가자 목록의 이름을 누르면 그 사람과의 1:1 대화가 작은 메신저 창으로 열립니다.

## 작은 메신저 창
메신저 메뉴로 가지 않고, 보고 있던 화면 위에 작은 대화 창을 띄워 바로 대화합니다. 창이 떠 있어도 뒤의 화면은 그대로 쓸 수 있고, 다른 메뉴로 옮겨도 창은 남아 있습니다.

### 이름을 눌러 대화하기
사람 이름에 마우스를 올리면 밑줄이 생기고 "메신저 열기"라고 나옵니다. 누르면 그 사람과의 1:1 대화가 화면 오른쪽 아래에 작은 창으로 열립니다. 같은 사람을 다시 누르면 이미 열린 창으로 갑니다. 내 이름은 눌러지지 않습니다.

- **홈**의 팀원 현황, **주소록**의 팀원 이름, **근무현황**(일일·주간)의 이름, 게시글 작성자, 업무 요청의 요청자·담당자, 댓글 작성자, 대화방 **참가자** 목록
- **주소록**·**조직도**에서 팀원 카드를 열고 **메시지**를 눌러도 작은 창으로 열립니다.
- **근무현황** 일일 현황의 현재원 이름은 누르면 사고 신청이 열리는 경우가 있습니다. 그때는 이름 옆의 작은 말풍선을 누르면 메신저가 열립니다.
- 서버가 꺼져 있을 때: 전에 대화한 적이 있는 사람이면 창이 열려 지난 대화를 읽고 메시지를 써 둘 수 있습니다(서버가 켜지면 전송). 처음 대화하는 사람이면 창 대신 안내가 나옵니다.

### 창 다루기
| 버튼 | 기능 |
|---|---|
| **…** (대화방 메뉴) | 참가자 · 알림 끄기/켜기 · 대화방 이름 바꾸기 · 이 대화방에서 회의 시작 · 대화방 나가기 |
| **–** (최소화) | 창을 이름표로 줄입니다. 그동안 온 메시지 수가 이름표에 빨간 숫자로 표시됩니다. 이름표를 누르면 다시 펼쳐집니다. |
| **↗** (메신저에서 열기) | 작은 창을 닫고 메신저 메뉴에서 같은 대화를 엽니다. |
| **✕** (창 닫기) | 창을 닫습니다. 대화 내용은 그대로 남습니다. |

- 여러 창을 나란히 열 수 있습니다. 화면 너비에 들어가는 만큼만 펼쳐지고, 넘치면 먼저 연 창부터 이름표로 줄어듭니다. 이름표도 다 들어가지 않으면 **+N**에 모이고, 누르면 목록이 나옵니다.
- 창 위쪽 줄(이름이 있는 줄)을 끌면 창을 옮길 수 있습니다.
- 파일 보내기, 캡처 붙여넣기, 읽음 표시 등은 메신저 메뉴의 대화와 같습니다.
- TeamHub를 다시 시작하면 작은 창은 닫힌 채로 시작합니다.

### 검색
목록 위 검색칸에 입력하면 대화방 이름과 **메시지 내용**을 함께 찾습니다. 결과를 누르면 그 대화방이 열립니다.

### 알림
- 새 메시지가 오면 Windows 알림이 뜹니다. 지금 보고 있는 대화방(펼쳐 둔 작은 메신저 창 포함), 알림을 끈 대화방, 방해 금지 시간에는 뜨지 않습니다. 최소화한 작은 창의 대화는 알림이 뜹니다.
- TeamHub가 꺼져 있던 동안 온 메시지는 다음에 켤 때 그대로 보입니다.

## 쪽지
짧은 전달 사항(전화 메모 등)을 남기는 기능입니다. 받는 사람이 꺼져 있어도 다음에 켤 때 받습니다.
- **쪽지 쓰기**(화면 오른쪽 위): 받는 사람(여러 명 가능)과 내용을 입력하고 **보내기**. 주소록에서 팀원을 누르고 **쪽지**를 누르면 그 사람이 받는 사람으로 들어간 채 열립니다.
- **받은 쪽지**: 파란 점은 안 읽은 쪽지입니다. 누르면 열리고 읽음으로 바뀝니다. **답장**, **삭제**가 있습니다.
- **보낸 쪽지**: 받는 사람별 읽음 여부(**읽음 1/3** 등)와 읽은 시각을 봅니다.

## 공유 메모
**메신저 → 공유 메모**. 간단한 전달 사항·전화 메모("○○과에서 전화 왔음")를 남기는 메모판입니다. 서버에 저장되고 공개 범위의 팀원에게 보입니다. (예전에는 메모 메뉴에 있었습니다.)

1. **공유 메모 남기기**를 누릅니다.
2. 내용을 쓰고 색과 **받는 사람(공개 범위)**: 팀 전체 · 그룹 · 지정한 사람을 고릅니다.
3. **남기기**를 누르면 받는 사람 화면에 바로 나타납니다.
4. 받은 사람이 메모 아래 **확인**을 누르면 "이름 확인 · 시각"이 표시됩니다. 다시 누르면 확인이 취소됩니다.
5. 확인된 메모는 7일 뒤 목록에서 사라집니다. 지우기(🗑)는 작성자와 관리자만 합니다.

쪽지와 다른 점: 쪽지는 받는 사람마다 따로 가고 각자의 읽음이 표시됩니다. 공유 메모는 여러 사람이 **같은 메모 한 장**을 보고, 그중 누군가 처리했다고 **확인**하면 됩니다.

## 팀원 알람
**메신저 → 팀원 알람**. 다른 팀원 PC에서 정한 시각에 알람이 울리게 합니다(예: "14시 회의 자료 지참"). (예전에는 알람 메뉴에 있었습니다.)
1. 받는 사람을 체크합니다(여러 명 가능). 목록 맨 위 **전체 선택**을 체크하면 보이는 팀원이 모두 선택되고, 다시 누르면 모두 풀립니다. 이름·부서를 검색한 뒤 누르면 검색된 사람만 선택됩니다.
2. 알람 내용, 덧붙일 말(선택), 울릴 일시를 정합니다. 바로 울리게 하려면 **즉시**를 누릅니다(다시 누르면 일시를 정하는 방식으로 돌아감).
3. **보내기**를 누릅니다. **즉시**를 골랐으면 단추가 **즉시 보내기**로 바뀌고, 누르는 바로 그때 울립니다.
- 받는 사람 PC에 "○○님이 보낸 알람" 창이 뜹니다. **확인**을 누르면 보낸 사람의 **보낸 알람** 목록에 "확인 시각"이 표시됩니다.
- 그 시각에 받는 사람 PC가 꺼져 있으면 다음에 켤 때(24시간 안) 울립니다.
- 아직 전달되지 않은 알람은 **보낸 알람**에서 **취소**할 수 있습니다.

## 개인정보 확인
메시지·쪽지·공유 메모·팀원 알람을 보낼 때, 그리고 게시글·댓글·공지를 올릴 때 내용에 **개인정보로 보이는 것**이 있으면 보내기 전에 한 번 더 묻습니다.

- 찾는 것: 주민등록번호, 외국인등록번호, 여권번호, 운전면허번호, 카드번호, 계좌번호(은행 이름이나 "계좌" 뒤의 번호), 휴대폰 번호, 이메일 주소
- 확인 창에는 무엇이 몇 건인지와 일부를 가린 값(예: `900101-1******`)이 나옵니다. **확인**을 누르면 그대로 보내고, **취소**를 누르면 보내지 않고 고칠 수 있습니다.
- 검사는 이 PC에서만 하고 어디에도 기록하지 않습니다.
- 알림일 뿐 완전한 차단이 아닙니다. 형식이 다른 번호는 찾지 못할 수 있고, 개인정보가 아닌 번호를 물어볼 수도 있습니다. 첨부 파일 안의 내용은 검사하지 않습니다.

## 보관 기간
메시지와 쪽지는 최종관리자(서버 PC)가 정한 기간(기본 365일)이 지나면 자동으로 지워집니다.
