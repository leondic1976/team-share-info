# 지식 노트

왼쪽 메뉴 **지식 노트**. 업무 지식·절차·참고 자료를 페이지로 정리하는 나만의 노트입니다. 모든 노트는 이 PC에만 저장됩니다. 팀과 나누려면 **팀 기록으로** 보냅니다.

## 페이지
- **새 페이지**를 누르고 제목과 내용을 씁니다. 입력하는 대로 저장됩니다.
- 제목 왼쪽 아이콘을 누르면 아이콘을 고릅니다. 별 단추(**즐겨찾기**)를 누르면 왼쪽 **즐겨찾기**에 들어갑니다.
- **하위 페이지**로 페이지 안에 페이지를 만들어 목차(계층)를 만듭니다. 왼쪽 목록의 꺾쇠 단추로 펼치고 접습니다.
- 왼쪽 목록에서 페이지를 끌어 다른 페이지 위에 놓으면 그 아래로 들어가고, 목록 빈 곳에 놓으면 맨 위 단계로 나옵니다.
- 위쪽 경로(상위 페이지 이름)를 누르면 상위 페이지로 갑니다.

## 블록 편집
- 빈 줄이나 띄어쓰기 뒤에서 **/** 를 누르면 블록 메뉴가 나옵니다. 이어서 글자를 치면 걸러지고 ↑↓·Enter로 고릅니다.

| 블록 | 쓰임 |
|---|---|
| 제목 1·2·3, 본문 | 문단 크기 |
| 글머리 목록, 번호 목록, 체크리스트 | 목록과 할 일 |
| 토글 | 꺾쇠를 눌러 펼치는 접이식 내용 |
| 인용, 콜아웃 | 강조할 내용(콜아웃은 전구 표시가 붙은 상자) |
| 코드, 구분선, 표, 이미지 | 코드·선·표·그림(2MB 이하, 붙여넣기도 가능) |
| 페이지 연결, 하위 페이지 | 다른 페이지 링크, 새 하위 페이지를 만들고 링크 |

- 줄 맨 앞에서 `# `(제목), `- `(목록), `1. `(번호), `[] `(체크), `> `(인용), ` ``` `(코드)를 치면 바로 바뀝니다.
- 글자를 고르고 Ctrl+B(굵게), Ctrl+I(기울임), Ctrl+U(밑줄).

## 페이지 연결과 백링크
1. 본문에서 **[[** 를 치고 페이지 이름 일부를 입력합니다.
2. 목록에서 페이지를 고르면 문서 표시가 붙은 링크가 들어갑니다. 없는 이름이면 **새 페이지 "…"** 로 바로 만듭니다.
3. 링크를 누르면 그 페이지로 갑니다.
- 페이지 아래 **이 페이지를 연결한 페이지**에 이 페이지를 가리키는 페이지가 모두 나옵니다(백링크).

## 데이터베이스
표처럼 항목을 모으고 속성으로 정리합니다(예: 업무 목록, 연락처, 도서 목록).
1. 왼쪽 위 **새 데이터베이스** 단추 또는 페이지 안 **데이터베이스**를 누릅니다.
2. **+ 새 행**으로 항목을 넣고, 칸을 눌러 바로 고칩니다. 행의 **열기**를 누르면 그 항목의 페이지가 열려 내용을 쓸 수 있습니다.
3. **열 추가**: 이름과 종류(텍스트·숫자·선택·여러 선택·날짜·체크·주소)를 정합니다. 열 제목을 누르면 이름 바꾸기, "삭제", "선택지: 가,나,다"로 선택지를 바꿉니다. 선택 칸에 새 값을 넣으면 선택지에 추가됩니다.
4. **정렬**과 **필터 추가**(포함·같음·보다 큼·비어 있음·체크됨 등)로 보고 싶은 항목만 봅니다. 설정은 데이터베이스에 저장됩니다.
5. **보드**: 선택 열 기준으로 칸반처럼 봅니다. 카드를 다른 칸으로 끌면 값이 바뀝니다.

## 템플릿
- 왼쪽 위 ▤(템플릿에서 만들기): 회의 노트, 업무 일지, 프로젝트, 독서·학습 기록.
- 페이지의 **템플릿으로 저장**을 누르면 하위 페이지까지 포함해 **내 템플릿**이 됩니다.

## 찾기·내보내기·공유
- 왼쪽 검색창: 제목과 본문을 모두 찾습니다.
- **Markdown**, **HTML**: 페이지를 파일로 저장합니다.
- **팀 기록으로**: 분류(업무 매뉴얼·인수인계서·회의록·자주 묻는 질문)와 공개 범위를 정해 사본을 팀 기록에 올립니다(서버 연결 필요). 중요 보안 내용, 개인정보, 비공개 정보는 올리지 마세요.
- **복제**: 같은 위치에 사본을 만듭니다.
