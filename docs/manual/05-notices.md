# 공지와 긴급알림

## 공지 등급

| 등급 | 받는 사람 화면 |
|---|---|
| 일반 | 공지 목록에만 표시됩니다. |
| 중요 | Windows 알림이 뜹니다. 알림을 누르면 공지가 열립니다. |
| 긴급 | 화면 맨 위에 빨간 **긴급 알림** 창이 소리와 함께 뜹니다. 다른 프로그램을 전체 화면으로 쓰고 있어도 위에 표시됩니다. |

긴급 공지는 기본적으로 관리자만 보낼 수 있습니다(관리 → 조직·운영 설정 → 긴급알림 발송 권한).

## 공지 보기
- 왼쪽 메뉴 **공지**를 누릅니다. 메뉴 옆 빨간 숫자는 안 읽은 공지 수입니다.
- 목록 위의 **전체 / 안 읽음 / 내가 쓴 공지**로 걸러 봅니다.
- 공지를 열면 자동으로 **읽음**이 됩니다.
- **확인이 필요한 공지**는 본문 아래의 **확인**(또는 **참석/불참** 같은 회신 버튼)을 눌러야 합니다.
- 첨부 파일은 이름을 누르면 내려받습니다.

## 긴급공지 (아주 급할 때)

화재·대피·시스템 장애처럼 **지금 바로 모두가 알아야 하는 일**에만 씁니다. 평소 알릴 일은 아래 **공지 쓰기**를 씁니다.

**보내기**
1. 화면 맨 위의 빨간 **긴급공지** 단추(또는 공지 화면 오른쪽 위 **긴급공지**)를 누릅니다. 보낼 수 있는 사람에게만 단추가 보입니다(기본: 최종관리자·서무. **관리 → 조직·운영 설정**에서 모두로 바꿀 수 있음).
2. **무슨 일인가요?** 에 한 줄로 적습니다(화면에 가장 크게 나옵니다). 필요하면 **어떻게 해야 하나요?** 에 행동 요령을 적습니다.
3. **각자 확인을 눌러야 닫힘**(처음 값 켜짐)과 확인하지 않은 사람에게 **다시 알림** 간격(처음 값 5분)을 정합니다.
4. **긴급 발송** → 받는 사람 수를 확인하고 **지금 팀 전체 화면에 띄우기**를 누릅니다. 되돌릴 수 없습니다.
5. 보낸 뒤 열리는 화면에서 사람별 전달·확인 현황을 보고, 확인하지 않은 사람에게 **다시 알리기**를 할 수 있습니다.

- 받는 사람은 늘 **팀 전체**입니다. 일부에게만 급히 알리려면 **공지 쓰기**에서 등급 **긴급**과 공개 범위를 고릅니다.
- 서버에 연결되어 있어야 보낼 수 있습니다(서버가 꺼져 있으면 전달할 방법이 없으므로 전화 등으로 알리세요).

**받는 쪽 — 긴급공지 창**
- 보는 화면 **한가운데**에 **빨간 창**이 다른 프로그램(전체 화면 포함) 위로 뜨고 경보음이 납니다. 확인할 때까지 20초마다 다시 울립니다.
- **확인**(또는 회신 단추)을 누르면 닫히고 확인 시각이 기록됩니다. 확인이 필요한 긴급공지는 확인 전에는 닫을 수 없습니다.
- PC가 꺼져 있었으면 TeamHub를 켜는 즉시 뜹니다. 방해 금지 시간·집중 타이머 중에도 뜹니다.
- 공지 목록에서는 **긴급공지** / **일반 공지** 탭으로 나뉘어 보이고, 긴급공지는 빨간 줄로 표시됩니다.

## 공지 쓰기
1. **공지 쓰기**를 누릅니다.
2. **등급**을 고릅니다.
3. **받는 사람(공개 범위)** 을 고릅니다.
   - **팀 전체** / **그룹**(내가 속한 그룹 중 선택) / **지정한 사람**(검색해서 선택)
4. **제목**과 **내용**을 입력합니다. 내용 편집기 도구 막대: 굵게, 기울임, 밑줄, 취소선, 소제목, 글머리 목록, 번호 목록, 체크리스트, 인용, 표 넣기, 되돌리기, 다시 실행. 이미지는 복사해서 붙여넣을 수 있습니다(1MB 이하).
5. 필요하면 **파일 첨부**를 누르거나 파일을 끌어다 놓습니다.
6. 선택 사항
   - **받는 사람의 "확인" 받기**: 받는 사람이 확인 버튼을 눌러야 합니다. **회신 항목**에 `참석, 불참`처럼 쉼표로 적으면 그 버튼들이 나옵니다.
   - **목록 맨 위에 고정**
   - **예약 발송**: 정한 시각에 자동으로 보냅니다.
   - **만료 시각**: 이 시각이 지나면 "만료"로 표시되고 재알림을 멈춥니다.
   - **자동 재알림 간격(긴급만)**: 확인하지 않은 사람에게 정한 간격(분)으로 다시 알림 창을 띄웁니다.
7. **게시**(긴급은 **긴급 발송**, 예약은 **예약 발송**)를 누릅니다.

## 수신 현황 (작성자·관리자)
내가 쓴 공지를 열면 아래에 **수신 현황**이 나옵니다.

- **안 읽음(미확인) / 읽음(확인함)** 탭으로 명단을 봅니다.
- 사람별로 **전달·읽음·확인 시각**과 **회신**이 표시되고, 녹색 점은 지금 접속 중인 사람입니다.
- 회신 항목이 있으면 항목별 인원이 아래에 합계로 나옵니다.
- **다시 알림**: 아직 읽지 않은(확인하지 않은) 사람에게만 다시 알립니다. 접속하지 않은 사람은 접속할 때 받습니다.
- **맨 위에 고정 / 고정 해제**, **삭제**를 할 수 있습니다.

## 방해 금지 시간
**설정 → 알림 → 방해 금지 시간**을 켜면 그 시간에는 중요·일반 알림이 뜨지 않습니다. 긴급 알림은 항상 뜹니다.
