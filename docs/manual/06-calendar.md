# 일정

## 화면
- 달력 위 **전체 / 개인 일정 / 공유 일정** 단추로 나눠 봅니다.
  - **개인 일정**: 내 PC에만 저장된 일정만. 다른 사람에게 보이지 않고 서버가 꺼져 있어도 쓰고 고칠 수 있습니다.
  - **공유 일정**: 서버에 저장되어 팀·부서·그룹·지정한 사람이 함께 보는 일정만.
  - **전체**: 둘을 함께(개인은 자물쇠 표시와 회색, 공유는 색깔).
- 위쪽 버튼으로 **월 / 주 / 일 / 목록** 보기를 바꾸고, 화살표 단추로 이동, **오늘**로 돌아옵니다.
- 일정 색깔
  - **회색 + 자물쇠 표시**: 내 PC에만 저장된 개인 일정 (다른 사람은 볼 수 없음)
  - **파란색**: 팀 전체 공유 일정
  - **그룹 색깔**: 그룹 공유 일정
  - **회색 [휴가] 이름**: 팀원의 부재 일정
  - **바쁨 · 이름**: 팀원이 시간만 알린 개인 일정
- 공휴일은 날짜 칸이 붉게 표시되고 이름이 나옵니다.
- **보기 대상**(오른쪽 위 목록): 전체 일정 / 내 일정만 / 개인 일정만 / 공유 일정만 / 특정 팀원의 일정
- 왼쪽 위 공간 전환(**팀 전체 ▾**)에서 그룹을 고르면 그 그룹 일정만 보입니다.

## 일정 만들기
1. **새 일정**을 누르거나, 달력의 날짜(또는 시간 칸)를 클릭합니다. 여러 날을 끌어서 고르면 그 기간으로 만들어집니다.
2. **종류**를 고릅니다.

| 종류 | 저장 위치 | 볼 수 있는 사람 |
|---|---|---|
| 개인 일정(자물쇠 표시) | 내 PC | 나만 |
| 공유 일정 | 서버 | 공개 범위(팀 전체·그룹·지정한 사람) + 참석자 |
| 부재 | 서버 | 팀 전체. 해당 시간 동안 팀원 현황에 **부재**로 표시 |

3. 제목, 시작·끝(종일이면 **종일** 체크)을 입력합니다. 날짜 칸을 누르면 달력이 열리고 날을 누르는 즉시 닫힙니다. 시각은 옆의 **시**·**분** 목록에서 고르면 바로 정해집니다(따로 누를 확인 단추가 없습니다).
4. 필요한 항목을 정합니다.
   - **반복**: 매일 / 평일 매일 / 매주(요일 선택) / 매월 / 매년, 간격, 종료(계속·날짜까지·횟수)
   - **알림**: 정시, 10분 전, 30분 전, 1시간 전, 1일 전 (여러 개 선택 가능)
   - **장소**, **내용**
   - 공유 일정: **공개 범위**, **참석자**
   - 부재: **부재 종류**(연가·반가·병가·공가·출장·교육 등). 부재 일정은 **근무현황** 메뉴에도 나타나며, 거기서 올려도 됩니다
   - 개인 일정: **팀원에게 바쁨으로만 표시** — 제목·내용은 내 PC에 두고 시간대만 팀원에게 "바쁨"으로 보여 줍니다.
5. **저장**을 누릅니다.

## 고치기·옮기기·지우기
- 공유 일정은 **쓴 사람**이 고치고 지웁니다. **서버 PC(최종관리자)** 는 모든 공유 일정을 보고 고치고 지울 수 있습니다(자기가 대상이 아닌 그룹·지정 일정도 달력에 보입니다). 서무는 자기에게 보이는 공유 일정을 고칠 수 있습니다.
- **개인 일정**은 각자 PC에만 있어 본인만 보고 고칩니다. 서버 PC도 볼 수 없습니다. 개인 일정의 "바쁨" 표시도 본인만 바꿉니다.
- 일정을 클릭하면 열립니다. 내가 만든 일정만 고칠 수 있고, 다른 사람 일정은 읽기 전용입니다.
- 일정을 **끌어서 다른 날·시간으로 옮기거나**, 아래 끝을 끌어서 길이를 바꿀 수 있습니다.
- 반복 일정을 고치거나 옮기거나 지우면 적용 범위를 묻습니다: **이 일정만 / 이 일정과 이후 일정 / 모든 반복 일정**

## 참석 회신
참석자로 지정된 공유 일정을 열면 **내 응답: 참석 / 불참 / 미정**을 고를 수 있습니다. 만든 사람은 참석자별 응답을 봅니다. 불참으로 응답한 일정은 알림이 오지 않습니다.

## 공유하기 / 개인 일정으로 옮기기
- **개인 일정 → 공유**: 개인 일정을 열고 **공유할 때의 공개 범위**를 고른 뒤 **공유하기**를 누릅니다. 서버에 올린 뒤 내 PC의 원본을 지울지 묻습니다.
- **공유 일정 → 개인**: 내가 만든 공유 일정을 열고 **개인 일정으로 옮기기**를 누릅니다. 내 PC에 복사한 뒤 서버 일정을 지울지 묻습니다.

## 알림
- 정한 시각에 Windows 알림이 뜹니다. TeamHub 창을 닫아(트레이) 두어도 뜹니다.
- PC가 절전 상태였다가 깨어나면 1시간 안에 놓친 알림을 보여 줍니다.

## 가져오기·내보내기·인쇄
- **일정 내보내기(.ics)**(아래 화살표 단추): 지금 보고 있는 기간의 일정을 `.ics` 파일로 저장합니다. Outlook·구글 캘린더 등에서 열 수 있습니다.
- **일정 가져오기(.ics)**(위 화살표 단추): `.ics` 파일의 일정을 **개인 일정**으로 가져옵니다.
- **인쇄**(프린터 단추): 지금 보이는 달력을 인쇄합니다. 월 보기에서 누르면 월간 일정표가 됩니다.

## 서버에 연결되지 않았을 때
개인 일정은 그대로 보고 만들 수 있습니다. 공유 일정은 마지막으로 받은 내용만 보이고, 새로 만들거나 고칠 수 없습니다.

## 공휴일 (관리자)
기본 공휴일이 들어 있습니다. 관리자는 **관리 → 공휴일**에서 기관 휴일을 추가하거나 고칠 수 있습니다.
