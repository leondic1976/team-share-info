# 관리대장

엑셀처럼 쓰는 대장(장부) 관리 화면입니다. 왼쪽 메뉴 **관리대장**. 물품·문서 수발신·예산 집행·차량 운행·대여·출장·교육 이수처럼 표로 관리하는 일이라면 무엇이든 열을 직접 정해 쓸 수 있습니다. 왼쪽에 대장 목록, 오른쪽에 표가 있습니다.

예전의 확장 기능 "스마트 대장"이 본 기능이 된 것입니다. 스마트 대장으로 만든 대장은 **개인용**에 그대로 있습니다.

## 대장의 종류
| 종류 | 저장되는 곳 | 볼 수 있는 사람 | 고칠 수 있는 사람 |
|---|---|---|---|
| 🔒 **개인용** | 이 PC의 로컬 DB | 나만 | 나 |
| 👥 **팀용** | 서버 DB | 팀 전체, 또는 고른 그룹의 구성원 | 볼 수 있는 사람 모두(또는 만든 사람·관리자만) |
| 👤 **지정자용** | 서버 DB | 만든 사람과 지정한 사람만 | 볼 수 있는 사람 모두(또는 만든 사람·관리자만) |

- 왼쪽 목록이 **개인용 / 팀용 / 지정자용** 세 묶음으로 나뉘어 있습니다. 묶음 이름을 누르면 접고 펼 수 있고, 오른쪽 숫자는 대장 개수입니다.
- 대장은 파일이 아니라 **DB에 행 단위로** 저장됩니다. 따로 정하지 않으면 개인용(이 PC의 로컬 DB)으로 만들어집니다.
- 팀용·지정자용 대장은 서버 백업에 포함됩니다. 개인용 대장은 이 PC에만 있으므로 설정 → **개인 데이터 내보내기**(전체)나 **다른 이름으로 저장**(대장 하나)으로 백업하세요.
- 서버에 연결되지 않은 동안에는 개인용 대장만 고칠 수 있습니다(팀용·지정자용은 마지막에 본 내용을 보기만 가능).
- 대장 하나에 **100,000행**, 200열까지 담습니다.

## 자동 저장
- 고치는 대로 저장됩니다(고친 행만 저장하므로 큰 대장도 빠릅니다). 대장 이름 옆에 **✓ 이 PC에 저장됨**(개인용) 또는 **✓ 서버에 저장됨**(팀용·지정자용)이 표시됩니다.
- **Ctrl**+**S**를 누르면 기다리지 않고 바로 저장합니다(누르지 않아도 저장됩니다).
- 다른 메뉴로 넘어가거나 프로그램을 닫아도 입력한 내용은 저장되어 있습니다.
- 서버에 저장하지 못하면 "서버에 저장하지 못함 · 다시 시도 중"이 표시되고, 연결되면 저절로 다시 저장합니다.

## 함께 쓰기 (팀용·지정자용)
- **여러 사람이 동시에 고칠 수 있습니다.** 누가 고치는 동안 기다릴 필요가 없고, 다른 사람이 고친 칸은 저장되는 대로 내 화면에 **바로** 나타납니다. 표 위 줄에 "OOO님이 방금 고침"이 표시됩니다.
- **같은 행의 다른 칸**을 두 사람이 고치면 둘 다 저장됩니다.
- **같은 칸**을 두 사람이 동시에 고치면 **먼저 저장된 값이 남습니다.** 나중 사람의 입력은 덮어쓰지 않고 그 사람의 **개인용 대장에 "(저장 못 한 내 변경)" 사본**으로 남기며, 알림으로 알려 줍니다. 사본에서 필요한 부분을 복사해 다시 넣으면 됩니다.
- 내가 칸에 입력하는 도중에 다른 사람이 그 칸을 고치면, Enter를 눌러도 덮어쓰지 않고 "입력하는 동안 다른 사람이 이 칸을 고쳤습니다"라고 알려 줍니다.
- 열 추가·삭제, 대장 이름·설명 변경도 두 사람이 동시에 하면 먼저 한 쪽이 반영됩니다.
- 다른 사람의 변경이 들어오면 내 **실행 취소**(Ctrl+Z) 기록은 비워집니다(남의 작업을 되돌리지 않도록). 크게 되돌려야 하면 **변경 이력**을 쓰세요.
- **새 변경 표시**: 다른 사람이 고친 뒤 아직 열어 보지 않은 대장은 목록에 **빨간 점**이, 왼쪽 메뉴 **관리대장**에 숫자가 표시됩니다. 대장이 나에게 새로 공유되면 Windows 알림이 옵니다.
- **더보기 → 볼 수 있는 사람 · 편집 권한**(만든 사람·관리자): 팀 전체 / 그룹 / 지정한 사람으로 바꾸거나, "만든 사람과 관리자만 고침(나머지는 보기 전용)"으로 바꿉니다.
- **더보기 → 팀용·지정자용으로 올리기**: 개인용 대장을 서버로 옮겨 함께 씁니다(이 PC의 것은 휴지통으로 가며, "개인용 대장에도 사본을 남기기"를 체크하면 남습니다).
- **더보기 → 개인용 대장으로 사본 받기**: 함께 쓰는 대장을 이 PC에 따로 복사합니다(사본은 나만 보고, 원래 대장과 따로 움직입니다).
- 개인정보(주민등록번호·연락처 등)가 들어 있는 대장은 지정자용으로 만들어 꼭 필요한 사람만 지정하세요.

## 변경 이력 (되돌리기)
표 위의 **🕘 변경 이력**. 대장의 예전 모습이 자동으로 보관됩니다.
- 보관되는 때: 대장을 **고치기 시작할 때**(10분 넘게 쉬었다가 다시 고칠 때마다 그 전 모습), **20행 이상이나 열을 한꺼번에 지울 때**, **되돌리기 직전**. **지금 모습 보관**으로 직접 남길 수도 있습니다.
- 대장마다 최근 **30개**까지 남습니다. 누가 언제 고치기 시작했는지도 함께 보입니다(팀용·지정자용은 관리 → 활동 기록에도 남습니다).
- **사본으로 열기**: 그 시점의 모습을 개인용 대장으로 엽니다(원래 대장은 그대로). 지워진 행 몇 개만 다시 가져올 때 좋습니다.
- **이 시점으로**: 대장 전체를 그 시점으로 되돌립니다. 지금 모습도 먼저 보관되므로 다시 돌아올 수 있습니다. 팀용·지정자용은 함께 쓰는 모든 사람의 화면이 바뀝니다(보기 전용인 사람은 되돌릴 수 없음).

## 휴지통
- **더보기 → 대장 삭제**를 하면 대장은 휴지통으로 갑니다. 왼쪽 아래 **🗑 휴지통**에서 **되살리기** 하거나 **완전히 삭제**합니다.
- 휴지통의 대장은 **30일** 뒤 자동으로 완전히 지워집니다(변경 이력 포함).
- 팀용·지정자용 대장은 만든 사람과 관리자만 지우고 되살릴 수 있습니다. 삭제하면 함께 쓰던 사람들의 목록에서 사라지고, 되살리면 다시 나타납니다.

## 대장 다루기
### 대장 만들기
- **+ 새 대장** → 이름을 적고, **개인용 · 팀용 · 지정자용** 중 하나를 고른 뒤 서식을 누릅니다. 팀용·지정자용은 이어서 볼 수 있는 사람과 편집 권한을 정합니다.

| 서식 | 들어 있는 열 (자동 계산) |

| 빈 대장 | 항목·내용·수량·비고 |
| 물품(비품) 관리 대장 | 관리번호·품명·규격·수량·단가·**금액**(=수량×단가)·취득일·위치·담당자·상태 |
| 문서 수발신 대장 | 구분·문서번호·일자·제목·상대 기관·담당자·처리 상태·처리일·**처리 기간**(일) |
| 예산 집행 대장 | 집행일·예산 과목·적요·거래처·집행액·**누적 집행액**·**잔액**·예산·증빙 |
| 차량 운행 일지 | 운행일·운전자·목적지·용무·출발/도착 거리·**운행 거리**·주유 |
| 대여·반납 대장 | 품목·대여자·대여일·반납 예정일·반납일·**상태**(대여중/반납/연체)·**연체 일수** |
| 출장 대장 | 출장자·출장지·시작일·종료일·**일수**·목적·여비·정산 |

- 처음 화면의 **개인용 · 팀용 · 지정자용** 카드를 눌러도 됩니다.
- **📥 파일에서 가져오기**(왼쪽 아래): 엑셀 파일(**.xlsx**, 첫 시트), **CSV**(엑셀의 한글 ANSI CSV도 읽음), 관리대장에서 저장한 **.json · .db** 파일을 개인용 대장으로 엽니다. 엑셀·CSV는 첫 줄이 열 이름이 되고 열 종류(숫자·날짜·체크)는 내용을 보고 정합니다. 옛 엑셀 파일(.xls)은 엑셀에서 .xlsx로 저장한 뒤 여세요.

| 복사·잘라내기·붙여넣기 | **Ctrl**+**C** / **X** / **V** — 엑셀과 서로 주고받을 수 있습니다. 붙여 넣을 행이 모자라면 행이 늘어납니다 |

- 날짜는 2026-03-05, 2026.3.5, 2026년 3월 5일 모두 됩니다. 숫자의 쉼표는 저절로 빠집니다.
- 열 종류와 맞지 않는 값(숫자 열에 글자 등)은 칸 아래에 빨간 줄이 생깁니다.
- 선택한 칸들의 **합계·평균·개수**가 아래 상태 줄에 나옵니다.

### 행과 열
- **+ 행**(맨 아래), **+ 열**(맨 오른쪽). 칸이나 행 번호를 **오른쪽 클릭**하면 위/아래에 행 넣기, 행 복제, 행 삭제.
- 열 머리글의 **▾**: 오름차순/내림차순 정렬, 거르기(필터: 값을 골라 그 행만 보기), 열 설정, 왼쪽/오른쪽에 열 넣기, 열 삭제. 머리글 오른쪽 끝을 끌면 너비가 바뀝니다.
- 필터나 찾기가 켜져 있으면 **필터 해제** 단추가 나옵니다. 합계 줄은 보이는 행만 셉니다.
- 정렬은 행 순서를 실제로 바꿉니다(실행 취소로 되돌리기).

### 열 설정 (머리글 ▾ → 열 설정, 또는 머리글 두 번 클릭)
| 항목 | 내용 |
|---|---|
| 종류 | 글자 · 숫자 · 날짜 · 목록에서 고르기(항목을 한 줄에 하나씩) · 체크 · 팀원(팀원 이름 목록) · 계산(수식) |
| 표시 형식 | 자동 · 정수(1,234) · 소수 1·2자리 · 원(1,234원) · 백분율 · 날짜 |
| 합계 줄 | 없음 · 합계 · 평균 · 최소 · 최대 · 개수(값 있는 칸) · 체크한 개수 |

열 이름을 바꾸면 그 열을 쓰는 수식도 함께 바뀝니다.

### 계산
- **계산 열**: 종류를 "계산(수식)"으로 하고 열 이름을 [ ]로 써서 식을 만듭니다. 모든 행에 같은 식이 적용되고, 아무것도 입력하지 않은 행에서는 비어 있습니다. 식을 넣으면 첫 행의 결과가 미리 보입니다.
  - 예: `=[수량]*[단가]` · `=IF([반납일]="","대여중","반납")` · `=[종료일]-[시작일]+1`(일 수) · `=ROUND([금액]*0.1,0)` · `=CUMSUM([집행액])`(첫 행부터의 누적)
- **칸 수식**: 어느 칸이든 `=`로 시작하면 수식입니다. 엑셀처럼 `A1`(열 글자+행 번호), `A1:C5`(범위), `$A$1`을 씁니다. 열 글자는 머리글 위쪽 작은 글자, 행 번호는 왼쪽 번호입니다. 수식이 든 칸은 왼쪽 위에 파란 삼각형이 표시됩니다.
- `[열 이름]`을 SUM 같은 함수 안에 쓰면 **그 열 전체**, 계산에 바로 쓰면 **같은 행의 값**입니다. `[@열 이름]`은 항상 같은 행입니다. 예: `=SUM([금액])`, `=[금액]/SUM([금액])`(비율).
- 날짜끼리 빼면 일 수입니다. 오늘은 `TODAY()`.
- 함수: SUM, AVERAGE, MIN, MAX, COUNT, COUNTA, COUNTBLANK, IF, IFERROR, AND, OR, NOT, ROUND, ROUNDUP, ROUNDDOWN, INT, ABS, MOD, POWER, SQRT, LEN, LEFT, RIGHT, MID, TRIM, UPPER, LOWER, CONCAT, TEXT, VALUE, TODAY, NOW, DATE, YEAR, MONTH, DAY, DAYS, DATEDIF, ISBLANK, ISNUMBER, ISERROR, SUMIF, COUNTIF, AVERAGEIF, VLOOKUP, MATCH, INDEX, ROW, CUMSUM. 설명은 대장 화면 왼쪽 아래 **사용법 · 함수**.
- 연산: `+ - * / ^`, 글자 잇기 `&`, 비교 `= <> < > <= >=`, 백분율 `%`.
- 오류 표시: `#DIV/0!`(0으로 나눔) `#VALUE!`(글자를 계산) `#REF!`(없는 칸·열) `#NAME?`(없는 함수) `#CYCLE!`(자기 자신을 참조) `#N/A`(찾는 값 없음) `#ERROR!`(식이 틀림).
- 정렬하면 행이 옮겨지므로 `A1` 주소를 쓰는 칸 수식은 다른 행을 가리킬 수 있습니다. 행마다 계산하는 식은 계산 열과 `[열 이름]`으로 만드세요.

### 다른 이름으로 저장 (파일로 내보내기)
표 위의 **💾 다른 이름으로 저장**(또는 **Ctrl**+**Shift**+**S**)을 누르고 형식을 고른 뒤 저장할 곳을 정합니다. 대장 자체는 계속 DB에 자동 저장되고, 여기서는 다른 프로그램에서 쓸 파일을 따로 만듭니다.

| 형식 | 쓰임 |
|---|---|
| **Excel 통합 문서 (.xlsx)** | 엑셀 2007 이상·한셀. 숫자는 숫자, 날짜는 날짜로 들어가고 표시 형식(1,234 · 원 · %)·열 너비·머리글 고정·자동 필터가 적용됩니다. 1,048,575행까지 |
| **Excel 97-2003 통합 문서 (.xls)** | 옛 엑셀용. 65,535행까지, 한 칸 4,000자까지 |
| **CSV (.csv)** | 쉼표로 나눈 글자 파일(UTF-8). 어느 프로그램에서나 열립니다 |
| **SQLite 데이터베이스 (.db)** | 표 `data`에 열 이름 그대로 저장됩니다. DB 도구로 조회할 수 있고, 관리대장에서 다시 가져오면 수식·열 설정까지 그대로 돌아옵니다 |
| **관리대장 파일 (.json)** | 수식·열 설정까지 그대로 담은 백업. 다른 PC로 옮길 때 |

- 수식은 **계산된 값**으로 저장됩니다(.json과 .db 안의 대장 정보는 수식 그대로).
- 찾기·필터로 일부 행만 보고 있으면 **보이는 행만 저장**을 고를 수 있습니다.

### 그 밖의 기능 (더보기)
- **표 전체 복사**: 엑셀에 바로 붙여 넣기(20,000행까지). **인쇄**: 표만 인쇄합니다(20,000행까지).
- **대장 복제**, **대장 설명 쓰기**(표 위에 메모), **대장 삭제**(휴지통으로).

### 큰 대장을 쓸 때
- 수만 행도 화면에는 보이는 부분만 그리므로 스크롤과 입력이 가볍습니다. **Ctrl**+**End**로 맨 끝, **Ctrl**+**Home**으로 맨 처음으로 갑니다.
- `=[수량]*[단가]`처럼 **같은 행만 쓰는 계산 열**은 고친 행만 다시 계산합니다. `=SUM([금액])`, `=CUMSUM([집행액])`처럼 **열 전체를 읽는 계산 열**이나 `A1` 주소를 쓰는 칸 수식이 있으면 입력할 때마다 전체를 다시 계산하므로, 행이 수만 개가 되면 느려질 수 있습니다. 합계는 **합계 줄**(열 설정)을 쓰는 편이 빠릅니다.
- 대장을 여는 시간과 메모리는 행 수에 비례합니다. 해마다·분기마다 대장을 나누면 더 가볍게 쓸 수 있습니다.

### 보기 공유 (개인용 대장의 사본)
개인용 대장을 옮기지 않고 지금 내용만 보여 주고 싶을 때 씁니다. 함께 고치려면 팀용·지정자용으로 올리세요.
- **더보기 → 팀원에게 보기 공유 (사본)** → 팀 전체 또는 고른 팀원 → **공유하기**. 지금 **보이는 행의 값**이 사본으로 서버에 올라가고 받는 사람에게 알림이 갑니다(64KB까지 — 큰 표는 팀용·지정자용으로 올리세요).
- 받는 사람은 **공유받은 대장**에서 **보기**(보기 전용)를 누르고, 필요하면 **내 대장으로 복사**(계산식은 값으로 바뀜)합니다.
- 표를 고친 뒤에는 다시 **공유 갱신**을 눌러야 받는 사람 화면이 바뀝니다. **공유 그만하기**로 서버의 사본을 지웁니다.
