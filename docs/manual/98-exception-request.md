# 보안프로그램 예외 등록 요청서 (관리자)

백신·PC 보안 프로그램이 TeamHub 설치·실행·통신을 막으면 전산(보안) 담당자에게 예외 등록을 요청합니다.

## 요청서 받기
- 서버 PC가 켜져 있으면 브라우저에서 `http://서버IP:포트/download`를 엽니다. 아래쪽 **예외 등록 요청서**에 버전·해시·서버 주소·포트가 채워져 있습니다. **인쇄·PDF**로 저장해 보냅니다.

## 요청서 항목
| 항목 | 내용 |
|---|---|
| 프로그램 이름 | TeamHub (팀 정보 공유 업무 보조 프로그램) |
| 버전 · 설치 파일 | `TeamHub-Setup-버전.exe` |
| 설치 파일 해시 | SHA-512(base64). 다운로드 사이트의 `updates/latest.yml` 또는 `/download` 페이지에 표시 |
| 실행 파일 위치 | `%LOCALAPPDATA%\Programs\TeamHub\TeamHub.exe` (사용자별 설치, 관리자 권한 불필요) |
| 데이터 위치 | `%APPDATA%\TeamHub` (개인 데이터), 서버 PC는 설정한 데이터 폴더 |
| 서버 PC와 팀원 PC 사이 | TCP 47800(바꾼 경우 그 포트) — HTTP·WebSocket, 사내망 |
| 서버 찾기 | UDP 47801 — 같은 네트워크 방송 |
| 화상회의 | PC끼리 직접 UDP(WebRTC), 사내망 안, 외부 서버 없음 |
| 서버 PC 방화벽 | 받는 방향 TCP 47800, UDP 47801 허용 |
| 인터넷(선택) | 업데이트·확장 기능 목록·게시판 차단 목록: `https://leondic1976.github.io/team-share-info/` (폐쇄망은 사용 안 함) |
| 인터넷(선택) | 기능요청·오류신고 보내기: `https://api.github.com` (설정에서 글을 보낼 때만. 서버 PC만 허용해도 팀원 PC의 글이 서버 PC를 거쳐 나갑니다) |
| 인터넷(선택) | 확장 기능 다운로드 수 표시·집계: `https://abacus.jasoncameron.dev` (확장 기능 화면을 열 때와 확장 기능 모음에서 설치할 때. 확장 기능 ID만 보냄. 막혀 있으면 횟수만 보이지 않고 나머지는 그대로 동작) |
| 코드 서명 | 설치 파일 속성 → **디지털 서명** 탭에 서명이 있으면 서명된 판입니다. 서명이 없는 판은 해시로 같은 파일인지 확인 |
| 개인정보 | 개인 메모·다이어리·보안 점검 결과는 각자 PC에만 저장. 중요 보안 내용·개인정보·비공개 정보 공유 금지 안내 상시 표시 |

## 백신·Windows가 바이러스·랜섬웨어로 표시할 때

TeamHub는 악성 프로그램이 아닙니다. 코드 서명이 없는 설치 파일은 보안 프로그램이 "처음 보는 실행 파일"로 보고 막는 일이 있습니다(오진). 아래 순서로 조치합니다.

| 화면에 나오는 것 | 조치 |
|---|---|
| **Windows의 PC 보호**(SmartScreen) | **추가 정보** → **실행** |
| Windows 보안 "위협 발견"으로 설치 파일이 지워짐 | Windows 보안 → 바이러스 및 위협 방지 → **보호 기록**에서 항목을 열어 **허용**(또는 복원)한 뒤 다시 설치 |
| "랜섬웨어 방지 · 보호된 폴더 액세스 차단" | Windows 보안 → 랜섬웨어 방지 관리 → **제어된 폴더 액세스를 통해 앱 허용** → `%LOCALAPPDATA%\Programs\TeamHub\TeamHub.exe` 추가 |
| V3·알약 등 백신이 설치·업데이트를 막음 | 백신의 **예외(검사 제외)** 에 `%LOCALAPPDATA%\Programs\TeamHub` 폴더와 `%LOCALAPPDATA%	eamhub-updater` 폴더를 추가. 기관 PC는 전산 담당자에게 위 요청서로 요청 |

오진 신고(한 번 처리되면 그 버전은 모든 PC에서 풀립니다. 설치 파일과 진단명을 함께 보냅니다):

| 보안 프로그램 | 신고하는 곳 |
|---|---|
| Windows 보안(Microsoft Defender) | `https://www.microsoft.com/wdsi/filesubmission` → Software developer → "Incorrectly detected" |
| V3(안랩) | 안랩 홈페이지 → 고객지원 → 오진 신고 |
| 알약(이스트시큐리티) | 알약 홈페이지 → 고객센터 → 오진 신고 |

이 버전부터 오진을 줄이려고 바꾼 것: 권한 상승 도우미(`elevate.exe`)를 설치 파일에서 뺌, 업데이트할 때마다 바탕 화면 바로가기를 다시 만들지 않음, 외부 IP 확인 사이트(`api.ipify.org`)에 접속하지 않음, 숨긴 창·실행 정책 무시 옵션으로 PowerShell을 실행하지 않음.
