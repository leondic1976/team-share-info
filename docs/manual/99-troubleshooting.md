# 문제 해결

| 증상 | 확인할 것 |
|---|---|
| 자동으로 찾은 서버 목록이 비어 있음 | 서버 PC가 켜져 있고 TeamHub가 실행 중인지 확인합니다. 네트워크가 다르거나 방화벽이 막으면 찾지 못합니다. 서버 주소를 직접 입력하세요. |
| **연결 확인**에서 "서버에 연결할 수 없습니다" | ① 주소·포트 확인 ② 서버 PC에서 **설정 → 서버 연결**의 서버 상태가 "실행 중"인지 확인 ③ 서버 PC에서 **방화벽 규칙 다시 등록** ④ 서버 PC의 Windows 네트워크 프로필이 "공용"이면 "개인"으로 바꿉니다. |
| 위쪽에 빨간 "서버 꺼짐 · 오프라인", 하단에 "서버 연결 끊김" | 서버 PC가 꺼졌거나 절전 상태입니다. 보관된 내용은 그대로 보이고 새로 쓴 글은 보관했다가 보냅니다(도움말 개요 "서버가 꺼져 있을 때"). 서버가 다시 켜지면 몇 초 안에 자동으로 연결됩니다. 서버 PC의 IP가 바뀌면 같은 네트워크에서는 스스로 다시 찾고, 찾지 못하면 **설정 → 서버 연결 → 서버 다시 찾기**를 누릅니다. |
| "사용이 중지되었습니다" 화면 | 관리자가 이 PC 또는 구성원 사용을 중지했습니다. 관리자에게 문의하거나 **처음부터 다시 신청**을 누릅니다. |
| "업데이트가 필요합니다" 화면이 계속됨 | 화면에 나오는 까닭을 확인합니다. 자동 업데이트가 안 되면 브라우저에서 `http://서버주소/download` 로 설치 파일을 받아 다시 설치합니다. 개인 데이터는 유지됩니다. |
| 설정 → 업데이트에 "서버 PC의 업데이트를 기다리는 중입니다" | 정상입니다. 팀원 PC는 서버 PC보다 새 버전을 설치하지 않습니다. 최종관리자에게 서버 PC의 업데이트를 부탁하세요. 서버 PC가 업데이트되면 다음 확인 때(다시 연결될 때나 30분마다) 저절로 받습니다. |
| "업데이트가 필요합니다" 화면에 "서버 PC가 아직 1.a.b입니다" | 이 PC가 쓸 수 있는 버전이 아직 서버 PC에 없습니다. 서버 PC가 업데이트하면 자동으로 받습니다. 서둘러야 하면 브라우저에서 `http://서버주소/download` 의 설치 파일로 설치합니다. |
| 설정 → 업데이트에 "확인하지 못했습니다" | 함께 나오는 까닭을 봅니다. 연결 문제면 인터넷·서버 연결을, "설치 파일을 저장하지 못했습니다"면 보안 프로그램이 막는지 확인합니다. **지금 확인**으로 다시 시도합니다. |
| **설치(다시 시작)** 을 눌렀는데 설치되지 않음 | 15초 안에 설치가 시작되지 않으면 프로그램이 그대로 계속 실행되고 까닭이 설정 → 업데이트에 나옵니다. 보안 프로그램이 설치 파일을 지웠으면 자동으로 다시 받습니다. 계속 안 되면 다운로드 사이트나 `http://서버주소/download` 에서 설치 파일을 받아 설치합니다. |
| 승인 대기 화면에서 진행되지 않음 | 관리자가 **관리 → 승인 관리**에서 승인해야 합니다. 신청 내용이 잘못됐으면 **신청 취소하고 처음으로**를 누르고 다시 신청합니다. |
| 서버 PC를 바꿔야 함 | 기존 서버의 데이터 폴더를 새 PC로 옮기는 **서버 이전** 기능을 사용합니다(관리 → 백업). |
| 백신·Windows가 설치 파일을 바이러스·랜섬웨어로 표시 | 오진입니다. 도움말 **보안프로그램 예외 등록 요청서**의 "백신·Windows가 바이러스·랜섬웨어로 표시할 때"를 따라 허용·예외 등록·오진 신고를 합니다. |
| 서버가 꺼져 있을 때 어떤 화면이 비어 있음 | 서버에 연결된 동안 한 번도 받아 두지 못한 내용입니다. 서버에 연결되어 있으면 주요 화면을 10분마다 받아 두므로, 서버가 켜져 있을 때 TeamHub를 잠시 켜 두면 다음부터 보입니다(도움말 개요 "서버가 꺼져 있을 때"). |
| "이 화면을 여는 중에 오류가 났습니다" | 그 화면에서만 난 오류입니다. 다른 메뉴는 그대로 쓸 수 있습니다. **다시 시도**를 누르거나 다른 메뉴로 갔다가 돌아옵니다. 계속되면 화면에 나온 오류 내용을 **설정 → 기능요청 및 오류신고**로 알려 주세요. |
| 알림 소리("팀뿌요~")가 나지 않거나 알림 카드가 뜨지 않음 | **설정 → 알림**의 **알림 소리**·**알림 미리보기**가 켜져 있는지, **방해 금지 시간**이나 **집중 타이머** 중이 아닌지, 그 대화방의 알림을 끄지 않았는지 확인합니다. 소리는 Windows 음량과 한국어 음성을 씁니다(**들어 보기**로 확인). 지금 보고 있는 대화방의 메시지는 알리지 않습니다. |
| 알림 카드가 보이는데 X나 카드를 눌러도 반응이 없음 | 카카오톡 같은 다른 프로그램의 알림 창이 같은 자리에 겹쳐 클릭을 가로챈 경우입니다. 카드 위에 마우스를 올리면 TeamHub 카드가 다시 맨 위로 올라오니 그다음 누릅니다. 1.11.1부터 카드는 다른 프로그램의 알림이 모이는 오른쪽 아래를 피해 오른쪽 위에 뜹니다. 그 전 버전이면 업데이트하세요. |
| 위쪽 연결 단추의 **보낼 것**이 줄지 않음 | 서버에 연결되어 있는지 확인하고 단추를 눌러 **지금 보내기**를 누릅니다. "보내지 못함"은 서버가 거절한 것이므로 까닭을 보고 **다시** 또는 지우기를 누릅니다. |
| 자료가 사라졌거나 잘못 지웠을 때 | 개인 자료(다이어리·메모·노트·개인 일정·알람 등)는 **설정 → 내 자료 백업 · 복구**의 백업 목록에서 지우기 전 날짜의 백업을 골라 **이 백업으로 복구**를 누릅니다(지금 자료는 "복구 직전" 백업으로 남습니다). 공용 PC에서 잘못 지운 사용자는 30일 안에 PC 책임자가 **설정 → 공용 PC 사용 → 지운 사용자 (30일 보관)** 의 **복구**로 되돌립니다. 공지·자료실·대화 같은 팀 자료는 서버에 있으므로 관리자에게 문의합니다(관리 → 백업·복구). |
| 공용 PC에서 TeamHub가 갑자기 사용자 선택 창으로 돌아감 | **자동 로그아웃**입니다. 공용 PC에서는 정해진 시간(기본 10분) 동안 PC를 쓰지 않거나 Windows를 잠그면 로그아웃됩니다. 1분 전에 뜨는 **자동 로그아웃 알림** 창에서 **계속 사용**을 누르면 취소됩니다. 로그아웃되면 저장하지 않은 내용은 사라지니 자리를 뜨기 전에 저장하세요. 시간은 PC 책임자가 **설정 → 공용 PC 사용**의 **자동 로그아웃 시간**(3~60분)에서 바꿉니다. |
| 문의할 때 알려 줄 정보 | **설정 → 프로그램 정보**의 버전, PC 이름, Windows 계정 |
