# TeamHub 개요

TeamHub는 팀원끼리 일정·공지·자료·메시지를 주고받는 Windows용 업무 보조 프로그램입니다. 팀원 PC 중 **한 대가 서버**가 되고, 나머지 팀원은 그 서버 PC의 IP 주소로 접속합니다. 인터넷 없이 사내망만으로 동작합니다.

> **주의** 중요 보안 내용, 개인정보, 비공개 정보는 공유할 수 없습니다. 이 안내는 화면 맨 아래에 항상 표시됩니다.

## 화면 구성

| 위치 | 내용 |
|---|---|
| 상단 바 | 프로그램 이름, 기관 · 팀명 › 지금 보고 있는 그룹, 통합 검색(Ctrl+K), Windows 창 버튼 |
| 왼쪽 메뉴 | 함께 쓰는 기능(홈, 공지, 일정, 자료실, 회의, 메신저, 게시판, 근무현황, 자료 취합, 조직도, 주소록, 식사 신청, 기록, 그 아래 빨간 글씨의 **긴급구조지휘대**), **개인용 · 내 PC에만 저장** 구분선 아래에 내 PC의 개인 기능(다이어리, 메모, 알람, 지식 노트, 내 파일, 런처, 유틸리티, 확장 기능. 확장 기능 아래에 관리대장과 설치한 확장 기능) / 아래쪽에 관리(관리자만), 설정, 도움말 |
| 가운데 | 선택한 메뉴의 화면 |
| 하단 표시줄 1줄 | 안내문(관리자가 정한 문구) |
| 하단 표시줄 2줄 | 기관·팀명 │ 내 이름 │ 서버 연결 상태 │ 프로그램 버전 |

- 왼쪽 메뉴 아래의 **메뉴 접기**를 누르면 아이콘만 표시됩니다.
- 메뉴 이름 오른쪽의 자물쇠 표시는 **내 PC에만 저장되는 개인 기능**입니다.
- **확장 기능**은 자주 쓰도록 굵은 강조색 글씨로 표시되고, 그 아래 항목은 안내선으로 묶여 있습니다. **긴급구조지휘대**는 빨간 굵은 글씨입니다.
- 메뉴 순서와 숨기기는 **설정 → 메뉴 편집**에서 바꿉니다.
- 화면 하나에서 오류가 나면 그 화면에만 "이 화면을 여는 중에 오류가 났습니다"와 **다시 시도**가 나옵니다. 다른 메뉴는 그대로 쓸 수 있습니다.

## 이 설명서 보는 법
- **팀원 모두**: 1~20장(각 메뉴 사용법), 90장(설정), 99장(문제 해결).
- **관리자(최종관리자 = 서버 PC, 서무 = 최종관리자가 지정한 사람)**: 2장의 서버 설정, 91장(관리), 98장(보안프로그램 예외 등록 요청서).
- 어느 화면에서든 **F1**을 누르면 이 도움말이 열립니다. 위쪽 검색창에 낱말을 넣어 찾습니다.

## 통합 검색 (Ctrl+K)
1. 상단 가운데 **검색**을 누르거나 **Ctrl+K**를 누릅니다.
2. 낱말을 입력하면 메뉴 이름(예: 근무현황, 주소록), 공지·일정·기록·게시판·자료실·메신저·주소록·구성원·업무일지(공유 자료, 내가 볼 수 있는 것만)와 내 메모·다이어리·지식 노트·내 파일·사이트 모음(개인 자료, 이 PC)이 함께 나옵니다.
3. ↑↓로 고르고 Enter, 또는 누르면 그 화면이 열립니다. Esc는 닫기입니다.
- 서버에 연결되지 않았을 때는 내 PC 자료만 찾습니다.

### 초성으로 찾기
- 한글은 **첫 자음(초성)** 만 입력해도 찾습니다. `ㄱㅁㅎㅎ`는 **근무현황**, `ㅎㄱㄷ`는 **홍길동**을 찾습니다.
- 글자와 초성을 섞어도 됩니다: `홍ㄱㄷ`, `ㅎ길ㄷ`도 **홍길동**을 찾습니다.
- 된소리는 자판에서 누른 그대로 구분합니다. `ㄲ`는 **까·꼬**처럼 ㄲ으로 시작하는 글자만 찾고, `ㄱ`는 ㄱ으로 시작하는 글자만 찾습니다.
- 초성 검색은 **이름과 제목**에서만 찾습니다(메뉴 이름, 공지·일정·기록·게시판 글 제목, 자료실 파일 이름, 구성원 이름·직위, 부서 이름, 주소록 연락처 이름·기관, 지식 노트 제목, 사이트 이름). 글의 본문과 메시지 내용은 낱말을 그대로 입력해야 찾습니다.
- 같은 방법이 다음 검색칸에서도 됩니다: 주소록(구성원·연락처), 조직도, 받는 사람·참석자 고르기 창, 부서 고르기, 메신저 대화방 찾기, 근무현황 기록, 자료실 파일 이름, 게시판·기록 검색(제목), 런처(작은 런처 창, 프로그램, 최근 문서, 사이트 모음).

## 서버 연결 상태

화면 **맨 위 왼쪽(팀 이름 옆)** 의 색 단추와 맨 아래 줄에 지금 서버와 연결되어 있는지 늘 표시됩니다.

| 위쪽 단추 | 아래 줄 | 의미 |
|---|---|---|
| 초록 **서버 연결됨** | ● 서버 연결됨 | 정상입니다. 바뀐 내용이 바로 반영됩니다. |
| 노랑 **서버 연결 중** | ● 서버 연결 중 | 접속을 시도하고 있습니다. |
| 빨강 **서버 꺼짐 · 오프라인** | ● 서버 연결 끊김 · 보관된 내용 표시 중(자동 재접속) | 서버 PC가 꺼졌거나 네트워크가 끊겼습니다. 몇 초마다 자동으로 다시 접속합니다. |
| 빨강 | ● 승인 대기 중 / 사용 중지됨 / 업데이트 필요 | 사용 신청 승인을 기다리는 중 / 관리자가 이 PC의 사용을 중지함 / 새 버전을 설치해야 함 |

위쪽 단추를 누르면 서버 주소, **지금 다시 연결**, **보낼 것**(아래), 팀원 PC에서는 **다른 서버**가 나옵니다. 단추 안의 숫자는 보내려고 보관해 둔 글의 개수입니다.

## 서버가 꺼져 있을 때

서버 PC가 꺼져 있어도 프로그램을 그대로 쓸 수 있습니다.

**볼 수 있는 것** — 서버가 켜져 있을 때 열어 본 공지·일정·자료 목록·메신저 대화(대화방마다 마지막 200개)·쪽지·게시판·기록·주소록·조직도·근무현황 등은 이 PC에 보관되어 그대로 보입니다. 서버에 연결되어 있는 동안 프로그램이 주요 화면(메신저 최근 대화 20개의 마지막 메시지, 받은 쪽지, 공지와 최근 공지 20건의 본문, 게시판 글 목록, 자료실 첫 화면, 기록 목록, 근무현황 이번 주·이번 달, 일정 앞뒤 몇 달, 식사 신청)을 10분마다 조용히 받아 두므로, 열어 본 적 없는 화면도 볼 수 있습니다(게시글 본문은 조회 기록이 남기 때문에 미리 받지 않습니다). 확장 기능(맛집 추천·설문조사·비품관리대장 등)도 열어 본 내용은 그대로 보입니다(보기만 가능). 서버가 꺼져 있는 동안에는 팀원의 접속 상태를 알 수 없어 모두 오프라인으로 표시됩니다. 60일 동안 다시 받지 못한 내용은 지워집니다.

**새로 쓸 수 있는 것** — 아래는 서버가 꺼져 있어도 쓸 수 있습니다. 쓴 글은 이 PC에 보관되고(위쪽 단추에 숫자 표시), 서버가 켜지면 쓴 순서대로 **자동으로 보냅니다.**

| 화면 | 서버가 꺼져 있어도 되는 것 |
|---|---|
| 메신저 | 글 메시지 보내기(대화방에 "서버 연결 시 전송"으로 표시), 쪽지 쓰기, 공유 메모 남기기 |
| 게시판 | 글쓰기(첨부 파일 없이), 댓글 |
| 공지 | 공지 쓰기 |
| 일정 | 새 공유 일정 |
| 다이어리 → 업무일지 | 업무일지 저장 |
| 근무현황 | 부재 올리기 |

**서버에 연결되어야 하는 것** — 이미 있는 글 고치기·지우기, 파일 올리기·내려받기, 읽음·확인 표시, 회의, 관리 메뉴. 두 사람이 떨어져서 같은 글을 고치면 한쪽 내용이 사라지기 때문에 막아 둡니다.

**보낼 것 확인** — 위쪽 연결 단추를 누르면 **보낼 것** 목록이 나옵니다.
- 휴지통 단추: 보내지 않고 지웁니다.
- "보내지 못함"으로 나오는 것은 서버가 거절한 것입니다(예: 그 사이 게시판이 없어짐). 까닭을 보고 **다시**를 누르거나 지웁니다.
- 같은 글이 두 번 올라가지 않습니다(보낸 뒤 응답을 못 받아 다시 보내도 서버가 한 번만 처리).

**보관되는 내용의 보호**
- 보관한 서버 내용과 보낼 글은 **암호화**해서 저장합니다. 열쇠는 Windows 계정에 묶여 있어, 파일을 다른 PC나 다른 Windows 계정으로 가져가면 읽을 수 없습니다.
- 그 PC를 쓰는 본인(구성원) 것만 보입니다. 관리 메뉴의 내용(구성원 PC 정보·활동 기록·설정)은 보관하지 않습니다.
- 관리자가 이 PC를 **차단**하면 보관된 서버 내용이 지워집니다. **설정 → 서버 연결 → 연결 초기화** 때도 지워집니다.
- 개인 기능(자물쇠 표시)은 서버와 상관없이 모두 씁니다.

**서버 PC의 주소가 바뀌었을 때** — 팀원 PC가 같은 네트워크에서 서버를 스스로 다시 찾아 새 주소로 접속합니다(같은 팀 서버인지 확인한 뒤). 찾지 못하면 **설정 → 서버 연결 → 서버 다시 찾기**를 누릅니다.

## 여러 서버(팀)에 접속하기 — 팀원 PC

팀원 PC 한 대로 여러 서버(팀)를 쓸 수 있습니다. **한 번에 한 서버**를 쓰고, 위쪽 연결 단추에서 바꿉니다.

1. 위쪽 연결 단추 → **다른 서버 추가** → 처음 화면에서 **서버에 접속** → 새 서버 주소로 사용 신청 → 그 서버 관리자가 승인.
2. 서버 바꾸기: 위쪽 연결 단추 → **다른 서버**에서 고릅니다. 다시 승인받지 않습니다.
3. 접속 정보 지우기: 목록의 휴지통 단추. 그 서버에서 보관해 둔 내용도 함께 지워집니다.

- 서버마다 따로 승인받고, 보관된 내용·보낼 글도 서버별로 따로 둡니다(섞이지 않음).
- 지금 쓰지 않는 서버의 알림(공지·메시지)은 그 서버로 바꿨을 때 받습니다.
- 개인 기능(자물쇠 표시)의 자료는 서버와 상관없이 하나입니다.
- 서버용 PC는 다른 서버에 접속할 수 없습니다.

## 데이터 저장 위치

| 구분 | 저장 위치 | 볼 수 있는 사람 |
|---|---|---|
| 개인 기능(자물쇠 표시): 개인 일정, 다이어리, 메모, 알람, 상용구, 지식 노트, 내 파일의 태그·가상 폴더·검색 색인, 사이트 모음, 런처 개인 항목, PC 점검 결과 | **내 PC** | 나만 |
| 공유 기능: 공지, 팀·그룹 일정, 자료실, 메신저, 게시판, 기록 문서 | **서버 PC** | 공개 범위에 해당하는 팀원 |

- 새로 만드는 항목은 기본이 **개인(내 PC)** 입니다. **공유**를 눌러 공개 범위를 골라야 서버로 올라갑니다.
- 서버 관리자도 다른 사람 PC의 개인 데이터는 볼 수 없습니다.

## 알림

- 메시지·쪽지·공지·새 일정·일정 알림·알람·기록·관리대장·확장 기능·사용 신청 등 프로그램의 알림은 모두 화면 오른쪽 위(창의 닫기 단추 바로 아래)에 **알림 카드**로 뜹니다. 이때 알림음과 함께 **"새로운 메시지 도착입니다"**(메시지·쪽지) 또는 **"새로운 알림 도착입니다"**(그 밖의 알림)라고 알려 줍니다. TeamHub 창을 닫아 트레이에 두어도 뜹니다.
- 카드는 누르거나 X(여러 장이면 **모두 닫기**)로 닫을 때까지 남아 있고, 누르면 그 화면이 열립니다. 잠금 PIN으로 잠겨 있을 때는 내용 없이 "새 알림이 있습니다"만 보입니다.
- 긴급공지는 카드가 아니라 화면 가운데 빨간 창과 경보음으로 알립니다(공지 장).
- 소리·카드 켜고 끄기, 방해 금지 시간은 **설정 → 알림**에서 정합니다.

## 창 닫기와 종료

- 창의 **✕(닫기)** 를 누르면 프로그램이 종료되지 않고 **작업 표시줄 오른쪽 알림 영역(트레이)** 으로 숨겨집니다. 알림은 계속 받습니다.
- 트레이 아이콘을 클릭하면 창이 다시 열립니다. 읽지 않은 알림이 있으면 아이콘에 빨간 점이 표시됩니다.
- 완전히 끝내려면 트레이 아이콘을 오른쪽 클릭 → **종료**를 누릅니다.
- 프로그램은 한 번만 실행됩니다. 이미 실행 중일 때 다시 실행하면 기존 창이 앞으로 나옵니다.
