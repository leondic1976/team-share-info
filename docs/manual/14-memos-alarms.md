# 메모 · 알람 · 업무 도구

혼자 쓰는 도구입니다. 모두 이 PC에만 저장되고 다른 사람에게 보이지 않습니다. 서버에 연결되지 않아도 쓸 수 있습니다. 팀원에게 남기는 **공유 메모**와 **팀원 알람**은 **메신저** 메뉴로 옮겼습니다(메신저 장 참고).

## 메모
왼쪽 메뉴 **메모 → 내 메모**.

### 쓰기와 정리
1. 검색창 옆 **+**(새 메모)를 누릅니다.
2. 오른쪽에 내용을 씁니다. 입력하는 대로 저장됩니다(오른쪽 위 "저장됨").
3. 도구 모음의 **체크리스트**로 할 일 목록을, **표 넣기**로 표를 만듭니다. 이미지는 복사해서 붙여넣습니다(1MB 이하).
4. 색상 동그라미로 색을 고르고, **고정**을 누르면 목록 맨 위에 둡니다.
5. **태그**에 쉼표로 구분해 입력합니다(예: 전화, 회의). 목록 위 태그를 누르면 그 태그의 메모만 보입니다.
6. 검색창은 내용과 태그를 함께 찾습니다.

### 다른 기능으로 옮기기
메모 아래 **이 메모를** 줄의 버튼을 누릅니다.

| 버튼 | 결과 |
|---|---|
| 할 일로 | 첫 줄을 제목으로 내 할 일(🔒)에 추가 |
| 일정으로 | 오늘 날짜의 개인 일정(종일)으로 추가 |
| 알람으로 | 첫 줄을 이름으로 알람 추가 창을 엶 |
| 다이어리로 | 오늘 다이어리 끝에 내용을 덧붙임 |

### 스티커 메모 (바탕화면에 붙이기)
1. 메모를 열고 **바탕화면에 붙이기**를 누르면 작은 메모 창이 바탕화면에 붙습니다.
2. 위쪽 띠를 끌어 옮기고, 가장자리를 끌어 크기를 바꿉니다.
3. 위쪽 버튼:

| 버튼 | 기능 |
|---|---|
| 색 동그라미 | 메모 색 바꾸기 |
| ☑ | 체크리스트 넣기 |
| 📌 | 항상 위(다른 창보다 위에 표시) 켜기·끄기 |
| ↗ | TeamHub 메모 화면 열기 |
| ✕ | 바탕화면에서 떼기(메모는 목록에 남음) |

- 프로그램을 껐다 켜도 스티커 메모는 같은 자리·크기로 다시 나타납니다.

### 빠른 메모 (Ctrl+Alt+M)
- 어느 화면에서든 **Ctrl+Alt+M**을 누르면 빠른 메모 창이 뜹니다. 트레이 아이콘 메뉴의 **빠른 메모**나 메모 화면의 **빠른 메모** 버튼으로도 엽니다.
- 적고 **Ctrl+Enter**(또는 **저장**)를 누르면 메모로 저장되고 창이 닫힙니다. **Esc**는 저장하지 않고 닫습니다.
- **바탕화면에 붙이기**를 체크하고 저장하면 바로 스티커 메모가 됩니다.
- 다른 프로그램이 Ctrl+Alt+M을 이미 쓰고 있으면 단축키가 동작하지 않습니다. 이때는 트레이 메뉴를 씁니다.

## 상용구
**메모 → 상용구**. 인사말·안내 문구·결재 문안·주소처럼 자주 쓰는 문구를 저장해 둡니다.
1. **상용구 추가** → 이름, 분류(선택), 문구 입력 → **저장**.
2. **복사**를 누르면 클립보드에 들어갑니다. 붙여넣을 곳에서 **Ctrl+V**를 누릅니다.

## 클립보드 기록
**메모 → 클립보드 기록**. 처음에는 꺼져 있습니다.
1. **클립보드 기록 사용**을 켜면 그때부터 복사한 글·이미지를 최근 100개까지 보관합니다.
2. 목록의 **복사**를 누르면 다시 클립보드에 들어갑니다.
3. **프로그램 종료 시 기록 삭제**를 켜면 TeamHub를 끝낼 때 기록이 지워집니다. **모두 지우기**로 언제든 지웁니다.
- 비밀번호 같은 내용을 복사할 때는 기록을 꺼 두세요.

## 화면 캡처
1. 메모 화면의 **화면 캡처** 또는 트레이 메뉴 **화면 캡처**를 누릅니다.
2. Windows 캡처 도구가 뜨면 영역을 끌어 지정합니다.
3. TeamHub에 캡처 창이 뜹니다.

| 버튼 | 결과 |
|---|---|
| 메모로 저장 | 캡처 그림이 든 메모(태그 "캡처")를 만듦 |
| 메신저에 붙여넣기 | 메신저를 엶. 대화방 입력창에서 Ctrl+V |
| 파일로 저장 | PNG 파일로 저장. 자료실에 끌어다 올릴 수 있음 |

- 캡처한 그림은 클립보드에도 들어 있어 한글·워드·메일 등에 Ctrl+V로 붙여넣을 수 있습니다.

## 알람
왼쪽 메뉴 **알람**. 내 알람은 이 PC에서만 울립니다. 울리면 화면 오른쪽 아래에 알람 창이 뜨고 소리가 납니다.

### 알람 종류
| 종류 | 설정 | 울리는 때 |
|---|---|---|
| 한 번 | 울릴 일시 | 그 시각 한 번. 울린 뒤 자동으로 꺼짐 |
| 반복 | 시각 + 반복(매일·평일·매주 요일·매월·매년) | 정한 날 그 시각마다 |
| 기한 | 마감 일시 + 알림(D-7, D-3, D-1, 마감 시각) | D-N은 그날 오전 9시, 마감 시각은 마감 때 |
| 타이머 | 몇 분 뒤 | 지금부터 정한 분이 지났을 때 |

### 추가하기
1. **알람 추가**를 누릅니다.
2. 이름을 쓰고 종류를 고른 뒤 시각을 정합니다. 반복 알람에는 **점심 10분 전**(평일 11:50), **퇴근 10분 전**(평일 17:50) 바로 넣기가 있습니다.
3. 필요하면 메모와 **소리** 여부를 정하고 **저장**을 누릅니다.
- **내 알람** 탭의 **바로 타이머**(5·10·15·30·60분)를 누르면 타이머가 바로 시작됩니다.

### 울릴 때
| 버튼 | 결과 |
|---|---|
| 끄기 | 알람 창을 닫음 |
| 5분 뒤 / 10분 뒤 | 그만큼 지나서 다시 울림 |

### 관리
- **내 알람** 탭: 스위치로 켜고 끕니다. 항목을 누르면 고치고, 🗑로 지웁니다. 각 항목에 다음에 울릴 시각이 표시됩니다.
- PC가 꺼져 있거나 절전 중이어서 놓친 알람은 켠 뒤 10분(절전 해제 시 1시간) 안의 것만 울립니다.

### 오늘 울릴 알림
**오늘 울릴 알림** 탭에 일정 알림, 할 일 마감, 연간 업무, 알람 중 오늘 울리는 것이 시간순으로 모입니다. 이미 울린 것은 흐리게 "울림"으로 표시됩니다. 항목을 누르면 해당 화면으로 갑니다.

## 집중 타이머
**알람 → 집중 타이머**.
1. 시간(15·25·50분 또는 직접 입력)을 고르고 **집중 시작**을 누릅니다.
2. 집중하는 동안 메신저·공지·일정 등의 **일반 알림(Windows 알림)은 보류**됩니다. 긴급 공지와 알람은 그대로 뜹니다.
3. 시간이 다 되면 알람 창이 뜨고, 보류된 알림 수가 한 번에 알려집니다.
4. **5분 휴식**으로 휴식 타이머를 씁니다. 중간에 끝내려면 **그만하기**.
- 아래에 오늘 집중한 횟수와 시간이 표시됩니다.

## 오늘의 업무 (홈)
- 홈의 **오늘의 업무** 위젯에 오늘 일정(개인 일정·팀원 부재 포함), 마감인 할 일(지난 것은 "지남"), 오늘 울릴 알람이 시간순으로 나옵니다.
- 하루 중 처음 프로그램을 켜면 "오늘의 업무: 일정 N건 · 마감 N건 · 알람 N건" 알림이 뜹니다.

## 즐겨찾기
- 기록 문서·게시글·공지 제목 옆, 자료실 파일 정보의 ☆를 누르면 즐겨찾기에 추가됩니다(★). 다시 누르면 빠집니다.
- 홈의 **즐겨찾기** 위젯에서 바로 엽니다. 자주 가는 웹 주소(전자결재 등)는 **런처 → 사이트 모음**에 등록합니다(위젯의 **사이트 모음** 단추). 예전에 위젯에 넣어 둔 웹 주소는 그대로 남아 있습니다.
- 즐겨찾기는 이 PC에만 저장됩니다.

## 계산 도구
왼쪽 메뉴 **유틸리티 → 계산 도구**. 아무것도 저장하지 않습니다.

| 도구 | 사용법 |
|---|---|
| 계산기 | 계산식을 쓰면 결과가 바로 보입니다. + − × ÷ ^ % 괄호, 천 단위 쉼표(1,200)를 쓸 수 있습니다. Enter를 누르면 기록에 남고, 기록을 누르면 결과가 복사됩니다. |
| 날짜 계산 | 시작일·종료일을 고르면 종료일까지 D-day, 기간(시작일 포함 일수), 근무일(주말·공휴일 제외)을 보여 줍니다. "시작일부터 N일 뒤"에 날짜와 근무일 기준 날짜가 나옵니다. 공휴일은 서버의 공휴일 목록을 씁니다. |
| 단위 변환 | 길이·넓이(㎡↔평)·무게(근·돈 포함)·데이터·온도를 고르고 값과 단위를 정합니다. |
