# 홈

프로그램을 열면 처음 보이는 화면입니다. 여러 기능의 요약을 **위젯**으로 보여 줍니다.

| 위젯 | 내용 |
|---|---|
| 읽어야 할 필독 문서 | 아직 읽지 않은 필독 기록. 있을 때만 보입니다. |
| 오늘의 업무 | 오늘의 공유 일정·개인 일정·팀원 부재, 마감인 할 일, 오늘 울릴 알람을 시간순으로 모아 보여 줍니다. 지난 마감은 "지남"으로 표시됩니다. **달력 보기**로 일정 화면에 갑니다. (예전의 "오늘 일정" 위젯은 같은 내용이어서 여기로 합쳤습니다.) |
| 공지 | 최근 공지 8개. 파란 점은 안 읽은 공지, **확인 필요**는 확인 버튼을 아직 누르지 않은 공지입니다. 클릭하면 공지가 열립니다. |
| 그룹 초대·가입 신청 | 받은 그룹 초대, 내가 그룹장인 그룹의 가입 신청. 있을 때만 보입니다. |
| 팀원 현황 | 팀원별 상태(온라인·자리비움·부재·오프라인)와 상태 메시지 |
| 즐겨찾기 | ☆로 모은 문서·게시글·자료·공지. 자주 가는 웹 사이트는 **사이트 모음**(런처)에 등록합니다. 위젯의 **사이트 모음**을 누르면 바로 갑니다. |

**위젯 편집**
1. 오른쪽 위 **위젯 편집**을 누릅니다.
2. ▲▼ 버튼으로 순서를 바꾸고, 눈 모양 버튼으로 숨기거나 다시 보이게 합니다.
3. **편집 완료**를 누릅니다. 이 PC에 저장되어 다시 실행해도 유지됩니다.

## 팀원 상태

| 상태 | 의미 |
|---|---|
| ● 온라인 | TeamHub가 실행 중이고 PC를 사용하고 있습니다. |
| ● 자리비움 | 5분 이상 키보드·마우스 입력이 없습니다. |
| ● 부재 | 휴가·출장 등 부재 일정 중입니다. |
| ● 오프라인 | TeamHub가 꺼져 있습니다. |
