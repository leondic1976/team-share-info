# TeamHub 개요

TeamHub는 팀원끼리 일정·공지·자료·메시지를 주고받는 Windows용 업무 보조 프로그램입니다. 팀원 PC 중 **한 대가 서버**가 되고, 나머지 팀원은 그 서버 PC의 IP 주소로 접속합니다. 인터넷 없이 사내망만으로 동작합니다.

> ⚠ 중요 보안 내용, 개인정보, 비공개 정보는 공유할 수 없습니다. 이 안내는 화면 맨 아래에 항상 표시됩니다.

## 화면 구성

| 위치 | 내용 |
|---|---|
| 상단 바 | 프로그램 이름, 통합 검색, Windows 창 버튼(최소화·최대화·닫기) |
| 왼쪽 메뉴 | 홈, 공지, 일정, 자료실, 회의, 메신저, 할 일, 게시판, 주소록, 기록, 다이어리, 메모, 알람, 런처, 유틸리티 / 아래쪽에 관리(관리자만), 설정, 도움말 |
| 가운데 | 선택한 메뉴의 화면 |
| 하단 표시줄 1줄 | 안내문(관리자가 정한 문구) |
| 하단 표시줄 2줄 | 기관·팀명 │ 내 이름 │ 서버 연결 상태 │ 프로그램 버전 |

- 왼쪽 메뉴 아래의 **메뉴 접기**를 누르면 아이콘만 표시됩니다.
- 메뉴 이름 오른쪽의 🔒 표시는 **내 PC에만 저장되는 개인 기능**입니다.

## 서버 연결 상태

| 표시 | 의미 |
|---|---|
| ● 서버 연결됨 | 정상입니다. |
| ● 서버 연결 중 | 접속을 시도하고 있습니다. |
| ● 서버 연결 끊김(재접속 중) | 서버 PC가 꺼졌거나 네트워크가 끊겼습니다. 자동으로 계속 다시 접속합니다. 이때도 개인 기능(🔒)은 그대로 쓸 수 있습니다. |
| ● 승인 대기 중 | 사용 신청을 보냈고 관리자 승인을 기다립니다. |
| ● 사용 중지됨 | 관리자가 이 PC의 사용을 중지했습니다. |
| ● 업데이트 필요 | 서버가 새 버전으로 바뀌었습니다. 새 버전을 설치해야 합니다. |

## 데이터 저장 위치

| 구분 | 저장 위치 | 볼 수 있는 사람 |
|---|---|---|
| 개인 기능(🔒): 개인 일정·할 일, 다이어리, 메모, 알람, 상용구, 지식 노트, 내 파일의 태그·가상 폴더·검색 색인, 사이트 모음, 런처 개인 항목, PC 점검 결과 | **내 PC** | 나만 |
| 공유 기능: 공지, 팀·그룹 일정, 자료실, 메신저, 게시판, 업무 요청, 기록 문서 | **서버 PC** | 공개 범위에 해당하는 팀원 |

- 새로 만드는 항목은 기본이 **개인(내 PC)** 입니다. **공유**를 눌러 공개 범위를 골라야 서버로 올라갑니다.
- 서버 관리자도 다른 사람 PC의 개인 데이터는 볼 수 없습니다.

## 창 닫기와 종료

- 창의 **✕(닫기)** 를 누르면 프로그램이 종료되지 않고 **작업 표시줄 오른쪽 알림 영역(트레이)** 으로 숨겨집니다. 알림은 계속 받습니다.
- 트레이 아이콘을 클릭하면 창이 다시 열립니다. 읽지 않은 알림이 있으면 아이콘에 빨간 점이 표시됩니다.
- 완전히 끝내려면 트레이 아이콘을 오른쪽 클릭 → **종료**를 누릅니다.
- 프로그램은 한 번만 실행됩니다. 이미 실행 중일 때 다시 실행하면 기존 창이 앞으로 나옵니다.
