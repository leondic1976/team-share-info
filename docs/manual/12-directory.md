# 주소록

오른쪽 위 **팀원·조직도 / 외부 연락처 / 내 정보**로 바꿉니다.

## 팀원·조직도
- 부서별로 팀원이 보입니다(하위 부서는 들여 써서 표시). 하위 부서의 제목에는 `행정지원본부 > 총무과 > 서무팀`처럼 맨 위 단계부터의 소속이 함께 나옵니다. 점 색은 팀원 상태입니다. 그림으로 된 조직도는 왼쪽 메뉴 **조직도**에서 봅니다.
- 검색칸에 이름·부서·담당 업무·내선번호를 입력해 찾습니다. 상위 부서 이름으로 찾으면 그 아래 부서의 팀원도 함께 나옵니다.
- 팀원을 누르면 소속(맨 위 단계부터)·직위·직급·내선·휴대폰·담당 업무가 보이고, **메시지 / 쪽지**를 바로 보낼 수 있습니다.

## 내 정보
- 이름·소속·직위·내선번호·휴대폰·상태 메시지·담당 업무를 고치고 **저장**을 누릅니다.
- **소속**은 목록에서 내 부서를 고르거나, 목록에 없으면 **목록에 없으면 직접 입력**을 눌러 `행정지원본부 > 총무과 > 서무팀`처럼 적습니다. 자세한 내용은 설명서의 **설정 (내 PC)** 장 "소속 고르기"를 보세요.
- **필명**: 자유롭게 정하는 이름입니다. 나만 입력하고 바꿀 수 있으며, 주소록과 구성원 목록에 `본명(필명)`으로 표시됩니다. 비우고 저장하면 없어집니다.
- **서버 PC에서 정한 항목**이라고 표시된 칸은 관리자(서버 PC)가 고친 값이라 바꿀 수 없습니다. 고쳐야 하면 관리자에게 요청하세요.
- 휴대폰 번호는 팀원 모두에게 보입니다. 원하지 않으면 비워 두세요.

## 외부 연락처
유관기관·거래처 연락처를 팀이 함께 씁니다.
- **연락처 추가**: 기관, 이름, 직위, 전화, 휴대폰, 이메일, 메모, 공개 범위를 입력합니다.
- 검색칸에 기관·이름·전화번호 일부를 입력해 찾습니다.
- 내가 등록한 연락처는 연필 단추로 수정, 휴지통 단추로 삭제할 수 있습니다.
- **CSV 가져오기**: 엑셀에서 **CSV UTF-8** 형식으로 저장한 파일을 고릅니다. 첫 줄 머리글에 `기관, 이름, 직위, 전화, 휴대폰, 이메일, 메모` 중 필요한 칸을 넣습니다(`성명`, `회사`, `휴대전화`, `비고` 등도 인식). 이름이 빈 줄은 건너뜁니다. 공개 범위는 지금 고른 공간(팀 전체 또는 그룹)이 됩니다.
- **CSV 내보내기**: 지금 보이는 연락처를 CSV 파일로 저장합니다. 엑셀에서 바로 열립니다.

## 부서 관리 (서버 PC)
부서 추가·수정·삭제·합치기와 구성원 배치는 **서버 PC**의 **설정 → 조직 관리**에서 합니다(최종관리자 전용). 자세한 내용은 설명서의 **설정 (내 PC)** 장 "조직 관리"를 보세요.
