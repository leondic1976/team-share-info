# 런처 (프로그램 · 사이트 · 양식 바로 실행)

자주 쓰는 프로그램, 폴더, 문서, 업무 사이트를 한곳에서 엽니다. 왼쪽 메뉴 **런처**.

## 내 런처
이 PC에만 저장됩니다.

### 자동 등록
- 처음 실행하면 이 PC에 설치된 **한글·한셀·한쇼, Excel·Word·PowerPoint·Outlook, Adobe Acrobat, Edge·Chrome·웨일·Firefox**와 파일 탐색기·메모장·계산기를 찾아 자동으로 등록합니다.
- 프로그램을 새로 설치했으면 **프로그램 다시 찾기**를 누릅니다. 지운 항목은 다시 추가되지 않습니다.

### 직접 추가
| 방법 | 순서 |
|---|---|
| 프로그램 추가 | 시작 메뉴의 프로그램 목록에서 이름을 찾아 **추가** |
| 파일·폴더 | 이름·위치를 입력하거나 **파일**/**폴더** 버튼으로 고름. 분류를 정하면 그 분류로 묶임 |
| 웹 주소 | 이름과 https:// 주소 입력 |
| 끌어다 놓기 | 바탕화면·탐색기의 파일·폴더·바로가기, 브라우저 주소를 런처 화면에 끌어다 놓기 |

### 실행과 정리
- 아이콘을 누르면 실행됩니다. 파일은 연결된 프로그램으로, 웹 주소는 기본 브라우저로 열립니다.
- **편집**을 누르면 각 항목에 ▲▼(순서), 연필(고치기), 휴지통(빼기) 단추가 나옵니다. 고치기에서 이름·위치·분류·실행 옵션을 바꿉니다.
- 위치가 바뀐 파일·폴더는 "파일이나 폴더가 없습니다"라고 알려 줍니다. 고치기로 위치를 다시 정합니다.

## 사이트 모음
자주 가는 웹 사이트를 분류별로 모아 둡니다. **런처 → 사이트 모음**. 이 PC에만 저장됩니다.
- **사이트 추가**: 이름, 주소(https://…), 분류, 메모.
- **주요 사이트 목록에서 고르기**: 정부24·국민신문고·나라장터·홈택스·국가법령정보센터 등 공공 사이트, 번역·사전, 포털·지도를 체크해 한 번에 추가합니다.
- **Chrome에서 / Edge에서 / 웨일에서**: 브라우저 즐겨찾기를 읽어 가져옵니다(브라우저 쪽은 바뀌지 않음). 이미 있는 주소는 건너뜁니다.
- **HTML 가져오기 / 내보내기**: 브라우저의 즐겨찾기 내보내기 파일(HTML)과 주고받습니다.
- 누르면 기본 브라우저로 열립니다. **편집**에서 순서 바꾸기·고치기·삭제. 빠른 실행창(Ctrl+Alt+Space)에서도 찾아집니다.

## 팀 공용 · 양식함
관리자가 등록한 업무 사이트, 공용 폴더, 양식 파일이 모든 팀원에게 똑같이 보입니다.
- 업무 사이트·공용 폴더: 누르면 열립니다.
- **양식**(새 문서로 열기): 누를 때마다 TeamHub 자료 폴더(`%APPDATA%\TeamHub\TeamHub 양식`)에 "양식이름_날짜" 사본을 만들어 엽니다. 원본 양식은 바뀌지 않습니다. 사본은 **최근 문서**에도 나옵니다. 원하는 폴더에 두려면 한글·오피스에서 **다른 이름으로 저장**을 씁니다. (이전 판에서 만든 사본은 **내 문서 → TeamHub 양식**에 그대로 있습니다.)

## 최근 문서
- 최근에 연 한글·오피스·PDF 등 문서와 TeamHub에서 연 문서가 최근 순으로 나옵니다.
- 핀 단추(**고정**)를 누르면 맨 위에 고정됩니다. 검색창에 이름 일부를 입력해 찾습니다.

## 빠른 실행 (Ctrl+Alt+Space)
1. 어느 화면에서든 **Ctrl+Alt+Space**를 누릅니다. 트레이 메뉴 **빠른 실행**이나 런처 화면 **빠른 실행** 버튼으로도 엽니다.
2. 이름 일부를 입력하면 내 런처·사이트 모음·팀 공용·양식·최근 문서에서 찾아 줍니다.
3. ↑↓로 고르고 **Enter**를 누르면 실행됩니다. **Esc**는 닫기입니다.
- 다른 프로그램이 이 단축키를 쓰고 있으면 동작하지 않습니다. 이때는 트레이 메뉴를 씁니다.

## 공용 런처 관리 (관리자)
**관리 → 공용 런처·보안**.
1. 종류(업무 사이트 / 공용 폴더·문서 / 양식 파일)를 고릅니다.
2. 이름, 주소·경로(양식은 파일), 분류를 넣고 **추가**를 누르면 모든 팀원 런처에 바로 나타납니다.
- 공용 폴더는 `\\서버이름\폴더` 형식 또는 드라이브 경로를 씁니다. 실행 파일(.exe, .bat 등)은 보안상 등록할 수 없습니다.
- 휴지통 단추로 지우면 팀원 런처에서도 사라집니다.
