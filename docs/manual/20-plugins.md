# 확장 기능 (플러그인)

TeamHub에 기능을 더하는 작은 프로그램입니다. 왼쪽 메뉴 **확장 기능**. 설치한 확장 기능은 그 아래에 메뉴로 나타납니다(예: 🪜 사다리타기).

## 설치
설치는 항상 **TeamHub 안에서** 권한을 확인한 뒤 진행됩니다.

| 방법 | 순서 |
|---|---|
| 확장 기능 모음 | **확장 기능** 화면 아래 **확장 기능 모음**에서 **설치** → 권한 확인 → **설치** |
| 다운로드 사이트 | 다운로드 사이트의 **확장 기능** 페이지에서 카드의 **TeamHub에서 설치** → TeamHub가 열리고 확인 창이 나옴 |
| 파일 (폐쇄망) | 사이트에서 **파일 받기**로 받은 `.thplugin` 파일을 옮긴 뒤 **파일에서 설치** |

- 확인 창에 확장 기능이 쓰는 **권한**이 나옵니다(팀원 이름 보기, 이 PC에 저장, 팀원과 함께하는 방, 알림, 클립보드 복사). 확장 기능은 이 권한 밖의 일은 할 수 없습니다.
- 확장 기능은 격리된 화면에서 실행되어 인터넷·내 파일·다른 프로그램에 직접 접근하지 못합니다.
- 새 버전이 있으면 설치된 확장 기능 카드에 **업데이트** 단추가 나옵니다.
- **사용** 스위치로 잠시 끄거나, **제거**로 지웁니다(이 PC에 저장된 확장 기능 데이터도 지워짐).
- 함께하기 방을 쓰는 확장 기능은 참여하는 팀원 모두 설치해야 합니다. 설치하지 않은 팀원이 초대를 받으면 설치 안내 알림이 옵니다.

## 사다리타기
### 바로 하기 (이 PC에서)
1. **참여자**를 줄바꿈이나 쉼표로 적습니다(2~30명). **팀원 불러오기**로 팀원 이름을 채우고 빠질 사람은 지웁니다.
2. **결과 종류**를 고릅니다.

| 종류 | 결과 |
|---|---|
| 당첨 고르기 | 당첨 N명(이름 바꾸기 가능), 나머지 꽝 |
| 순서 정하기 | 1등 ~ N등 |
| 팀 나누기 | A팀·B팀… (2~6팀, 고르게) |
| 커피 몰아주기 | 1명이 쏘기, 나머지 꽝 |
| 벌칙 정하기 | 노래·간식·회의록·청소 등(고칠 수 있음) |
| 직접 입력 | 결과 칸에 직접 적기(모자라면 꽝) |

3. **결과 가리기**를 켜 두면 결과가 ❓로 가려지고, 이름을 누를 때마다 하나씩 공개됩니다. **가로줄**로 사다리 복잡도를 고릅니다.
4. **사다리 만들기** → 위쪽 **이름을 누르면** 그 사람의 길을 따라 선이 그려지고 결과가 열립니다. **모두 공개**는 한 사람씩 차례로 보여 줍니다.
5. **다시 섞기**(새 사다리), **결과 복사**(메신저에 붙여넣기), **처음으로**.

### 팀원과 함께 (실시간)
1. **팀원과 함께** 탭 → 참여자·결과를 적고 **방 이름**을 정한 뒤 **방 만들고 초대**를 누릅니다. 누구나 방을 만들 수 있습니다.
   - 참여자 이름이 팀원 이름과 같으면 그 팀원에게 초대 알림이 갑니다. **팀 전체에 공개**를 켜면 알림 없이 모두의 방 목록에 보입니다.
2. 각자 사다리 위쪽 **고르기**를 눌러 자기 출발점을 고릅니다. 다시 누르면 취소합니다. 다른 사람이 고른 자리는 고를 수 없습니다.
3. 모두 고르면 방을 만든 사람이 **결과 공개**를 누릅니다. 비어 있는 자리는 참여자 목록에서 고르지 않은 사람에게 무작위로 배정됩니다.
4. 참여한 모든 사람의 화면에서 동시에 길이 그려지고 결과가 나옵니다.
- 가로줄은 출발점이 모두 정해진 **뒤에** 무작위(암호학적 난수)로 만들어지므로 누구도 미리 결과를 알 수 없습니다.
- 방 목록에서 진행 중인 방에 **참여**하거나, 끝난 방의 **결과 보기**를 합니다. 방을 만든 사람은 방을 지울 수 있습니다.

### 기록
**기록** 탭에 지난 게임(바로 하기·함께)의 결과가 50개까지 남습니다(이 PC에 저장).
