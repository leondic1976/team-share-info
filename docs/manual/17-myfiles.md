# 내 파일 (탐색기 · 빠른 검색 · 태그 · 가상 폴더)

왼쪽 메뉴 **내 파일**. 이 PC의 파일을 찾고 정리합니다. 파일은 원래 자리에 그대로 있고, 태그·가상 폴더·검색 색인 정보만 이 PC에 저장됩니다. 서버로 보내지 않습니다.

## 탐색기
### 이동
- 왼쪽: **바로 가기**(바탕 화면·문서·다운로드·사진·내 폴더), **고정한 폴더**, **드라이브**, **최근 간 폴더**.
- 위쪽 경로 표시줄의 폴더 이름을 누르면 그 폴더로 갑니다. 빈 곳을 누르면 경로를 직접 입력할 수 있습니다(Enter로 이동).
- ← → ↑ 버튼: 뒤로 / 앞으로 / 위 폴더. Backspace도 위 폴더입니다.
- 핀 단추(**이 폴더 고정**)로 지금 폴더를 **고정한 폴더**에 넣거나 뺍니다.
- 열 제목(이름·수정한 날짜·종류·크기)을 누르면 정렬이 바뀝니다. **숨김 파일**로 숨긴 파일을 보이게 합니다.

### 선택과 열기
- 누르면 선택, Ctrl+누르기로 여러 개, Shift+누르기로 범위 선택, Ctrl+A로 모두 선택합니다.
- 더블클릭(또는 Enter): 폴더는 들어가고 파일은 연결된 프로그램으로 엽니다.

### 관리
| 기능 | 방법 |
|---|---|
| 새 폴더 | **새 폴더** → 이름 입력 → Enter |
| 이름 바꾸기 | 항목 선택 → **이름 바꾸기** 또는 F2 → 입력 → Enter (Esc 취소) |
| 복사·옮기기 | **복사**(Ctrl+C) 또는 **잘라내기**(Ctrl+X) → 대상 폴더로 이동 → **붙여넣기**(Ctrl+V) |
| 끌어서 옮기기 | 항목을 폴더 줄이나 왼쪽 목록으로 끌어 놓기. Ctrl을 누른 채 놓으면 복사 |
| 지우기 | **휴지통으로** 또는 Delete → 확인. Windows 휴지통에서 되살릴 수 있습니다 |
| 속성 | 크기, 파일·폴더 수, 만든 날짜, 수정한 날짜 |
| 경로 복사 / 탐색기 | 경로를 클립보드에 복사 / Windows 탐색기에서 위치 열기 |

- 같은 이름이 있으면 덮어쓰지 않고 "이름 (2)"처럼 새 이름으로 만듭니다.
- Windows, Program Files, ProgramData, 드라이브 맨 위, 다른 사용자 폴더 안의 파일은 바꾸거나 지울 수 없습니다(보기·열기는 가능).

## 빠른 검색
1. 어디서든 **Ctrl+Alt+F**를 누르거나 **내 파일 → 빠른 검색**을 엽니다.
2. 파일·폴더 이름 일부를 입력하면 바로 결과가 나옵니다.
   - 띄어 쓴 단어는 모두 들어 있는 것만 찾습니다(예: `2026 보고`).
   - `*`, `?`를 쓸 수 있습니다(예: `*.hwp`, `회의록_??`).
3. **종류**(문서·표·발표·PDF·그림 등), **크기**, **수정일**(오늘·7일·30일·1년·6개월 넘은 것)로 좁힙니다.
4. 결과를 더블클릭하면 열리고, **폴더 열기** 단추는 들어 있는 폴더를 엽니다. Ctrl+클릭으로 여러 개 골라 **태그**·**가상 폴더에**·**경로 복사**를 합니다.
5. 탐색기의 돋보기 단추(**이 폴더에서 찾기**)를 누르면 그 폴더 안에서만 찾습니다.

### 색인 폴더
- 오른쪽 위 **색인 … 개 · 색인 폴더 N곳**을 누르면 색인할 폴더 목록이 나옵니다. 처음에는 바탕 화면·문서·다운로드·사진입니다.
- **폴더·드라이브 추가**로 D: 드라이브나 업무 폴더를 넣습니다. **다시 색인** 단추는 다시 색인, **색인에서 빼기**(휴지통) 단추는 색인에서 빼기(파일은 지우지 않음)입니다.
- 파일 **이름**만 색인합니다(내용은 읽지 않음). 시스템 폴더(Windows, Program Files, AppData 등)는 건너뜁니다.
- 파일이 생기거나 지워지면 몇 초 안에 반영되고, 6시간마다 다시 검사합니다. 큰 드라이브는 처음 색인에 몇 분 걸릴 수 있습니다.

## 태그 · 가상 폴더 · 스마트 폴더
파일을 옮기지 않고 주제별로 모아 봅니다. **내 파일 → 태그·가상 폴더**.

| 기능 | 쓰는 법 |
|---|---|
| 태그 | 탐색기·검색 결과에서 **태그** → 있는 태그를 고르거나 새 태그 입력 → 저장. 왼쪽 태그를 누르면 그 태그의 파일이 모입니다. 색·이름 바꾸기, 태그 삭제(파일은 그대로) |
| 가상 폴더 | **가상 폴더에** → 고르거나 새로 만들기. 여러 곳의 파일을 한 묶음으로 봅니다. 묶음 옆 ＋로 하위 묶음, 연필 단추로 이름·메모 |
| 스마트 폴더 | 빠른 검색에서 조건을 정하고 **스마트 폴더로 저장**. 열 때마다 조건에 맞는 파일을 새로 찾습니다(예: 최근 7일 문서) |

- 파일이 옮겨지거나 지워지면 **찾을 수 없음**으로 표시됩니다. **목록에서 빼기**로 정리합니다.
- TeamHub 탐색기에서 이름을 바꾸거나 옮긴 파일은 태그·가상 폴더가 자동으로 따라갑니다.
