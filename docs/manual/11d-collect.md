# 자료 취합

"각 담당은 ○○ 자료를 ○일까지 제출" 같은 일을 하는 화면입니다. 요청한 사람이 대상과 마감을 정해 보내면, 대상자는 파일이나 글로 제출하고, 요청한 사람은 누가 냈는지 한눈에 보고 낸 자료를 한꺼번에 내려받습니다. 왼쪽 메뉴 **자료 취합**(근무현황 아래).

- 메뉴 옆 숫자는 **내가 아직 내지 않은 요청** 수입니다.
- 요청할 수 있는 사람: 처음에는 모든 팀원. 관리자가 **관리 → 조직·운영 설정 → 자료 취합 요청 권한**을 **최종관리자·서무만**으로 바꾸면 그 사람들만 **새 요청** 단추가 보입니다.
- 쓰지 않으면 관리자가 **관리 → 조직·운영 설정 → 사용할 기능**에서 끌 수 있습니다.
- 서버에 연결되어 있어야 요청하고 제출할 수 있습니다.

## 목록
- **해야 할 것**: 나에게 온 요청 중 아직 내지 않은 것. 마감이 가까운 순서로 나오고, 마감까지 남은 시간(예: 3일 남음, 5시간 남음)이 함께 나옵니다. 하루가 안 남으면 빨간색입니다.
- **지난 것**: 이미 냈거나 **해당 없음**으로 알린 것, 마감이 지나 더 받지 않는 것.
- **내가 요청한 것**: 내가 보낸 요청과 제출 현황(냈다 / 대상 인원, 해당 없음, 미제출 수).
- 최종관리자(서버 PC)는 볼 수 있는 다른 사람의 요청을 **다른 사람 요청**에서 봅니다.
- 오른쪽 검색 칸에 제목이나 요청한 사람 이름을 넣어 찾습니다. 줄을 누르면 요청이 열립니다.

## 요청하기
1. **새 요청**을 누릅니다.
2. **제목**과 **설명**(무엇을, 어떤 양식으로 내야 하는지)을 적습니다.
3. 채워 낼 양식이 있으면 **양식 파일**에서 **파일 첨부**로 올립니다(끌어다 놓아도 됩니다). 여러 개도 됩니다.
4. **마감 일시**를 정합니다. 처음에는 3근무일 뒤 18:00로 들어가 있습니다.
5. **마감 후 제출 허용**: 켜 두면 마감이 지나도 받고 **늦게 제출**로 표시합니다. 끄면 마감 뒤에는 받지 않습니다.
6. **제출 방식**: **파일**(파일을 올려서), **글**(내용을 적어서), **파일과 글**(둘 중 하나 또는 둘 다).
7. **대상**: **팀 전체**, **그룹**(그 그룹 사람 모두), **지정한 사람** 중에서 고릅니다. 요청한 나는 대상에서 빠집니다.
8. **요청 보내기**를 누릅니다. 대상자 화면에 "팀뿌요~" 소리와 함께 알림 카드가 뜹니다. 그때 PC가 꺼져 있던 사람은 다음에 접속할 때 카드를 받습니다.

- 그룹으로 보낸 요청은 그룹에 새로 들어온 사람도 대상이 되고, 그룹에서 나간 사람은 대상에서 빠집니다(이미 낸 사람의 자료는 남습니다).
- 설명과 제출 내용에는 개인정보를 적지 마세요. 적으면 보내기 전에 한 번 더 묻습니다.

## 제출 현황 (요청한 사람)
요청을 열면 아래에 **제출 현황**이 나옵니다. 요청한 사람과 최종관리자만 봅니다. 대상자는 자기 것만 봅니다.

- 위쪽 숫자 칸: **대상 · 제출 · 늦게 제출 · 해당 없음 · 미제출** 인원. 칸을 누르면 그 상태의 사람만 표에 나옵니다(**대상**을 누르면 모두).
- 표: 부서, 이름, 상태, 제출 시각, 낸 파일과 글(해당 없음이면 사유). 파일 이름을 누르면 내려받아 엽니다. 사람이 내거나 바꾸면 화면이 바로 바뀝니다.
- 상태
  | 상태 | 뜻 |
  |---|---|
  | 제출 | 마감 전에 냈습니다. |
  | 늦게 제출 | 마감이 지난 뒤에 냈습니다(마감 후 제출 허용일 때). |
  | 해당 없음 | 낼 것이 없다고 알렸습니다. |
  | 미제출 | 아직 내지 않았습니다. |
- **미제출자에게 다시 알림**: 아직 내지 않은 사람에게만 알림 카드와 소리를 다시 보냅니다. 지금 접속하지 않은 사람은 접속하면 받습니다. 마감되어 더 받지 않는 요청에는 쓸 수 없습니다.
- **자동 알림**: 내지 않은 사람에게 **마감 하루 전**과 **마감 1시간 전**에 서버가 한 번씩 알림을 보냅니다. 서버 PC를 다시 켜도 같은 알림을 또 보내지 않습니다. 마감을 바꾸면 새 마감에 맞춰 다시 알립니다. 요청을 보낼 때 이미 그 시각이 지났으면(예: 3시간 뒤가 마감이면 "하루 전") 보내지 않습니다.
- **한꺼번에 내려받기 (ZIP)**: 낸 파일 전부를 ZIP 파일 하나로 저장합니다. 파일 이름은 `자료취합_제목_날짜.zip`이고, 안의 파일은 `부서_이름_원래파일이름`입니다. 글로 낸 내용은 `부서_이름_제출내용.txt`, 제출 현황 표는 `제출현황.csv`로 함께 들어 있습니다. 4GB가 넘으면 한 번에 묶을 수 없으니 파일 이름을 눌러 나누어 받습니다.
- **목록 저장 (CSV)**: 제출 현황 표만 엑셀에서 열 수 있는 파일로 저장합니다.
- 저장한 뒤 나오는 **폴더 열기**로 저장한 곳을 엽니다.

## 고치기 · 일찍 마감 · 삭제 (요청한 사람)
- **고치기**: 제목, 설명, 양식 파일, 마감 일시, 마감 후 제출 허용을 바꿉니다. 마감을 늦추면 그 사이에 늦게 낸 사람은 **제출**로 바뀝니다. 대상과 제출 방식은 보낸 뒤에는 바꿀 수 없습니다(새로 요청하세요).
- **일찍 마감**: 지금부터 더는 받지 않습니다. 되돌릴 수 없습니다.
- **삭제**: 요청과 낸 파일을 모두 지웁니다. 되돌릴 수 없으니 필요한 자료는 먼저 내려받으세요.
- 최종관리자(서버 PC)도 같은 일을 할 수 있습니다.

## 제출하기 (대상자)
1. 알림 카드를 누르거나 **자료 취합 → 해야 할 것**에서 요청을 엽니다.
2. **요청 내용**에서 설명과 마감을 확인하고, **양식 파일**이 있으면 **저장** 또는 **열기**로 내려받습니다.
3. **내 제출**에서 **제출할 파일**을 **파일 첨부**로 올리거나(끌어다 놓아도 됩니다) **내용**을 적습니다. 올릴 수 있는 크기와 막힌 확장자는 다른 첨부 파일과 같습니다.
4. **제출**을 누릅니다. 상태가 **제출**로 바뀌고 낸 파일과 내용이 보입니다.

- **바꿔서 다시 제출**: 파일을 빼거나 더해서 다시 냅니다. 다시 낸 시각이 제출 시각이 됩니다. 마감이 지난 뒤 다시 내면 **늦게 제출**이 됩니다.
- **제출 취소**: 낸 것을 거두어 **미제출**로 돌아갑니다. 마감 전에만 됩니다.
- **해당 없음**: 낼 것이 없을 때 누르고, 필요하면 사유를 적은 뒤 **확인**을 누릅니다. 이미 낸 파일과 내용은 지워집니다. 마음이 바뀌면 **제출하기**로 다시 낼 수 있습니다.
- 마감이 지나면(마감 후 제출 허용이 꺼진 요청) 또는 요청한 사람이 **일찍 마감**하면 더는 내거나 바꿀 수 없습니다.
- 낸 파일은 나와 요청한 사람(그리고 최종관리자)만 내려받을 수 있습니다. 다른 대상자는 볼 수 없습니다.

## 보관
- 양식 파일과 낸 파일은 서버 PC에 보관되며 서버 백업에 함께 들어갑니다. 메신저 파일 보관 기간이 지나도 지워지지 않습니다. 요청을 **삭제**할 때 함께 지워집니다.
