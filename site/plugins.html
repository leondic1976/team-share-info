🧩 확장 기능

TeamHub에 기능을 더합니다. 이 페이지에서는 고르기만 하고, 설치는 TeamHub 프로그램 안에서 권한을 확인한 뒤 진행됩니다.

불러오는 중…

설치 방법
  1. TeamHub에서 설치를 누르면 TeamHub가 열리고 설치 확인 창이 나옵니다(TeamHub가 설치되어 있어야 합니다).
  2. 또는 TeamHub의 확장 기능 메뉴 → 확장 기능 모음에서 설치를 누릅니다.
  3. 폐쇄망: 파일 받기로 .thplugin 파일을 받아 옮긴 뒤, TeamHub 확장 기능 → 파일에서 설치.

확장 기능은 격리된 화면에서 실행되어 인터넷·파일·다른 프로그램에 직접 접근하지 못하고, 설치할 때 보여 주는 권한 안에서만 동작합니다.
