# 문제 해결

| 증상 | 확인할 것 |
|---|---|
| 자동으로 찾은 서버 목록이 비어 있음 | 서버 PC가 켜져 있고 TeamHub가 실행 중인지 확인합니다. 네트워크가 다르거나 방화벽이 막으면 찾지 못합니다. 서버 주소를 직접 입력하세요. |
| **연결 확인**에서 "서버에 연결할 수 없습니다" | ① 주소·포트 확인 ② 서버 PC에서 **설정 → 서버 연결**의 서버 상태가 "실행 중"인지 확인 ③ 서버 PC에서 **방화벽 규칙 다시 등록** ④ 서버 PC의 Windows 네트워크 프로필이 "공용"이면 "개인"으로 바꿉니다. |
| 위쪽에 빨간 "서버 꺼짐 · 오프라인", 하단에 "서버 연결 끊김" | 서버 PC가 꺼졌거나 절전 상태입니다. 보관된 내용은 그대로 보이고 새로 쓴 글은 보관했다가 보냅니다(도움말 개요 "서버가 꺼져 있을 때"). 서버가 다시 켜지면 몇 초 안에 자동으로 연결됩니다. 서버 PC의 IP가 바뀌면 같은 네트워크에서는 스스로 다시 찾고, 찾지 못하면 **설정 → 서버 연결 → 서버 다시 찾기**를 누릅니다. |
| "사용이 중지되었습니다" 화면 | 관리자가 이 PC 또는 구성원 사용을 중지했습니다. 관리자에게 문의하거나 **처음부터 다시 신청**을 누릅니다. |
| "업데이트가 필요합니다" 화면이 계속됨 | 화면에 나오는 까닭을 확인합니다. 자동 업데이트가 안 되면 브라우저에서 `http://서버주소/download` 로 설치 파일을 받아 다시 설치합니다. 개인 데이터는 유지됩니다. |
| 설정 → 업데이트에 "확인하지 못했습니다" | 함께 나오는 까닭을 봅니다. 연결 문제면 인터넷·서버 연결을, "설치 파일을 저장하지 못했습니다"면 보안 프로그램이 막는지 확인합니다. **지금 확인**으로 다시 시도합니다. |
| **설치(다시 시작)** 을 눌렀는데 설치되지 않음 | 15초 안에 설치가 시작되지 않으면 프로그램이 그대로 계속 실행되고 까닭이 설정 → 업데이트에 나옵니다. 보안 프로그램이 설치 파일을 지웠으면 자동으로 다시 받습니다. 계속 안 되면 다운로드 사이트나 `http://서버주소/download` 에서 설치 파일을 받아 설치합니다. |
| 승인 대기 화면에서 진행되지 않음 | 관리자가 **관리 → 승인 관리**에서 승인해야 합니다. 신청 내용이 잘못됐으면 **신청 취소하고 처음으로**를 누르고 다시 신청합니다. |
| 서버 PC를 바꿔야 함 | 기존 서버의 데이터 폴더를 새 PC로 옮기는 **서버 이전** 기능을 사용합니다(관리 → 백업). |
| 백신·Windows가 설치 파일을 바이러스·랜섬웨어로 표시 | 오진입니다. 도움말 **보안프로그램 예외 등록 요청서**의 "백신·Windows가 바이러스·랜섬웨어로 표시할 때"를 따라 허용·예외 등록·오진 신고를 합니다. |
| 위쪽 연결 단추의 **보낼 것**이 줄지 않음 | 서버에 연결되어 있는지 확인하고 단추를 눌러 **지금 보내기**를 누릅니다. "보내지 못함"은 서버가 거절한 것이므로 까닭을 보고 **다시** 또는 지우기를 누릅니다. |
| 문의할 때 알려 줄 정보 | **설정 → 프로그램 정보**의 버전, PC 이름, Windows 계정 |
