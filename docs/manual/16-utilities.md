# 유틸리티 (PC 자원 · 보안 점검 · 진단 · 정리)

왼쪽 메뉴 **유틸리티**. 모두 이 PC에서만 동작하며 결과를 서버나 관리자에게 보내지 않습니다.

## PC 자원
- **CPU·메모리·네트워크**: 2초마다 갱신되는 사용량과 최근 2분 그래프. 90% 이상이면 빨간색으로 표시됩니다.
- **드라이브**: 드라이브별 남은 공간. 남은 공간이 10% 미만이면 "공간 부족"으로 표시되고 하루 한 번 Windows 알림이 옵니다.
- **시스템 정보**: PC 이름, 사용자, 운영체제, CPU, 메모리, IP·MAC 주소, 부팅 시각.
- **자원을 많이 쓰는 프로그램**: CPU·메모리를 많이 쓰는 프로그램 8개. **작업 관리자**로 바로 갑니다.

## 보안 점검
1. **보안 점검 시작**을 누릅니다(최대 1분).
2. 항목마다 **양호 / 주의 / 취약 / 확인 불가**와 현재 상태, 조치 방법이 나옵니다. **설정 열기**를 누르면 해당 Windows 설정 화면이 열립니다.

| 항목 | 양호 기준 |
|---|---|
| 백신 | 실시간 감시 켜짐, Defender는 업데이트 7일 이내. 다른 백신은 "실행 중/설치됨"까지만 확인 |
| 방화벽 | 모든 프로필(도메인·개인·공용) 켜짐 |
| Windows 업데이트 | 최근 설치 45일 이내(90일 넘으면 취약) |
| 화면 보호기 잠금 | 켜짐 + 해제 시 로그온 화면 + 10분 이하 |
| 로그인 암호 | 암호 설정, 변경 90일 이내. 도메인·Microsoft 계정은 확인 불가 |
| 공유 폴더 | 공유 중인 폴더 없음 |
| USB 자동 실행 | 꺼짐 |
| 디스크 암호화 (C:) | BitLocker 켜짐 |
| 지정 보안프로그램 | 관리자가 정한 프로그램이 실행 중 |

- 관리자 권한이 필요한 항목은 "확인 불가"로 표시됩니다.
- 결과는 이 PC에 최근 24회까지 보관됩니다. 30일 넘게 점검하지 않으면 오전 10시에 점검 알림이 옵니다.

## 네트워크 진단
1. **진단 시작**을 누릅니다. 특정 PC나 프린터를 확인하려면 주소를 입력합니다.
2. 순서대로 확인합니다.

| 단계 | 문제일 때 확인할 것 |
|---|---|
| 네트워크 연결 | 랜선·와이파이 연결 |
| 게이트웨이(공유기) | 공유기·허브 전원. 핑을 막아 둔 곳도 있어 "주의"만으로는 문제가 아닐 수 있음 |
| TeamHub 서버 | 서버 PC가 켜져 있는지, 서버 PC 방화벽 |
| 인터넷 | 폐쇄망(업무망)이면 연결되지 않는 것이 정상 |

## 임시 파일 정리
1. 내 계정의 임시 폴더 목록이 나옵니다. 7일 지난 항목은 미리 선택되어 있습니다.
2. 목록을 확인하고 체크를 고친 뒤 **선택 항목 지우기**를 누릅니다. 확인 창에서 한 번 더 확인합니다.
- 지운 파일은 되살릴 수 없습니다. 다른 프로그램이 쓰고 있는 파일은 건너뜁니다.

## Windows 설정
프린터·스캐너, 블루투스, 디스플레이, 소리, 자동 실행, 네트워크, 프록시, 공유 설정, Windows 업데이트, Windows 보안, 방화벽, 로그인 옵션, 잠금 화면, 장치 암호화, 저장소, 설치된 앱, 전원, 날짜·시간, PC 정보 화면과 작업 관리자·장치 관리자·제어판·디스크 정리를 바로 엽니다.

## 계산 도구
계산기, 날짜 계산, 단위 변환. 사용법은 도움말 "메모 · 알람 · 업무 도구" 장의 "계산 도구"를 봅니다.

## 보안 점검 지정 프로그램 (관리자)
**관리 → 공용 런처·보안 → 보안 점검 지정 프로그램**.
1. 이름, 프로세스 이름(예: agent.exe), 서비스 이름(쉼표로 구분)을 넣고 **추가**를 누릅니다.
2. 팀원이 보안 점검을 하면 그 프로그램이 실행 중인지 확인합니다. 결과는 팀원 각자의 PC에만 남습니다.
