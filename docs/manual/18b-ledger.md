# 관리대장

엑셀처럼 쓰는 대장(장부) 관리 화면입니다. 왼쪽 메뉴 **관리대장**. 물품·문서 수발신·예산 집행·차량 운행·대여·출장·교육 이수처럼 표로 관리하는 일이라면 무엇이든 열을 직접 정해 쓸 수 있습니다. 왼쪽에 대장 목록, 오른쪽에 표가 있습니다.

예전의 확장 기능 "스마트 대장"이 본 기능이 된 것입니다. 스마트 대장으로 만든 대장은 **개인용**에 그대로 있습니다.

## 대장의 종류
| 종류 | 저장되는 곳 | 볼 수 있는 사람 | 고칠 수 있는 사람 |
|---|---|---|---|
| 🔒 **개인용** | 이 PC | 나만 | 나 |
| 👥 **팀용** | 서버 | 팀 전체, 또는 고른 그룹의 구성원 | 볼 수 있는 사람 모두(또는 만든 사람·관리자만) |
| 👤 **지정자용** | 서버 | 만든 사람과 지정한 사람만 | 볼 수 있는 사람 모두(또는 만든 사람·관리자만) |

- 왼쪽 목록이 **개인용 / 팀용 / 지정자용** 세 묶음으로 나뉘어 있습니다.
- 팀용·지정자용 대장은 서버 백업에 포함됩니다. 개인용 대장은 이 PC에만 있으므로 필요하면 **대장 파일로 저장**으로 백업하세요.
- 서버에 연결되지 않은 동안에는 개인용 대장만 고칠 수 있습니다(팀용·지정자용은 마지막에 본 내용을 보기만 가능).

## 자동 저장
- 저장 단추가 없습니다. 고치는 대로 저장되고, 대장 이름 옆에 **저장됨**(개인용) 또는 **서버에 저장됨**(팀용·지정자용)이 표시됩니다.
- 다른 메뉴로 넘어가거나 프로그램을 닫아도 입력한 내용은 저장되어 있습니다.
- 서버에 저장하지 못하면 "서버에 저장하지 못함 · 다시 시도 중"이 표시되고, 연결되면 저절로 다시 저장합니다.

## 함께 쓰기 (팀용·지정자용)
- **한 번에 한 사람이 고칩니다.** 입력을 시작하면 표 위에 **✏️ 내가 편집 중**이 표시되고, 그동안 다른 사람 화면에는 **🔒 OOO님이 편집 중**으로 나오며 보기만 할 수 있습니다.
- 저장된 내용은 다른 사람 화면에 **바로** 나타납니다(새로 고칠 필요 없음).
- **편집 끝내기**를 누르거나, 1분 동안 입력이 없거나, 다른 메뉴로 넘어가면 다른 사람이 고칠 수 있게 됩니다. 프로그램이 꺼지거나 연결이 끊긴 경우에도 1분 30초쯤 뒤에는 풀립니다.
- **충돌 방지**: 서버는 저장할 때마다 "어느 내용을 보고 고친 것인지"를 확인해, 그 사이 다른 사람이 고쳤으면 저장을 받지 않습니다. 그래서 서로의 입력을 덮어쓰는 일이 없습니다. 이런 경우(예: 연결이 끊긴 사이 다른 사람이 고침) 내가 입력한 내용은 **개인용 대장에 "(저장 못 한 내 변경)" 사본**으로 남고, 화면은 서버의 최신 내용으로 바뀝니다. 사본에서 필요한 부분을 복사해 다시 넣으면 됩니다.
- **더보기 → 볼 수 있는 사람 · 편집 권한**(만든 사람·관리자): 팀 전체 / 그룹 / 지정한 사람으로 바꾸거나, "만든 사람과 관리자만 고침(나머지는 보기 전용)"으로 바꿉니다.
- **더보기 → 팀용·지정자용으로 올리기**: 개인용 대장을 서버로 옮겨 함께 씁니다(이 PC의 것은 없어지며, "개인용 대장에도 사본을 남기기"를 체크하면 남습니다).
- **더보기 → 개인용 대장으로 사본 받기**: 함께 쓰는 대장을 이 PC에 따로 복사합니다(사본은 나만 보고, 원래 대장과 따로 움직입니다).
- **더보기 → 대장 삭제**(만든 사람·관리자): 함께 쓰던 모든 사람에게서 사라지며 되돌릴 수 없습니다. 누군가 편집 중이면 지울 수 없습니다.
- 개인정보(주민등록번호·연락처 등)가 들어 있는 대장은 지정자용으로 만들어 꼭 필요한 사람만 지정하세요.

## 대장 다루기
### 대장 만들기
- **+ 새 대장** → 이름을 적고, **개인용 · 팀용 · 지정자용** 중 하나를 고른 뒤 서식을 누릅니다. 팀용·지정자용은 이어서 볼 수 있는 사람과 편집 권한을 정합니다.

| 서식 | 들어 있는 열 (자동 계산) |
|---|---|
| 빈 대장 | 항목·내용·수량·비고 |
| 물품(비품) 관리 대장 | 관리번호·품명·규격·수량·단가·**금액**(=수량×단가)·취득일·위치·담당자·상태 |
| 문서 수발신 대장 | 구분·문서번호·일자·제목·상대 기관·담당자·처리 상태·처리일·**처리 기간**(일) |
| 예산 집행 대장 | 집행일·예산 과목·적요·거래처·집행액·**누적 집행액**·**잔액**·예산·증빙 |
| 차량 운행 일지 | 운행일·운전자·목적지·용무·출발/도착 거리·**운행 거리**·주유 |
| 대여·반납 대장 | 품목·대여자·대여일·반납 예정일·반납일·**상태**(대여중/반납/연체)·**연체 일수** |
| 출장 대장 | 출장자·출장지·시작일·종료일·**일수**·목적·여비·정산 |
| 교육 이수 현황 | 이름·부서·교육명·이수일·시간·이수 |

- **CSV 가져오기**: 엑셀에서 "CSV로 저장"한 파일을 엽니다. 첫 줄이 열 이름이 되고, 열 종류(숫자·날짜·체크)는 내용을 보고 정합니다. 엑셀의 한글 CSV(ANSI)도 읽습니다.
- **대장 파일 열기**: "대장 파일로 저장"한 백업(.json)을 개인용 대장으로 엽니다(다른 PC로 옮길 때).

### 입력
| 동작 | 방법 |
|---|---|
| 새 값 입력 | 칸을 고르고 바로 입력 → **Enter**(아래로) / **Tab**(오른쪽으로) |
| 고쳐 쓰기 | **F2** 또는 두 번 클릭, 취소는 **Esc** |
| 이동 | 방향키, **Ctrl**+방향키(끝으로), **Home**/**End**, **PageUp**/**PageDown** |
| 여러 칸 고르기 | **Shift**+방향키 또는 끌기, 행 번호를 누르면 행 전체, 열 머리글을 누르면 열 전체, **Ctrl**+**A** 전체 |
| 지우기 | **Delete** |
| 복사·잘라내기·붙여넣기 | **Ctrl**+**C** / **X** / **V** — 엑셀과 서로 주고받을 수 있습니다. 붙여 넣을 행이 모자라면 행이 늘어납니다 |
| 오늘 날짜 | **Ctrl**+**;** |
| 체크 칸 | 누르거나 **Space** |
| 실행 취소·다시 | **Ctrl**+**Z** / **Ctrl**+**Y** (또는 위쪽 ↶ ↷) |
| 찾기 | **Ctrl**+**F** — 찾는 말이 들어 있는 행만 보입니다 |

- 위쪽 **수식 입력줄**에 고른 칸의 원래 내용(수식)이 보이고, 여기서 고친 뒤 **Enter**로 넣을 수 있습니다.
- 날짜는 2026-03-05, 2026.3.5, 2026년 3월 5일 모두 됩니다. 숫자의 쉼표는 저절로 빠집니다.
- 열 종류와 맞지 않는 값(숫자 열에 글자 등)은 칸 아래에 빨간 줄이 생깁니다.
- 선택한 칸들의 **합계·평균·개수**가 아래 상태 줄에 나옵니다.

### 행과 열
- **+ 행**(맨 아래), **+ 열**(맨 오른쪽). 칸이나 행 번호를 **오른쪽 클릭**하면 위/아래에 행 넣기, 행 복제, 행 삭제.
- 열 머리글의 **▾**: 오름차순/내림차순 정렬, 거르기(필터: 값을 골라 그 행만 보기), 열 설정, 왼쪽/오른쪽에 열 넣기, 열 삭제. 머리글 오른쪽 끝을 끌면 너비가 바뀝니다.
- 필터나 찾기가 켜져 있으면 **필터 해제** 단추가 나옵니다. 합계 줄은 보이는 행만 셉니다.
- 정렬은 행 순서를 실제로 바꿉니다(실행 취소로 되돌리기).

### 열 설정 (머리글 ▾ → 열 설정, 또는 머리글 두 번 클릭)
| 항목 | 내용 |
|---|---|
| 종류 | 글자 · 숫자 · 날짜 · 목록에서 고르기(항목을 한 줄에 하나씩) · 체크 · 팀원(팀원 이름 목록) · 계산(수식) |
| 표시 형식 | 자동 · 정수(1,234) · 소수 1·2자리 · 원(1,234원) · 백분율 · 날짜 |
| 합계 줄 | 없음 · 합계 · 평균 · 최소 · 최대 · 개수(값 있는 칸) · 체크한 개수 |

열 이름을 바꾸면 그 열을 쓰는 수식도 함께 바뀝니다.

### 계산
- **계산 열**: 종류를 "계산(수식)"으로 하고 열 이름을 [ ]로 써서 식을 만듭니다. 모든 행에 같은 식이 적용되고, 아무것도 입력하지 않은 행에서는 비어 있습니다. 식을 넣으면 첫 행의 결과가 미리 보입니다.
  - 예: `=[수량]*[단가]` · `=IF([반납일]="","대여중","반납")` · `=[종료일]-[시작일]+1`(일 수) · `=ROUND([금액]*0.1,0)` · `=CUMSUM([집행액])`(첫 행부터의 누적)
- **칸 수식**: 어느 칸이든 `=`로 시작하면 수식입니다. 엑셀처럼 `A1`(열 글자+행 번호), `A1:C5`(범위), `$A$1`을 씁니다. 열 글자는 머리글 위쪽 작은 글자, 행 번호는 왼쪽 번호입니다. 수식이 든 칸은 왼쪽 위에 파란 삼각형이 표시됩니다.
- `[열 이름]`을 SUM 같은 함수 안에 쓰면 **그 열 전체**, 계산에 바로 쓰면 **같은 행의 값**입니다. `[@열 이름]`은 항상 같은 행입니다. 예: `=SUM([금액])`, `=[금액]/SUM([금액])`(비율).
- 날짜끼리 빼면 일 수입니다. 오늘은 `TODAY()`.
- 함수: SUM, AVERAGE, MIN, MAX, COUNT, COUNTA, COUNTBLANK, IF, IFERROR, AND, OR, NOT, ROUND, ROUNDUP, ROUNDDOWN, INT, ABS, MOD, POWER, SQRT, LEN, LEFT, RIGHT, MID, TRIM, UPPER, LOWER, CONCAT, TEXT, VALUE, TODAY, NOW, DATE, YEAR, MONTH, DAY, DAYS, DATEDIF, ISBLANK, ISNUMBER, ISERROR, SUMIF, COUNTIF, AVERAGEIF, VLOOKUP, MATCH, INDEX, ROW, CUMSUM. 설명은 대장 화면 왼쪽 아래 **사용법 · 함수**.
- 연산: `+ - * / ^`, 글자 잇기 `&`, 비교 `= <> < > <= >=`, 백분율 `%`.
- 오류 표시: `#DIV/0!`(0으로 나눔) `#VALUE!`(글자를 계산) `#REF!`(없는 칸·열) `#NAME?`(없는 함수) `#CYCLE!`(자기 자신을 참조) `#N/A`(찾는 값 없음) `#ERROR!`(식이 틀림).
- 정렬하면 행이 옮겨지므로 `A1` 주소를 쓰는 칸 수식은 다른 행을 가리킬 수 있습니다. 행마다 계산하는 식은 계산 열과 `[열 이름]`으로 만드세요.

### 저장·내보내기 (더보기)
- 대장 하나는 약 500KB(보통 2,000~5,000행)까지이며, 넘으면 저장되지 않고 알림이 나옵니다. 해마다·분기마다 대장을 나누면 가볍게 쓸 수 있습니다.
- **CSV로 저장**: 엑셀에서 바로 열리는 파일(보이는 행, 계산된 값). **표 전체 복사**: 엑셀에 바로 붙여 넣기.
- **대장 파일로 저장**: 수식·열 설정까지 그대로 담은 백업(.json). 다른 PC에서 **대장 파일 열기**로 엽니다.
- **인쇄**: 표만 인쇄합니다. **대장 복제**, **대장 설명 쓰기**(표 위에 메모), **대장 삭제**(되돌릴 수 없음).

### 보기 공유 (개인용 대장의 사본)
개인용 대장을 옮기지 않고 지금 내용만 보여 주고 싶을 때 씁니다. 함께 고치려면 팀용·지정자용으로 올리세요.
- **더보기 → 팀원에게 보기 공유 (사본)** → 팀 전체 또는 고른 팀원 → **공유하기**. 지금 **보이는 행의 값**이 사본으로 서버에 올라가고 받는 사람에게 알림이 갑니다(64KB까지).
- 받는 사람은 **공유받은 대장**에서 **보기**(보기 전용)를 누르고, 필요하면 **내 대장으로 복사**(계산식은 값으로 바뀜)합니다.
- 표를 고친 뒤에는 다시 **공유 갱신**을 눌러야 받는 사람 화면이 바뀝니다. **공유 그만하기**로 서버의 사본을 지웁니다.
