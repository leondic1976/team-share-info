# 확장 기능 (플러그인)

TeamHub에 기능을 더하는 작은 프로그램입니다. 왼쪽 메뉴 **확장 기능**. 설치한 확장 기능은 그 아래에 메뉴로 나타납니다(예: 🪜 사다리타기).

**관리대장**은 설치할 필요 없이 항상 들어 있는 기능으로, 확장 기능 메뉴 바로 아래와 확장 기능 화면 맨 위("기본으로 들어 있는 기능")에 있습니다.

| 기본 제공 확장 기능 | 하는 일 | 자료가 있는 곳 |
|---|---|---|
| 🪜 사다리타기 | 당첨·순서·팀 나누기 | 함께하기 방은 서버, 기록은 이 PC |
| 🍜 맛집 추천 | 사무실 주변 맛집 추천 글·좋아요·댓글·랭킹 | 서버(팀 전체가 봄) |
| 📊 설문조사 | 설문 만들기·응답·결과 | 서버(받는 사람만 봄) |
| 🍱 식사 신청 | 사무실 점심·저녁 신청, 날짜별 현황, 월별 집계 | 서버(팀 전체가 봄) |
| 🧮 N분의 1 정산 | 회식비 등 나누기, 송금 정리 | 이 PC |
| 🔎 이미지 글자 읽기 (OCR) | 사진·캡처의 글자를 텍스트로 | 이 PC(이미지는 저장하지 않음) |
| ✨ AI 도우미 (Copilot) | Windows Copilot에 보낼 질문 만들기 | 이 PC(질문은 Copilot에 붙여넣을 때 Microsoft로 감) |

## 설치
설치는 항상 **TeamHub 안에서** 진행됩니다. TeamHub와 함께 제공되는 확장 기능(위 표)은 프로그램 안에 들어 있어 **인터넷 없이 한 번에** 설치됩니다.

| 방법 | 순서 |
|---|---|
| 기본 제공 (가장 쉬움) | **확장 기능** 화면 아래 **확장 기능 모음**에서 "기본 제공" 카드의 **바로 설치**. 여러 개면 **기본 제공 모두 설치** |
| 확장 기능 모음(다운로드 사이트) | 사이트에만 있거나 더 새 버전인 카드는 **설치** → 권한 확인 → **설치** (인터넷 필요) |
| 다운로드 사이트 | 다운로드 사이트의 **확장 기능** 페이지에서 카드의 **TeamHub에서 설치** → TeamHub가 열리고 확인 창이 나옴 |
| 파일 (폐쇄망) | 사이트에서 **파일 받기**로 받은 `.thplugin` 파일을 옮긴 뒤 **파일에서 설치** |

- 다운로드 사이트·파일에서 설치할 때는 확인 창에 확장 기능이 쓰는 **권한**이 나옵니다(팀원 이름 보기, 이 PC에 저장, 팀원과 함께하는 방, 알림, 클립보드 복사, 내가 고른 파일로 저장·열기, 내가 넣은 이미지의 글자 읽기, Copilot 열기). 확장 기능은 이 권한 밖의 일은 할 수 없습니다.
- 파일 권한이 있어도 확장 기능은 파일을 직접 고르지 못합니다. 저장·열기 창에서 **내가 고른 파일 하나**만 저장하거나 읽습니다(글자 파일: csv, txt, json 등, 5MB까지).
- 확장 기능은 격리된 화면에서 실행되어 인터넷·내 파일·다른 프로그램에 직접 접근하지 못합니다.
- 새 버전이 있으면 설치된 확장 기능 카드에 **업데이트** 단추가 나옵니다.
- **사용** 스위치로 잠시 끌 수 있습니다.

## 삭제
- **설치된 확장 기능** 카드나 **확장 기능 모음**의 "설치됨" 카드에서 **삭제**를 누르고 확인합니다. 왼쪽 메뉴에서도 사라집니다.
- 이 PC에 저장된 그 확장 기능의 데이터도 함께 지워집니다. 서버에 있는 자료(함께하기 방 등)는 남습니다.
- 삭제한 뒤에도 **확장 기능 모음**에서 **바로 설치**(또는 **설치**)로 언제든 다시 설치할 수 있습니다.

## 알아 둘 점
- 함께하기 방을 쓰는 확장 기능은 참여하는 팀원 모두 설치해야 합니다. 설치하지 않은 팀원이 초대를 받으면 설치 안내 알림이 옵니다.

## 사다리타기
### 바로 하기 (이 PC에서)
1. **참여자**를 줄바꿈이나 쉼표로 적습니다(2~30명). **팀원 불러오기**로 팀원 이름을 채우고 빠질 사람은 지웁니다.
2. **결과 종류**를 고릅니다.

| 종류 | 결과 |
|---|---|
| 당첨 고르기 | 당첨 N명(이름 바꾸기 가능), 나머지 꽝 |
| 순서 정하기 | 1등 ~ N등 |
| 팀 나누기 | A팀·B팀… (2~6팀, 고르게) |
| 커피 몰아주기 | 1명이 쏘기, 나머지 꽝 |
| 벌칙 정하기 | 노래·간식·회의록·청소 등(고칠 수 있음) |
| 직접 입력 | 결과 칸에 직접 적기(모자라면 꽝) |

3. **결과 가리기**를 켜 두면 결과가 ❓로 가려지고, 이름을 누를 때마다 하나씩 공개됩니다. **가로줄**로 사다리 복잡도를 고릅니다.
4. **사다리 만들기** → 위쪽 **이름을 누르면** 그 사람의 길을 따라 선이 그려지고 결과가 열립니다. **모두 공개**는 한 사람씩 차례로 보여 줍니다.
5. **다시 섞기**(새 사다리), **결과 복사**(메신저에 붙여넣기), **처음으로**.

### 팀원과 함께 (실시간)
1. **팀원과 함께** 탭 → 참여자·결과를 적고 **방 이름**을 정한 뒤 **방 만들고 초대**를 누릅니다. 누구나 방을 만들 수 있습니다.
   - 참여자 이름이 팀원 이름과 같으면 그 팀원에게 초대 알림이 갑니다. **팀 전체에 공개**를 켜면 알림 없이 모두의 방 목록에 보입니다.
2. 각자 사다리 위쪽 **고르기**를 눌러 자기 출발점을 고릅니다. 다시 누르면 취소합니다. 다른 사람이 고른 자리는 고를 수 없습니다.
3. 모두 고르면 방을 만든 사람이 **결과 공개**를 누릅니다. 비어 있는 자리는 참여자 목록에서 고르지 않은 사람에게 무작위로 배정됩니다.
4. 참여한 모든 사람의 화면에서 동시에 길이 그려지고 결과가 나옵니다.
- 가로줄은 출발점이 모두 정해진 **뒤에** 무작위(암호학적 난수)로 만들어지므로 누구도 미리 결과를 알 수 없습니다.
- 방 목록에서 진행 중인 방에 **참여**하거나, 끝난 방의 **결과 보기**를 합니다. 방을 만든 사람은 방을 지울 수 있습니다.

### 기록
**기록** 탭에 지난 게임(바로 하기·함께)의 결과가 50개까지 남습니다(이 PC에 저장).

## 맛집 추천
사무실 주변 맛집을 팀원끼리 추천하는 게시판입니다. 팀 전체가 함께 봅니다. 쓰려면 서버에 연결되어 있어야 하고, 보려는 팀원도 이 확장 기능을 설치해야 합니다.

- **맛집 추천하기**: 가게 이름, 종류(한식·중식·일식·양식·분식·카페·디저트·술집·기타), 별점, 대표 메뉴, 1인 가격대, 걸어서 몇 분, 태그(혼밥·단체·회식·가성비 등), 한 줄 평을 적고 **올리기**. 내 글은 **고치기·지우기**를 할 수 있습니다.
- **좋아요 / 가봤어요 / 댓글**: 글 아래 단추를 누릅니다. 다시 누르면 취소됩니다. 다른 팀원이 누르거나 쓰면 내 화면에 바로 반영됩니다. 단추에 마우스를 올리면 누가 눌렀는지 보입니다.
- **종류·검색·정렬**: 위쪽에서 종류를 고르고, 가게·메뉴·글쓴이로 검색하고, 최신순·인기순·별점순으로 바꿉니다. **내 글** 탭은 내가 쓴 글만 모읍니다.
- **맛집 랭킹**: 같은 가게를 여러 사람이 추천하면 하나로 모아 평균 별점과 좋아요·가봤어요 수로 순위를 매깁니다. 누르면 그 가게의 추천 글을 봅니다.
- **🎲 오늘 뭐 먹지?**: 지금 보고 있는 목록(고른 종류·검색어)에서 한 곳을 뽑습니다. 별점과 좋아요가 많을수록 잘 뽑힙니다.
- **📋 복사**: 추천 글을 메신저에 붙여넣을 수 있게 복사합니다.
- 한 사람이 추천 글 60개, 댓글 300개까지 쓸 수 있습니다. 사진은 올릴 수 없습니다. 팀 전체가 보는 글이므로 개인정보는 적지 마세요.

## 설문조사
1. **새 설문 만들기** → 제목과 안내 글을 적습니다.
2. 문항을 만듭니다. 종류: **하나 고르기 · 여러 개 고르기 · 별점(1~5) · 주관식**. 고르기 문항은 보기를 한 줄에 하나씩 적습니다. **꼭 답해야 함**을 정하고 ↑↓로 순서를 바꿉니다(30문항까지).
3. **마감 일시**(선택), **결과를 볼 수 있는 사람**(누구나 언제든 · 응답한 사람만 · 마감한 뒤에 · 만든 사람만), **이름 숨김**을 정합니다.
4. **받는 사람**: 팀 전체 또는 지정한 사람. 지정하면 그 사람들에게 초대 알림이 갑니다.
5. **설문 시작**.

- **응답**: 진행 중 목록에서 **응답 필요**로 표시된 설문을 열어 답하고 **응답 보내기**. 마감 전까지 **내 응답 고치기**를 할 수 있습니다.
- **결과**: 보기별 막대와 비율, 별점 평균, 주관식 모음이 나옵니다. 응답한 사람과 아직 안 한 사람도 보입니다.
- **만든 사람**: **지금 마감하기**, **결과 복사**(메신저용 요약), **CSV로 저장**(엑셀에서 열기), **설문 삭제**.
- **이름 숨김** 설문은 결과 화면과 저장 파일에 누가 무엇을 답했는지 표시하지 않고, 응답자 목록도 보여 주지 않습니다. 다만 응답은 서버에 응답자별로 저장되므로 완전한 무기명 투표는 아닙니다. 민감한 조사에는 쓰지 마세요.
- 받는 사람도 이 확장 기능을 설치해야 응답할 수 있습니다.

## N분의 1 정산
이 PC에서만 계산하고 저장합니다(서버에 보내지 않음).

### 간단 N빵
총 금액과 인원을 넣으면 1인당 금액이 나옵니다. 금액은 `187,500`, `18.7만`, `3천`처럼 적어도 됩니다.
- **금액 단위·단위 맞춤**: 1·10·100·1,000·10,000원 단위로 올림·반올림·내림. 모이는 돈과 **남는 돈·모자란 돈**이 함께 나옵니다.
- **먼저 뺄 금액**: 지원금·회비·쿠폰을 빼고 나머지만 나눕니다.
- **더 내는 사람**: 몇 명이 얼마씩 더 내는지(덜 내면 음수) 넣으면 나머지 사람의 금액이 계산됩니다.

### 항목별 정산
1차·2차·커피처럼 항목마다 낸 사람과 함께한 사람이 다를 때 씁니다.
1. **함께한 사람**을 넣습니다(**팀원 불러오기** 또는 이름 입력). 이름 옆 숫자는 분담 **비율**입니다(1 = 보통, 1.5 = 더 냄, 0.5 = 덜 냄, 0 = 안 냄).
2. **항목 추가** → 항목 이름, 금액, 낸 사람을 넣고 함께한 사람을 고릅니다.
3. 각자 **부담할 금액 · 이미 낸 돈 · 받을 돈/보낼 돈**과, 가장 적은 횟수로 끝내는 **보낼 돈**(누가 누구에게 얼마)이 나옵니다. 송금 단위를 맞출 수 있습니다.

- **결과 복사**: 메신저에 붙여넣을 글을 복사합니다. 아래 **받을 계좌**를 적어 두면 함께 들어갑니다. 복사한 내용은 **기록** 탭에 남습니다.

## 이미지 글자 읽기 (OCR)
사진·캡처·스캔 이미지의 글자를 텍스트로 바꿉니다. **Windows에 들어 있는 글자 인식**을 쓰므로 인터넷이 필요 없고 이미지가 PC 밖으로 나가지 않습니다.

1. 이미지를 넣습니다: **붙여넣기(Ctrl+V)**, 끌어다 놓기, **이미지 파일 고르기**(여러 장 가능). 화면 일부는 `Windows 키 + Shift + S`로 캡처한 뒤 붙여넣습니다.
2. **글자 읽기**를 누르면 오른쪽에 글자가 나옵니다. 여러 장은 차례로 읽어 이어 붙입니다.
3. 이미지 위를 **끌어서 고르면** 그 부분만 읽습니다(**고른 부분 읽기**).
4. 결과는 바로 고칠 수 있고, **줄바꿈 정리**(줄 끝에서 끊긴 문장 잇기), **복사**, **파일로 저장**(.txt)을 합니다. **최근 결과** 20개가 이 PC에 남습니다.

- 잘 안 읽히면 **작은 글자 키우기**(기본 켜짐)와 **흑백 대비 높이기**를 바꿔 보세요. 글자가 선명하고 반듯할수록 잘 읽습니다. 손글씨, 기울어진 사진, 표 안의 작은 글자는 틀리기 쉽습니다.
- **언어**는 이 PC의 Windows에 설치된 글자 인식 언어 중에서 고릅니다. 목록이 비어 있으면 Windows 설정 → 시간 및 언어 → 언어 및 지역 → 한국어 → 언어 옵션에서 **광학 문자 인식**을 설치하세요.
- 인식 결과는 틀릴 수 있습니다. 숫자·이름·금액은 원본과 꼭 맞춰 보세요.

## AI 도우미 (Copilot)
Windows에 들어 있는 무료 **Copilot**에게 일을 시키기 쉽게, 잘 통하는 질문을 만들어 줍니다.

1. **무엇을 시킬지** 고릅니다: 요약, 보고서·공문 초안, 문장 다듬기·맞춤법, 쉬운 말로, 번역, 회의록 정리, 답장·안내문 초안, 엑셀 수식·함수, 아이디어·개선안, 자유 질문.
2. **내용**을 붙여넣거나 적고, 말투·분량·형식을 고릅니다. 오른쪽에 Copilot에 보낼 질문이 만들어집니다(고쳐 써도 됩니다).
3. **복사하고 Copilot 열기**를 누르면 질문이 복사되고 Copilot이 열립니다. Copilot 입력칸에 **Ctrl+V → Enter**.
4. 받은 답은 복사해서 메모·문서에 붙여 씁니다.

- Copilot은 다른 프로그램이 질문을 대신 넣어 주는 방법을 제공하지 않아서, 붙여넣기는 직접 해야 합니다. Copilot 앱이 없는 PC에서는 브라우저로 Copilot 웹 페이지가 열립니다.
- **Copilot은 인터넷이 되는 PC에서만 동작하고, 붙여넣은 내용은 Microsoft로 전송됩니다.** 개인정보, 비공개 문서, 보안 내용은 넣지 마세요. 기관의 생성형 AI 이용 지침을 따르세요. 질문에 개인정보로 보이는 것이 있으면 복사하기 전에 한 번 더 묻습니다.
- 답은 틀릴 수 있습니다. 사실·숫자·법령은 꼭 확인하세요.
- **내 질문 틀 만들기**로 자주 시키는 일을 저장하고, **최근 질문**에서 다시 씁니다(이 PC에만 저장).

## 식사 신청
사무실 점심·저녁을 날짜별로 신청합니다. 신청하는 팀원 모두 설치해야 합니다.

### 처음 한 번: 관리자(서버 PC)가 설정
1. 관리자가 **식사 신청**을 열고 **설정** 탭을 누릅니다(관리자에게만 보임).
2. **점심 받기**, **저녁 받기**와 각각의 **신청 마감 시각**을 정합니다(처음 값: 점심 10:30, 저녁 15:30).
3. **며칠 앞까지 신청**(1 = 오늘만, 14일까지), **토·일요일에도 받기**, **공휴일에는 받지 않기**(처음 값: 켜짐), **안내 글**(예: 식당·가격)을 정합니다.
4. **서무**: 다른 사람의 식사를 대신 신청·취소할 사람을 고릅니다(여러 명 가능). 설정을 만든 관리자는 고르지 않아도 늘 할 수 있습니다.
5. **식사 신청 시작**을 누릅니다. 이후에는 같은 화면에서 고치고 **저장**합니다.

- 마감 시각은 **서버 PC의 시계**를 따릅니다. 팀원 PC의 시계가 달라도 같은 때에 마감됩니다(오른쪽 위에 서버 시각 표시).
- 설정은 처음 만든 관리자만 바꿀 수 있습니다.
- **공휴일**은 **관리 → 공휴일**의 목록을 따릅니다. 임시공휴일·기관 휴무일은 거기에 넣으면 그날 신청을 받지 않습니다. 목록은 식사 신청을 열 때 읽으므로, 공휴일을 고친 뒤에는 화면을 다시 엽니다.

### 신청 (신청 탭)
- 오늘부터 정해진 날까지 날짜마다 **점심**·**저녁** 칸이 나옵니다. 칸에 마감 시각과 남은 시간, 지금까지 신청한 인원이 보입니다.
- **신청**을 누르면 "✅ 신청함"이 됩니다. **취소**로 취소하고, **다시 신청**으로 다시 신청합니다. **마감 시각 전에는 몇 번이든** 바꿀 수 있습니다.
- 마감 시각이 지나면 그날 그 식사는 단추가 사라지고 "마감됨"으로 바뀌며, 신청도 취소도 할 수 없습니다.
- 공휴일은 날짜 칸이 나오지 않고 "공휴일(이름) — 신청을 받지 않습니다"라고만 보입니다.
- 서무가 대신 신청·취소한 것은 칸에 "○○○ 대신"이라고 보입니다. 마감 전이면 본인이 다시 바꿀 수 있고, **나중에 한 것**이 남습니다.

### 현황 탭
- 날짜를 **◀ ▶**로 옮기며 점심·저녁별 신청 인원과 이름(부서별)을 봅니다. "신청 받는 중"이면 아직 바뀔 수 있고, "마감 · 확정"이면 확정된 명단입니다.
- 다른 사람이 신청·취소하면 바로 반영됩니다.
- **대신 신청**(관리자·서무에게만, 마감 전에만 보임): 식사 칸 아래에서 사람을 고르고 **대신 신청**을 누릅니다. 명단의 이름 옆 **✕**는 대신 취소입니다. 대신 신청한 사람은 이름 옆에 "대신"이 붙고, 마우스를 올리면 누가 했는지 보입니다. 내일 것을 대신 신청하려면 **▶**로 날짜를 옮깁니다.
- **주문용 글 복사**: `오늘 11/23(월) 점심 5명: …` 형태로 복사해 메신저 등에 붙여넣습니다.

### 집계 탭
- 달마다 사람별 점심·저녁 횟수와 합계를 봅니다. **마감이 지나 확정된 신청만** 셉니다.
- **CSV로 저장**으로 엑셀에서 열 수 있는 파일로 저장합니다. 신청 기록은 100일 동안 보관됩니다(대신 신청한 기록은 62일).
