# 할 일 · 업무 요청

## 종류
| 종류 | 저장 위치 | 볼 수 있는 사람 |
|---|---|---|
| 개인 할 일 🔒 | 내 PC | 나만 |
| 업무 요청 | 서버 | 요청한 사람, 담당자 (그룹을 고른 상태에서 만들면 그 그룹 구성원도) |

## 만들기
1. **새 할 일**을 누릅니다.
2. **개인 할 일** 또는 **업무 요청**을 고릅니다.
3. 제목, 마감, 우선순위를 정합니다.
   - 업무 요청: **담당자**를 고르고 내용·첨부 파일을 넣습니다. 나 자신을 담당자로 지정할 수도 있습니다.
   - 개인 할 일: 메모를 적을 수 있습니다.
4. **요청 보내기**(개인 할 일은 **저장**)를 누릅니다. 담당자에게 Windows 알림이 갑니다.

## 보기
- 위쪽 버튼: **내가 할 일**(내가 담당자인 업무 + 개인 할 일) / **내가 요청한 일** / **전체 업무**(볼 수 있는 모든 업무) / **개인 할 일만**
- 오른쪽 위 버튼으로 **목록 보기**와 **칸반 보기**(요청·할 일 / 진행 중 / 완료 / 확인)를 바꿉니다.
- 목록에서는 끝난 일이 숨겨집니다. **끝난 일도 보기**를 체크하면 보입니다.
- 마감이 지난 일은 마감 시각이 빨간색으로 표시됩니다.
- 업무 마감일은 **일정** 달력에도 📌로 표시됩니다.

## 업무 진행 (업무를 눌러 열기)
| 단계 | 누가 | 버튼 |
|---|---|---|
| 요청 → 진행 중 | 담당자 | **시작** |
| 진행 중 → 완료 | 담당자 | **완료** (요청 단계에서 바로 완료도 가능) |
| 완료 → 확인 | 요청한 사람 | **확인** |
| 완료·확인 → 진행 중 | 요청한 사람(담당자도 완료 상태에서 가능) | **시작** (다시 진행) |

- 아래 **댓글**로 진행 상황을 주고받습니다.
- 제목·내용·마감·담당자 변경과 **삭제**는 요청한 사람만 할 수 있습니다.

## 개인 할 일
- 목록 왼쪽 체크박스로 완료 표시합니다.
- 누르면 제목·마감·우선순위·메모를 고치거나 삭제할 수 있습니다.

## 마감 알림
- 마감 **하루 전**과 **마감 시각**에 Windows 알림이 뜹니다(내가 담당자인 업무, 개인 할 일).
