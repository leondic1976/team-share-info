# 메신저 · 쪽지 · 공유 메모 · 팀원 알람

왼쪽 메뉴 **메신저**를 누릅니다. 팀원에게 무언가를 보내는 기능은 모두 여기에 있습니다. 메뉴 옆 빨간 숫자는 안 읽은 메시지와 쪽지 수입니다.

| 탭 | 언제 쓰나 |
|---|---|
| **대화** | 실시간으로 주고받는 1:1 대화와 대화방 |
| **쪽지** | 한 사람씩 받는 전달 글. 누가 읽었는지 보입니다 |
| **공유 메모** | 팀·그룹·지정한 사람이 함께 보는 전달 메모판(전화 메모 등) |
| **팀원 알람** | 정한 시각에 팀원 PC에서 울리는 알람 |

화면 오른쪽 위에 **새 대화**와 **쪽지 쓰기** 단추가 항상 있습니다. 어느 탭에 있든 누르면 받는 사람을 고르는 창이 열립니다.

사람을 고르는 창(새 대화, 쪽지 쓰기, 참가자 추가)에는 이름 앞의 점과 오른쪽 글자로 각 팀원의 상태가 **온라인**(초록) · **자리비움**(주황) · **부재** · **오프라인**(회색, TeamHub가 꺼져 있음)으로 표시되고, 접속한 사람부터 위에 나옵니다. 창을 열어 둔 동안에도 상태가 바뀌면 바로 반영됩니다. 오프라인인 사람에게 보낸 메시지·쪽지는 다음에 켤 때 받습니다.

## 대화

### 대화 시작
1. 화면 오른쪽 위의 **새 대화**를 누릅니다.
2. 사람을 고릅니다. 한 명이면 **1:1 대화**, 여러 명이면 **대화방**이 됩니다(대화방 이름은 선택).
3. **대화 시작**을 누릅니다. 같은 사람과의 1:1 대화는 항상 같은 대화방으로 이어집니다.
- **그룹 대화방**은 그룹마다 자동으로 있습니다. 그룹 구성원이 바뀌면 대화방 구성원도 따라 바뀝니다.

### 메시지 보내기
- 아래 입력칸에 쓰고 **Enter**로 보냅니다. **Shift+Enter**는 줄바꿈입니다.
- **파일 보내기**(클립 모양 단추)를 누르거나 파일을 대화 창에 끌어다 놓으면 파일을 보냅니다. 사진은 대화에 바로 보이고 누르면 크게 봅니다.
- **받은 파일**: 파일 줄의 **저장**을 누르면 저장할 위치를 골라 내려받습니다(마지막에 고른 폴더를 기억합니다). **열기**를 누르면 그 폴더(처음에는 다운로드 폴더)에 내려받아 바로 엽니다. 내려받은 뒤에는 파일 줄 아래에 저장된 폴더와 **열기** · **폴더 열기**가 나옵니다. 같은 이름의 파일이 있으면 덮어쓰지 않고 `이름 (2)`처럼 저장합니다. 실행 파일(exe, bat 등)은 저장만 하고 여기서 바로 열지 않습니다. 공지·게시글의 첨부 파일도 같은 방식입니다.
- 화면 캡처(예: `Windows 키 + Shift + S`)나 복사한 이미지를 입력칸에 **붙여넣기(Ctrl+V)** 하면 바로 보내지 않고 입력칸 위에 미리보기로 보입니다. 글을 함께 쓰고 **Enter**나 **보내기**를 누르면 보냅니다. 미리보기의 X 단추로 뺄 수 있습니다(한 번에 10개까지).
- **인터넷 주소**: 메시지에 `https://…`, `http://…`, `www.…`로 시작하는 주소를 쓰면 밑줄 친 링크가 됩니다. 누르면 PC의 웹 브라우저에서 열립니다(TeamHub 안에서는 열지 않음). 쪽지와 공유 메모의 주소도 같습니다. 주소 바로 뒤에 붙은 한글이나 문장 끝의 마침표·괄호는 주소에 넣지 않습니다.
- **이모티콘**(웃는 얼굴 단추): 인사·기쁨·사랑·응원·위로·놀람·화남·대답·업무·식사·날씨·동물 등 상황별 170여 개를 고릅니다. 위의 칸에 "감사", "축하", "커피"처럼 적어 찾을 수 있고, **최근** 탭에 쓴 것이 모입니다. 고른 이모티콘은 입력칸에 들어가며 **Enter**로 보냅니다. 이모티콘만 1~3개 보내면 크게 보입니다.

### 메시지 고치기 · 지우기
- 내가 보낸 메시지에 마우스를 올리면 연필(**고치기**)과 휴지통(**삭제**) 단추가 나옵니다.
- **고치기**: 글 메시지는 보낸 뒤 **24시간**까지 고칠 수 있습니다. 칸에서 고치고 **Enter**(또는 **고치기**)를 누르면 모든 사람의 화면에서 바뀌고, 시각 옆에 **수정됨**이 붙습니다(마우스를 올리면 고친 시각). **Esc**는 취소입니다. 사진·파일은 고칠 수 없습니다.
- **삭제**: 대화방의 모든 사람에게서 지워지고 그 자리에 **삭제된 메시지입니다.** 가 남습니다. 사진·파일도 함께 지워집니다. 되돌릴 수 없습니다.
- 다른 사람이 보낸 메시지는 고치거나 지울 수 없습니다. 고치기·지우기는 서버에 연결되어 있을 때만 됩니다.

### 메시지 글자 크기
- 대화방 위쪽의 **가-** / **가+** 단추로 메시지 글자를 작게·크게 합니다(11~22px). 가운데 숫자를 누르면 기본 크기로 돌아갑니다. 작은 메신저 창에서는 **…**(대화방 메뉴) 맨 위에 있습니다.
- 모든 대화방과 작은 메신저 창에 똑같이 적용되고, 이 PC에만 저장됩니다(다른 팀원 화면은 바뀌지 않음).

### 읽음 표시
메시지 옆의 **주황색 숫자**는 아직 읽지 않은 사람 수입니다. 모두 읽으면 숫자가 사라집니다.

### 대화방 관리 (오른쪽 위 버튼)
| 버튼 | 기능 |
|---|---|
| **알림 끄기** / **알림 켜기**(종 모양) | 이 대화방의 알림 켜기·끄기. 끄면 알림 카드·소리와 안 읽은 숫자 합계에서 빠집니다. |
| **이 대화방에서 회의 시작**(카메라 모양) | 대화방 구성원과 화상 회의를 엽니다(회의 장). |
| **대화방 이름 바꾸기**(연필 모양) | 대화방 이름 바꾸기 (여러 명 대화방) |
| **참가자**(사람 모양) | 참가자 목록을 보고 사람을 추가하거나 내보냅니다(아래 "참가자 추가·내보내기"). 대화방 이름 옆의 **○명**을 눌러도 열립니다. |
| **대화방 나가기**(문 모양) | 대화방에서 나갑니다(아래 "대화방 나가기"). |

### 대화방 나가기
필요 없는 대화를 내 목록에서 없앱니다. 대화방을 연 뒤 아래 중 하나를 누르고, 확인 창에서 **확인**을 눌러야 나가집니다. (왼쪽 대화 목록의 줄에는 나가기 단추가 없습니다.)
- 대화방 위쪽의 **대화방 나가기**(문 모양) 단추, 작은 메신저 창에서는 **…**(대화방 메뉴) → **나가기**
- **참가자** 창 아래의 **나가기**

| 대화 종류 | 나가면 |
|---|---|
| 여러 명 대화방 | 내 목록에서 사라지고, 남은 사람들에게 "○○님이 나갔습니다."라고 표시됩니다. 다시 들어가려면 참가자가 나를 다시 추가해야 합니다. |
| 1:1 대화 | 내 목록에서만 사라집니다. 상대에게는 알리지 않습니다. 상대가 다시 메시지를 보내거나 내가 그 사람과 다시 대화를 시작하면 이전 내용과 함께 다시 나타납니다(메시지는 없어지지 않습니다). |
| 그룹 대화방 | 나갈 수 없습니다(단추가 흐리게 표시됨). 그룹에서 나가야 빠집니다. |

나가면 열려 있던 그 대화의 화면과 작은 메신저 창도 닫힙니다. 서버에 연결되어 있을 때만 나갈 수 있습니다.

### 참가자 추가·내보내기
대화 도중 언제든 **참가자** 창에서 사람을 넣고 뺄 수 있습니다.

- **추가**: "추가할 사람"에서 사람을 체크하고 **추가**를 누릅니다. 대화방에 "○○님이 △△님을 초대했습니다"가 표시됩니다.
- **1:1 대화에 추가**: 1:1 대화는 두 사람만의 대화로 남습니다. 사람을 추가하면 두 사람과 추가한 사람이 들어간 **새 대화방**이 만들어지고 화면이 그 대화방으로 바뀝니다. 이전 1:1 대화 내용은 새 대화방으로 옮겨지지 않습니다.
- **내보내기**: 참가자 이름 옆의 **내보내기**를 누릅니다. 대화방을 만든 사람과 관리자(최종관리자·서무)만 할 수 있습니다. 내보낸 사람의 목록에서 대화방이 바로 사라지고, 그 사람은 이 대화방의 이전 대화도 볼 수 없습니다. 다시 추가하면 다시 볼 수 있습니다.
- **나가기**: 내가 대화방에서 나갑니다(위 "대화방 나가기").
- **그룹 대화방**은 그룹 구성원을 그대로 따르므로 여기서 바꿀 수 없습니다. 그룹 메뉴에서 그룹 구성원을 바꾸세요.
- 참가자 목록의 이름을 누르면 그 사람과의 1:1 대화가 작은 메신저 창으로 열립니다.

## 작은 메신저 창
메신저 메뉴로 가지 않고, 보고 있던 화면 위에 작은 대화 창을 띄워 바로 대화합니다. 창이 떠 있어도 뒤의 화면은 그대로 쓸 수 있고, 다른 메뉴로 옮겨도 창은 남아 있습니다.

### 이름을 눌러 대화하기
사람 이름에 마우스를 올리면 밑줄이 생기고 "메신저 열기"라고 나옵니다. 누르면 그 사람과의 1:1 대화가 화면 오른쪽 아래에 작은 창으로 열립니다. 같은 사람을 다시 누르면 이미 열린 창으로 갑니다. 내 이름은 눌러지지 않습니다.

- **홈**의 팀원 현황, **주소록**의 팀원 이름, **근무현황**(일별·주간)의 이름, 게시글 작성자, 댓글 작성자, 대화방 **참가자** 목록, 공지 **수신 현황**의 이름, **그룹** 구성원 목록
- **주소록**·**조직도**에서 팀원 카드를 열고 **메시지**를 눌러도 작은 창으로 열립니다.
- **근무현황** 일별 현황의 현재원 이름은 누르면 사고 신청이 열리는 경우가 있습니다. 그때는 이름 옆의 작은 말풍선을 누르면 메신저가 열립니다.
- 서버가 꺼져 있을 때: 전에 대화한 적이 있는 사람이면 창이 열려 지난 대화를 읽고 메시지를 써 둘 수 있습니다(서버가 켜지면 전송). 처음 대화하는 사람이면 창 대신 안내가 나옵니다.

### 창 다루기
| 버튼 | 기능 |
|---|---|
| **…** (대화방 메뉴) | 글자 크기 · 참가자 · 알림 끄기/켜기 · 대화방 이름 바꾸기 · 이 대화방에서 회의 시작 · 나가기 |
| **–** (최소화) | 창을 이름표로 줄입니다. 그동안 온 메시지 수가 이름표에 빨간 숫자로 표시됩니다. 이름표를 누르면 다시 펼쳐집니다. |
| **메신저에서 열기** | 작은 창을 닫고 메신저 메뉴에서 같은 대화를 엽니다. |
| **✕** (창 닫기) | 창을 닫습니다. 대화 내용은 그대로 남습니다. |

- 여러 창을 나란히 열 수 있습니다. 화면 너비에 들어가는 만큼만 펼쳐지고, 넘치면 먼저 연 창부터 이름표로 줄어듭니다. 이름표도 다 들어가지 않으면 **+N**에 모이고, 누르면 목록이 나옵니다.
- 창 위쪽 줄(이름이 있는 줄)을 끌면 창을 옮길 수 있습니다.
- 파일 보내기, 캡처 붙여넣기, 읽음 표시 등은 메신저 메뉴의 대화와 같습니다.
- TeamHub를 다시 시작하면 작은 창은 닫힌 채로 시작합니다.

### 검색
목록 위 검색칸에 입력하면 대화방 이름과 **메시지 내용**을 함께 찾습니다. 결과를 누르면 그 대화방이 열립니다.

### 알림
- 새 메시지나 쪽지가 오면 알림음과 함께 **"새로운 메시지 도착입니다"**라고 알려 주고, 화면 오른쪽 위(창의 닫기 단추 바로 아래)에 보낸 사람과 내용이 **미리보기 카드**로 뜹니다. TeamHub 창이 트레이에 숨어 있어도 뜹니다. 카드를 누르면 그 대화가 열리고, X(또는 여러 개일 때 **모두 닫기**)로 닫을 때까지 남아 있습니다. 같은 대화방 메시지는 한 카드에 모이고 개수가 표시됩니다. 잠금 PIN으로 잠겨 있을 때는 내용 없이 "새 알림이 있습니다"만 보입니다. 공지·새 일정·일정 알림·알람 등 다른 알림도 같은 카드로 뜨고, 알림음과 함께 "새로운 알림 도착입니다"라고 알려 줍니다. 소리와 미리보기는 **설정 → 알림**의 **알림 소리**·**알림 미리보기**에서 끌 수 있고(미리보기를 끄면 Windows 알림으로 알려 줌), **시험 알림**으로 카드를, **들어 보기**로 소리를 확인할 수 있습니다. 지금 보고 있는 대화방(펼쳐 둔 작은 메신저 창 포함), 알림을 끈 대화방, 방해 금지 시간에는 뜨지 않습니다. 최소화한 작은 창의 대화는 알림이 뜹니다.
- TeamHub가 꺼져 있던 동안 온 메시지는 다음에 켤 때 그대로 보입니다.

## 쪽지
짧은 전달 사항(전화 메모 등)을 남기는 기능입니다. 받는 사람이 꺼져 있어도 다음에 켤 때 받습니다.
- **쪽지 쓰기**(화면 오른쪽 위): 받는 사람(여러 명 가능)과 내용을 입력하고 **보내기**. 주소록에서 팀원을 누르고 **쪽지**를 누르면 그 사람이 받는 사람으로 들어간 채 열립니다.
- **받은 쪽지**: 파란 점은 안 읽은 쪽지입니다. 누르면 열리고 읽음으로 바뀝니다. **답장**, **삭제**가 있습니다.
- **보낸 쪽지**: 받는 사람별 읽음 여부(**읽음 1/3** 등)와 읽은 시각을 봅니다.

## 공유 메모
**메신저 → 공유 메모**. 간단한 전달 사항·전화 메모("○○과에서 전화 왔음")를 남기는 메모판입니다. 서버에 저장되고 공개 범위의 팀원에게 보입니다. (예전에는 메모 메뉴에 있었습니다.)

1. **공유 메모 남기기**를 누릅니다.
2. 내용을 쓰고 색과 **받는 사람(공개 범위)**: 팀 전체 · 그룹 · 지정한 사람을 고릅니다.
3. **남기기**를 누르면 받는 사람 화면에 바로 나타납니다.
4. 받은 사람이 메모 아래 **확인**을 누르면 "이름 확인 · 시각"이 표시됩니다. 다시 누르면 확인이 취소됩니다.
5. 확인된 메모는 7일 뒤 목록에서 사라집니다. 지우기(휴지통 단추)는 작성자와 관리자만 합니다.

쪽지와 다른 점: 쪽지는 받는 사람마다 따로 가고 각자의 읽음이 표시됩니다. 공유 메모는 여러 사람이 **같은 메모 한 장**을 보고, 그중 누군가 처리했다고 **확인**하면 됩니다.

## 팀원 알람
**메신저 → 팀원 알람**. 다른 팀원 PC에서 정한 시각에 알람이 울리게 합니다(예: "14시 회의 자료 지참"). (예전에는 알람 메뉴에 있었습니다.)
1. 받는 사람을 체크합니다(여러 명 가능). 목록 맨 위 **전체 선택**을 체크하면 보이는 팀원이 모두 선택되고, 다시 누르면 모두 풀립니다. 이름·부서를 검색한 뒤 누르면 검색된 사람만 선택됩니다.
2. 알람 내용, 덧붙일 말(선택), 울릴 일시를 정합니다. 바로 울리게 하려면 **즉시**를 누릅니다(다시 누르면 일시를 정하는 방식으로 돌아감).
3. **보내기**를 누릅니다. **즉시**를 골랐으면 단추가 **즉시 보내기**로 바뀌고, 누르는 바로 그때 울립니다.
- 받는 사람 PC에 "○○님이 보낸 알람" 창이 뜹니다. **확인**을 누르면 보낸 사람의 **보낸 알람** 목록에 "확인 시각"이 표시됩니다.
- 그 시각에 받는 사람 PC가 꺼져 있으면 다음에 켤 때(24시간 안) 울립니다.
- 아직 전달되지 않은 알람은 **보낸 알람**에서 **취소**할 수 있습니다.

## 개인정보 확인
메시지·쪽지·공유 메모·팀원 알람을 보낼 때, 그리고 게시글·댓글·공지를 올릴 때 내용에 **개인정보로 보이는 것**이 있으면 보내기 전에 한 번 더 묻습니다.

- 찾는 것: 주민등록번호, 외국인등록번호, 여권번호, 운전면허번호, 카드번호, 계좌번호(은행 이름이나 "계좌" 뒤의 번호), 휴대폰 번호, 이메일 주소
- 확인 창에는 무엇이 몇 건인지와 일부를 가린 값(예: `900101-1******`)이 나옵니다. **확인**을 누르면 그대로 보내고, **취소**를 누르면 보내지 않고 고칠 수 있습니다.
- 검사는 이 PC에서만 하고 어디에도 기록하지 않습니다.
- 알림일 뿐 완전한 차단이 아닙니다. 형식이 다른 번호는 찾지 못할 수 있고, 개인정보가 아닌 번호를 물어볼 수도 있습니다. 첨부 파일 안의 내용은 검사하지 않습니다.

## 보관 기간
메시지와 쪽지는 최종관리자(서버 PC)가 정한 기간(기본 365일)이 지나면 자동으로 지워집니다.

대화방에서 주고받은 파일과 사진은 서버 PC의 저장 공간을 위해 따로 정한 기간(기본 90일, 관리 > 조직·운영 설정 > 저장 공간의 **메시지 파일 보관 기간**)이 지나면 서버 PC에서 지워집니다. 메시지는 남고 그 자리에 파일 이름과 **보관 기간이 지나 서버에서 삭제된 파일입니다.** 가 표시되며, 더 내려받을 수 없습니다. 오래 두어야 할 파일은 미리 내려받아 두거나 자료실에 올려 두세요.
