# 조직도

기관·팀의 부서와 사람을 위에서 아래로 그린 그림으로 봅니다. 왼쪽 메뉴 **조직도**(근무현황과 주소록 사이).

- 맨 위 칸이 기관·팀, 그 아래로 부서가 상위 부서 → 하위 부서 순서로 이어지고, 부서 칸 안에 소속 구성원이 카드로 나옵니다.
- 팀원 누구나 볼 수 있습니다. 부서와 배치는 서버 PC에서만 바꿉니다(**설정 → 조직 관리**).
- 서버가 꺼져 있어도 마지막으로 본 조직도가 그대로 보입니다(상태 점과 오늘 부재는 마지막으로 받은 내용).

## 맨 위 요약 줄
- **총원 · 재석 · 부재 · 미접속 · 부서** 수가 나옵니다.
  - **재석**: 지금 프로그램을 켜고 있는 사람(온라인·자리비움).
  - **부재**: 켜고 있지 않은 사람 중 오늘 근무현황(연가·출장 등)이나 부재 일정이 있는 사람.
  - **미접속**: 나머지.
- 오른쪽에 상태 점 색(온라인·자리비움·부재·오프라인)과 기준 시각이 있습니다.

## 부서 칸
- 부서 이름, **재석 인원/총원**(하위 부서 포함), 부재 인원, 대표 전화·내선, 위치, 담당 업무가 나옵니다.
- **부서장**은 칸 맨 위에 색을 달리해 크게 표시됩니다. 다른 부서 소속인 사람이 부서장이면 이름만 한 줄로 나옵니다.
- 이름 오른쪽 **∨** 를 누르면 그 부서(구성원과 하위 부서)를 접고, **>** 를 누르면 다시 폅니다. **모두 펼치기 / 모두 접기**로 한 번에 바꿉니다.
- 어느 부서에도 들어 있지 않은 사람은 **부서 미지정** 칸에 모입니다.

## 구성원 카드
- 상태 점, 이름(필명), 직위·직급, 담당 업무, 내선번호·휴대폰, 상태 메시지가 나옵니다.
- 오늘 근무현황에 올린 것이 있으면 **연가**, **출장 14:00~** 처럼 종류와 시간이 색으로 표시됩니다.
- **부서장 / 최종관리자 / 서무 / 나** 표시가 붙습니다.
- 카드를 누르면 자세한 정보가 열리고 **메시지 / 쪽지 / 업무 요청**을 바로 보낼 수 있습니다.

## 찾기와 골라 보기
- **검색칸**에 이름·부서·담당 업무·전화번호 일부를 입력하면 맞는 사람과 부서에 테두리가 생기고 나머지는 흐려집니다. 첫 결과로 화면이 옮겨 가고, **Enter**를 누를 때마다 다음 결과로 갑니다(**Shift+Enter**는 이전). 접어 둔 부서도 검색하는 동안에는 펼쳐집니다.
- **전체 부서** 목록에서 부서를 고르면 그 부서와 하위 부서만 봅니다.
- **재석만**을 켜면 지금 재석 중인 사람만 남습니다.

## 크기와 이동
- **화면 맞춤**: 조직도 전체가 화면 너비에 들어오게 줄입니다(처음 상태).
- **축소 / 확대**(돋보기 단추)로 크기를 바꾸고, 가운데 **숫자(%)** 를 누르면 100%로 봅니다.
- 조직도가 화면보다 크면 빈 곳을 마우스로 끌어 옮기거나 스크롤 막대를 씁니다.

## 목록형
오른쪽 위 **목록형**을 누르면 같은 내용을 부서별 표(이름, 직위·직급, 담당 업무, 내선, 휴대폰, 오늘)로 봅니다. 사람이 많을 때 한눈에 보기 좋습니다. **조직도**를 누르면 그림으로 돌아갑니다.

## 인쇄
**인쇄**를 누르면 지금 보는 내용(고른 부서, 재석만)을 A4 가로로 인쇄하거나 PDF로 저장합니다. 조직도가 한 장 너비에 맞게 줄어들고, 너무 넓어 글자가 작아지면 목록형으로 인쇄됩니다.
