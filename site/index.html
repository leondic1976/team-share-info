TeamHub

한 대의 PC가 서버가 되어 팀원끼리 공지·일정·자료·메신저·회의를 나누는 Windows 업무 프로그램입니다.

최신 버전 확인 중
Windows 10·11 (64비트) · 관리자 권한 없이 설치

설치

  1. 위 단추로 TeamHub-Setup-버전.exe를 내려받아 실행합니다. 설치는 자동으로 끝나고 TeamHub가 열립니다.
  2. Windows가 "PC 보호" 창을 띄우면 추가 정보 → 실행을 누릅니다(서명되지 않은 사내 배포 프로그램이라 나오는 안내입니다).
  3. 팀에서 처음 쓰는 경우: 한 사람이 이 PC를 서버로 사용을 고르고 설정을 마칩니다.
  4. 다른 팀원: 서버에 접속을 고르고 서버 PC 주소(예: 192.168.0.10:47800)를 넣어 사용 신청 → 관리자가 승인하면 바로 씁니다.

폐쇄망(인터넷이 안 되는 업무망)에서는 이 파일을 USB 등으로 옮겨 설치하거나, 서버 PC 주소 뒤에 /download를 붙인 사내 다운로드 페이지에서 받습니다.

업데이트

  • 자동 업데이트: 설치된 TeamHub가 이 사이트(인터넷) 또는 서버 PC(폐쇄망)에서 새 버전을 확인해 내려받고, 다음에 켤 때 설치합니다.
  • 수동 업데이트: TeamHub 설정 → 업데이트 → 지금 확인. 자동 업데이트를 끄면 직접 내려받기·설치를 누릅니다.
  • 폐쇄망: 관리자가 관리 → 업데이트 배포 → 다운로드 사이트에서 가져오기(서버 PC에 인터넷 필요) 또는 이 사이트에서 받은 설치 파일을 직접 올립니다.
